  1. 上のファイル名を確認し、「エディタで開いて取得」を押します。エディタ上部の「ダウンロード」から、自分の学校アカウントで今回の実習ファイルを取得します。
  2. 取得したファイルを、名前を変えずに 書類 → HTML実習 フォルダへ保存します。前の実習のHTMLも同じフォルダに置きます。
  3. エディタ上部の「開く」で接続済みのHTML実習フォルダの一覧を更新し、今回のHTMLを選びます。初めて接続するときは「設定」からフォルダを接続します。
  4. コードを編集し、プレビュー右上の更新アイコン（⌘Enter）で表示を確認します。コード領域上部の「保存」も押し、「Macのファイルに保存しました」の表示を確認します。
  5. エディタの「提出」を押すと、保存済みの実習ファイルが提出フォームに準備されます。対象ファイル名を確認して「提出する」を押し、「提出を受け付けました」まで確認してください。別タブ・ダウンロード保存では、保存したファイルを選択します。

初めての操作は取得・フォルダ接続・保存の詳しい手順を確認してください。保存できない環境や読取専用で開いたファイルでは、「保存」で上書きできない説明を確認してから「コピーをダウンロード」を選び、保存先・内容・ファイル名をFinderで確認します。

プレビュー更新とファイル保存は別の操作です。配付情報（joho-issued-htmlを含むコメント）は削除・変更しないでください。CotEditorなどで編集した場合は、上の「提出する」から提出フォームを開けます。

確認できた採点項目には ★ が付きます。受付期間内は何回でも修正して再提出できますが、同じ課題の新しい提出は 60秒以上 あけてください。

★はコードの確認結果です。画像が表示されること、リンクが開くこと、見やすさは、自分のブラウザでも確かめてください。

保存・復元で困ったとき

保存に失敗したときは、編集画面を閉じずに先生に相談してください。作業後は HTML実習 フォルダ全体を別の場所にもコピーしておくと、画像もまとめて戻せます。

次回はMacに保存したファイルを「開く」から選んで続けます。接続先は記憶され、許可済みなら自動で再接続します。許可が必要なときだけ「前回のフォルダへ再接続」を押します。ブラウザの控えは自動では開かず、万が一のときだけ「設定」に常にある「復旧候補を開く…」から日時とファイル名を確認して選び、復旧した内容をMacへ保存してください。

提出済みのHTMLは、提出画面の「控えを保存」から控えを保存できます。これは提出時点のHTMLだけで、画像や提出後の編集内容は含みません。テンプレートを取り直しても作業途中の内容は復元されないので、編集中のファイルに上書きしないでください。

(1) リンク

ハイパーリンク

ハイパーリンクとは、ハイパーテキストにおいて複数の文書を結び付ける役割を担う参照のことです。現在では、単にリンクとよばれることがほとんどで、このサイトでも単にリンクと表記します。

<a>タグ

リンクを貼るには、リンクさせたい部分を<a>タグで囲み、リンク先をhref属性で指定します。<a>はanchorの略で、リンクの出発点や到達点を意味します。 


        <a href="リンク先">リンクの文字</a>

サイト内リンク

サイト内の別のHTMLファイルを指定するときには、相対パスを使用します。


        <a href="./html12-01.html">HTMLファイルの構成</a><br>

他のページへのリンクも作成しましょう。

html15-01.html と、これまでに編集した html12-01.html・html13-01.html・html13-02.html・html14-01.html を、同じ HTML実習 フォルダに置いてください。リンクをクリックして、それぞれのページが開くことも確認します。

エディタにはHTML実習フォルダ全体を接続します。編集内容を保存してから、エディタ内のプレビューでリンクを押してください。リンク先のHTMLがコード欄にも開きます。元へ戻るときは上部の「開く」で一覧を更新し、html15-01.html を選びます。

プレビューの「別タブ」では、ファイル間の移動はできません。リンク先を後からフォルダに追加した場合は、編集中のHTMLを保存してから、「開く」で一覧を更新してください。

残りのリンクを条件から作ろう

上の1つ目の例を参考に、次の3つを追加してください。リンク先のファイル名と、画面に表示する文字を区別して入力します。

リンク先のファイル名リンクの文字
html13-01.html見出し・段落・改行
html13-02.htmlページのアウトライン
html14-01.html画像の挿入

それぞれのリンクのあとにbrで改行を入れます。どのファイルが開くか予想してからクリックし、リンクの文字と行き先が一致することを確かめましょう。

外部リンク

外部のサイトへのリンクを外部リンクといいます。外部サイトを指定するときには、絶対パスを使用します。外部リンクでは、新規ウィンドウや新規タブで開くことが多いですが、その場合はtarget="_blank"を加えます。

エディタのプレビューでは、安全のため外部リンクを常に別タブで開きます。targetの有無による違いを確かめるときは、保存したHTMLをFinderからChromeやSafariで開いて確認してください。


        <a href="https://www.kaijo.ed.jp/" target="_blank">海城中学高等学校</a><br>

続きは、https://www.apple.com/jp/へ「Apple」、https://www.google.com/へ「Google」という文字でリンクを作ってください。どちらも新しいタブで開く指定と、リンクのあとの改行を加えます。

自由製作で資料の出典へリンクするときも、リンクの文字から行き先が分かるかを確認します。

(2) ページ内リンク

ページ内リンク

ページ内にリンクを設定するためには、リンク先（到達点）の要素にid属性を使ってあらかじめ名前を付けておく必要があります。例えば、ページ内のある<h2>タグにtopic_bというIDを指定しておきます。 


        <h2 id="topic_b">トピックB</h2>

次に、リンク元（出発点）の<a>タグのhref属性に、ID名を「#」のあとに続けて記述します。


        <a href="#topic_b">トピックBはこちら</a>

長い1ページで必要な情報を見つけられるようにする、自由製作の目次にも使える技術です。

ID属性について

ID属性は、任意のタグにid="ID名"を加えます。HTMLの仕様上は、次のルールを守る必要があります。

  • 1つのIDは、同じ文書内で１回のみ使用できます。
  • ID名は空にせず、半角スペース・タブ・改行などのASCII空白文字を含めません。
  • アルファベットの大文字と小文字は区別されています。

この実習では、入力ミスを避けて扱いやすくするため、英字で始め、半角の英数字・ハイフン（-）・アンダースコア（_）を使うことにします。

別のページの特定部分へのリンク

別ページの特定の到達点を指定する場合には、html15-02.html#topic-cのように、HTMLファイル名のあとに「#」とID名を記述します。


        <a href="./html15-02.html#topic-c">未来の技術</a>
