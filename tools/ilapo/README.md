# イラポ 0.3 BETA

開発ネームは「イラポ」。正式名称は保留。海城中学高等学校 情報科の、ピクトグラム・ロゴ・説明図・スライド制作を目指すブラウザ用ベクターエディタ。

## 今回の範囲

計画①・②に続き、2026-09-16に「③ 説明図・スライド制作」を実装した。アニメーションは計画④で追加する。

- 長方形・角丸長方形・楕円・三角形・五角形・線・文字の追加。クリックまたはドラッグで配置。
- 選択・Shiftで追加選択・範囲選択、移動・サイズ変更・回転・反転。数値入力でも操作可能。
- コピー・貼り付け・複製・削除、平坦なグループ、固定・解除、重なり順。
- 最初に選んだ図形を基準にした整列・大きさ合わせ、等間隔配置、書式コピー。グループ内の相対位置を保つ。
- 塗り・線・線幅・破線・線端・線の角・透明度、18色のパレット・自由な色選択・RGB・16進数。
- 日本語の複数行文字、ゴシック・明朝・等幅、太字・斜体、部分的な上付き・下付き。
- 18/36/72px、名刺55×91mm、JIS B5 182×257mm、A4 210×297mm、16:9 1280×720px、自由キャンバス、任意のpx/mm/pt。幅・高さの入れ替え。用紙変更で作品は拡大縮小しない。
- 複数ページの追加・複製・削除・並べ替え・改名。ページ間コピー。
- 自動保存と明示保存を独立して保持し、読み込み時に候補を選択。ブラウザ内とローカルファイルを利用。
- 基本的な標準SVGの取り込み・書き出し、複数ページをまとめた再編集用ZIP。
- 100操作のUndo/Redo、1回の操作を1回で取消。ドラッグ途中は文書・保存を変更せず、Escape・pointercancel・フォーカス喪失で取消。
- テーマ（自動・ライト・ダーク）、操作文字3段階、グリッドと配置・移動時の吸着、パン・ズーム。
- 常設の上部は1行、選択時の編集はポップアップ。狭い幅では上部「…」から追加ツール・用紙・ページへアクセス。作図を続けながら読める共通ヘルプ。

## 0.2で追加した操作

- 初期ツールは直接選択（A）。点・区間を選び、ドラッグ・Shiftで追加選択・点の範囲選択で編集する。「全体を選択」（V）で図形全体の移動・変形へ切り替える。選択中の操作は上中央のポップアップに置く。
- 「パス」からアンカー一覧・座標編集・全アンカー選択。区間を選んで追加、または区間をダブルクリック。選んだ点は矢印キーでも移動できる。
- ハンドルのドラッグ、角／滑らかな点への変換。通常のハンドル移動は反対側の方向をそろえて長さを保つ。Optionでは片側だけを変更し、吸着も一時解除する。数値によるハンドル編集は両側を独立して指定する。
- 選んだ直線同士の角を、実際の三次ベジェ曲線に置き換える。指定半径はworld座標のpxで、隣の辺の半分以内に収める。複数角は変更前の辺から同時に計算する。曲線が接する角の半径指定は未対応で、そのような箇所は「滑らかにする」とハンドルで調整する。
- Delete／「削除して切り開く」は選択点の箇所で切断。「削除して前後をつなぐ」は残る点を接続する。選んでいないサブパスの閉じ方・穴は保つ。「ここで切り開く」は切断箇所の点を複製して形を保ち、閉路は開路へ、開路の途中は2本へ分割する。
- 端点2つを、直線・中間の1点へまとめる・滑らかな曲線で連結する。滑らかな連結では両端を動かさず接線をそろえる。同じパスの両端なら閉じる。異なる回転・拡大率のパスも最初のパスの座標系に移し、位置を保つ。
- 閉じたパス同士を合体／型抜き／重なりだけ残す。最初に選んだパスのID・書式・行列を引き継ぎ、型抜きはそのパスから後のパスを引く。空の結果は入力図形を削除し、Undoで戻せる。文字・開路には適用しない。結果は穴と曲線を含む通常のSVGパスで、直後も保存後も再編集できる。
- グリッド、ピクセル、他のアンカー、他のパスへの吸着を切り替える。アンカー→パス→グリッド／ピクセルの順に優先。吸着先を点と名称で示し、内部座標は小数を維持する。パス途中に別の端点を重ねても2本のパスのままで、後からの移動には追従しない。
- PNGの倍率・透明／白背景、ページ／選択範囲の出力。最大1辺16384pxかつ約3200万画素を超える出力は明示的に断る。
- Chromeの印刷画面からベクターPDFを保存する。現在／全ページ、A4・JIS B5・名刺・任意サイズ・自由キャンバスの実寸を維持。寸法はSVGのCSS pxをmmへ換算し、比率から用紙を推測しない。PDFの直接ダウンロードではなく印刷ダイアログを使用する。

アンカー・ハンドル・吸着の表示はSVG出力へ含めない。アンカーのドラッグはプレビューから確定時に1履歴として記録し、キャンセル時は点の選択も復元する。変形済みパスのSVG再読み込みで縦方向の移動量が失われる既存の行列合成も修正した。

## 0.3で追加した操作

- 菱形・平行四辺形・太い矢印・吹き出し。既存の基本図形と同じ通常パスで、アンカー編集・合体・型抜きが可能。
- 図形同士を接続する矢印。ドラッグまたは2回のクリックで作成し、空白にも端点を置ける。図形の移動・回転・パスの編集に追従する。図形の輪郭で自動接続するほか、接続する辺と辺内の位置（0〜1）を指定できる。
- 接続先の削除で端点をその位置に残して接続解除。ページ・図形群の複製では内部の接続を新しいIDへ更新し、コピーに含まれない外部の図形への接続は解除する。
- 選択時の「接続・経路」で直線／折れ線／直角、始点と終点の矢じり、複数行ラベル・位置、折れ曲がり点の座標・追加・削除を編集。直接選択では端点・経路点・ラベルをドラッグでき、線のダブルクリックでも点を追加できる。Optionを押して端点を置くと図形への接続を解除する。キャンセル・Undoは1回の編集単位を保つ。
- 矢印を「通常のパスに変換」すると、線・矢じり・文字をグループにした普通のオブジェクトになる。変換後は追従を終了し、直接選択や合体の対象にできる。
- 人・鍵・PC・サーバー・クラウド・フォルダ・書類・スマホ・チェック・注意の10種類の自作アイコン。通常のパスなので色やアンカーを変更できる。
- 選択した図形群を自作部品に登録し、グループとして再配置。元の部品と配置済みの図形は独立し、部品内部の接続だけを複製先へ引き継ぐ。部品集をJSON保存し、別環境へ追加できる。100部品・各200オブジェクト・保存文字列3MiBまで。容量不足や破損した読み込みでは既存の部品集を保持する。
- PNG・JPEG・WebPの下絵。画像はブラウザ内でデコードしてPNGへ再保存し、元の画素数を保ち、表示寸法だけ用紙に合わせる。初期設定は不透明度40%・固定・出力対象外。「画像の設定」で名前・不透明度・固定・出力への包含を変更できる。画像はパスへ自動変換しない。
- 静止スライドの発表表示。先頭／現在のページから開始し、前後・Home/End・クリック・スワイプで移動する。先頭・末尾では循環しない。Escape／終了で元の編集とフォーカスへ戻り、全画面も切り替えられる。発表中の操作で作品・履歴を変更しない。

常設の上部は1行のまま、挿入操作は「＋ 挿入」または狭い画面の「…」、図形の編集は選択ポップアップにまとめる。下絵は編集用ZIPへ保存するが、通常のSVG・PNG・PDF・ページ一覧・発表には含めない。「画像として出力に含める」を選んだ画像はすべてに含める。

直角線の自動経路は折れ曲がり点と端点の方向を結ぶもので、障害物・線・ラベルの衝突回避や図形全体の自動配置はしない。自己ループや込み入った経路は点を追加して調整する。ラベルの初期位置がほかの図形に重なる場合も手動で移動できる。部品は平坦なグループであり、配置後に部品集の変更を自動反映する「インスタンス」ではない。

## 保存形式と互換性

再編集用ファイルは `作品名.ilapo.zip`。中に `manifest.json` と `pages/<page-id>.svg` がある。

- 通常のパス・文字・埋め込み画像の正本は各SVG。manifestは文書・ページ情報と名前・グループ・固定・下絵フラグを補足し、パスデータや画像データを二重保存しない。
- 接続矢印はmanifestに接続先・端点・経路点・書式・ラベルを持ち、SVGには他アプリでも表示できる線・矢じり・文字へ展開した見た目を記録する。再編集用ZIPはmanifestの接続モデルを復元し、通常のSVG取り込みでは線と文字として取り込む。
- 形式名は `kaijo-ilapo`。従来のバージョン1を読み込め、画像・接続矢印を使った作品はバージョン2に移行する。古いアプリへ渡すときは通常のSVG等を使用する。ページと図形に安定したIDを持ち、文書、表示倍率・テーマ、選択状態を分ける。
- ZIPを展開すると各SVGを単独で持ち出せる。これは他アプリがイラポ独自の接続や将来のアニメーションを理解するという意味ではない。
- 座標はCSS pxの小数。mmは `96 / 25.4`、ptは `96 / 72` で換算。SVGの幅・高さはCSS pxで記載し、印刷寸法へ対応する。
- 取り込めるSVGは基本図形、パス、グループ、対応範囲の文字・tspanと変形、および埋め込みPNG/JPEG/WebP（preserveAspectRatio=none指定）の画像。ルートの寸法はpx/mm/cm/pt/in、viewBoxとの倍率差は中央配置または縦横独立の倍率で反映する。未対応の表現は黙って削除せず読み込みを断る。グラデーション・マスク・フィルター・外部参照・スクリプト・evenoddの塗り・任意フォント・文字部分ごとの色や大きさなどは対象外。詳細はSVG入出力のテストを参照。
- 破損・未対応データは文書を置き換える前に検証。文字列をHTMLやプログラムとして実行しない。
- ファイルは20MiBまで。ZIPは展開後の合計にも上限を設ける。最大100ページ、ページごと5000図形、文書全体10000図形。上限は動作の保証値ではなく入力の保護境界。
- 画像ファイルの取り込みは8MiB・1600万画素まで。画像1つのデータURLは5MiB、文書全体で12MiBまで。下絵も保存容量に数える。ブラウザの保存容量を超えた場合は作品を保持してローカル保存を案内する。ZIP内のSVGには復元用の下絵も含むので、下絵を除いた持ち出しには通常のSVG書き出しを使う。

ブラウザ保存キーは `kaijo-ilapo:auto` / `kaijo-ilapo:saved`。テーマ等は `kaijo-ilapo:settings`、ヘルプは `kaijo-ilapo:help`、部品集は `kaijo-ilapo:components`。部品集は作品ファイルとは別に保存し、配置済みの図形は部品集がなくても復元できる。別アプリの保存領域を使用しない。

ローカル自動保存は書き込みを許可したChromeの現在のセッションで利用する。明示保存とは別の保存先を選ぶ。保存処理を直列化し、停止・再開始をまたぐ古い保存、同一ファイルへの自動／明示保存、外部変更の検出に対応する。失敗時は作品を保持しブラウザ保存を継続する。保存ハンドルは永続化せず、次回起動で利用者が選び直す。

## 構成と開発担当

Codexが担当。担当外アプリは閲覧・レビューのみ。共通仕様は `../docs/README.md`（ローカル資料）、個別仕様はこの会話の決定を優先する。

| ファイル | 役割 |
|---|---|
| `core.js` | 文書、入力検証、図形、行列、履歴、ブラウザ保存 |
| `geometry.js` | Paper.jsによる境界とSVG出力の外接範囲 |
| `path-edit.js` | 点・ハンドル・角丸・連結・合体の幾何処理 |
| `path-ui.js` | 直接選択・点のポップアップ・吸着・編集プレビュー |
| `connectors.js` / `connector-ui.js` | 図形への接続・経路・矢じり・ラベルとその編集 |
| `assets.js` | 自作アイコン・部品集・ローカル画像の取り込み |
| `presentation.js` / `presentation.css` | 静止ページの発表表示・全画面・操作 |
| `export.js` | PNGとベクター印刷用ページ |
| `svg.js` | 安全なSVG表示・入出力、ZIPの保存・復元 |
| `local-autosave.js` | ローカル保存先・権限・外部変更・書き込み順序 |
| `editor.js` / `editor.css` / `index.html` | 操作・画面・表示設定 |
| `vendor/` | 固定版Paper.jsとfflate、ライセンスと入手元 |
| `../shared/help-panel.*` | 共通の非モーダルヘルプ（利用のみ） |

ランタイムにCDN・外部サービスへ接続しない。ビルド工程は不要。リポジトリをローカルHTTPサーバーで配信して `tools/ilapo/` を開く。

Chromeのヘッドレス実行で、作図・移動・拡大縮小・履歴、日本語の複数行・上付き下付き、色と書式、グループ・整列、複数ページ、18px/A4、実際のSVG/ZIPダウンロードと再読込、通常幅・736px・390px、ダーク・特大文字、キーボード・タッチを確認する。SVG専用回帰では合体・型抜き後のアンカー変更と保存、自由キャンバスの負座標、viewBoxの倍率と物理単位、太い線の切出し、未対応要素の拒否、保存前後の文書一致を確認する。

追加回帰では、複数点・片側ハンドル・ドラッグ取消、3つの角の同時丸め、合体した曲線の切断・連結・ZIP復元後の再編集、グリッド／ピクセル／パス吸着、Option解除、タッチでの点移動、Escapeとフォーカス復帰を確認する。幾何回帰は点数だけで判定せず、実際の接線・半径・曲線長・穴の面積・変形済みの最近点・保存前後の文書一致を確認する。

既存のil03・il11と参照済みの練習スライドをもとに、ナイフとフォーク（線の追加・アンカー移動・連結・角丸）、水滴（菱形の下3点の丸め）、ハート（2円の合体・下側の点を削除・両端連結・新しい点を下へ移動・肩を滑らかにする）の作例を検証用に生成・表示確認した。元スライドの画面や図版はアプリへ転載していない。ハートの曲線に接する肩は、半径指定ではなく滑らかな点とハンドルで整える。

PNGの18px・倍率・透明／白背景・日本語上付き下付き、負座標を含む自由範囲・選択範囲を画素で確認した。ChromeヘッドレスのPDFではA4＋JIS B5の2ページ、任意210×100mm、自由1280×720px、18pxの寸法とベクター／文字を確認した。印刷用iframeの後始末はafterprintイベントの模擬で検証し、ネイティブ印刷ダイアログでの設定操作は未確認。

実機確認と模擬確認を区別する。ローカル自動保存の失敗・外部変更・権限・世代管理は模擬ハンドルで検証。OSのファイル選択画面での操作、Illustrator等への持ち出し後の編集は未確認。Safariの実機確認は作成者の指示により省略する。

0.3のChrome回帰では、実際のドラッグで接続した矢印の追従、複数経路点の編集・取消・Undo、直角線の全区間と端点の向き、回転した図形への接続、繰り返し再計算の安定、コピー先への参照更新、ZIPの完全往復、SVGでの通常パス化、部品登録・挿入、PNG画像の元解像度保持と下絵の出力除外を確認する。発表の前後移動・Escape・フォーカス復帰・文書の保持、1280/736/390pxとタッチでの経路点移動も対象。全画面はChromeヘッドレスの実際のAPIで開始とEscapeでの終了を確認し、既存の全画面を勝手に終了しない境界は模擬APIでも検証する。
