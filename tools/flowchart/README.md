# フローチャートエディタ

情報科の授業で使う、フローチャート・アクティビティ図・状態遷移図の作図エディタ。構造式エディタの画面構成を基準に、部品の配置、接続、修正、保存、画像出力をまとめる。

2026-09-15に表示名を「図エディタ」から「フローチャートエディタ」へ変更し、本体を `tools/flowchart/` へ移した。旧 `tools/diagram/index.html` は移動用の入口とし、HTTPでは新URLへ転送する。ファイルを直接開いていた場合は、旧URLのブラウザ保存を書き出すボタンを表示して移行できるようにする。再編集ファイルの `.diagram.json` と文書形式は維持する。

## 開発担当・共通仕様

担当はCodexのフローチャートエディタ継続開発の会話（2026-09-15記録）。対象は `tools/flowchart/` とし、構造式・分子模型・論理回路など担当外のアプリは参照・レビューに留める。担当の変更は作成者の明示的な依頼に従う。共通仕様はローカル資料 `tools/docs/README.md` を参照し、このREADMEにはフローチャートエディタ固有の仕様と実装状況を記録する。

## 実行

静的ファイルだけで動作する。外部ライブラリ、ビルド、ログイン、サーバーへのデータ保存は不要。

利用・検証の基準はmacOSのGoogle Chromeとする。2026-09-15の作成者の指示により、Safariの実機確認は今後の完了条件に含めない。

リポジトリのルートで以下を実行し、表示されたURLの `/tools/flowchart/` を開く。

```sh
python3 -m http.server 8000
```

## 操作

- 上部は1行とし、ファイル操作・Undo/Redo・ツール・設定を置く。実際の幅が足りないときは「ツール」で開閉し、選択・画面移動・文字追加・貼り付け・図の種類・表示／操作設定をまとめる。貼り付けは未選択でも使える。左側は図形と線・矢印の部品パレットとする。
- 選択した部品への操作は、作図面上のポップアップにある「編集」「形」「書式」「色」「整列」「重なり」から使う。コピー・複製・削除・大きさをそろえる・書式コピー・グループ化・固定は「編集」。狭い画面ではメニューを画面内へ収め、項目が多い場合は内部をスクロールする。Escapeで閉じ、開いたボタンへフォーカスを戻す。
- 「重なり」の最前面・1つ前面・1つ背面・最背面で図形・枠なし文字の順序を変更する。複数選択・グループでは図形の相対順を保ち、1つ前面／背面は選択した連続部分と隣の非選択図形を入れ替える。担当領域→矢印→図形の基本層は維持し、矢印どうしの順序は変更しない。固定した部品を含む選択では変更できない。未選択の固定図形をまたいで、編集可能な図形を前後へ移すことはできる。
- 「重なり」→「重なった部品を選ぶ」で、背後の図形・文字・線もサムネイル付きの候補から選べる。候補は選択した部品それぞれの描画範囲（外接矩形）と重なるものを前面から表示し、離れたグループの間の空白を一括した範囲にはしない。長いラベルの範囲も含める。グループはまとめて選択し、「今の選択に追加」で複数選択できる。固定部品も選択可能。候補を選ぶ・閉じるだけでは文書や履歴を変更せず、Escape・閉じるで元の選択を保つ。
- 重なり順は既存の `nodes` 配列順で保存する（後ろの要素ほど前面）。コピー・部品セット・SVG／PNG・印刷も同じ順に描画し、保存形式の追加は不要。順序変更は1回のUndoで戻せ、端での操作は履歴を増やさない。自動経路・ラベル候補の計算順は描画順と分け、前面・背面への移動で矢印の経路やラベル位置が変わらないようにする。
- 部品を選び、作図面をクリックして配置する。部品ボタンでEnterを押すと画面中央へ配置できる。
- フローチャート・アクティビティ図では、「処理」を選んで線をクリックすると途中へ挿入できる。線を選択して「処理を挿入」を押す操作にも対応する。前後の接続をつなぎ直し、元のラベルを手前の線に残す。短い直線では後続の図形を動かして間隔を確保する。挿入とつなぎ直し・間隔調整は1回のUndoで戻せる。
- 折れ線では同じ経路上の近くの空いた位置に挿入し、角をまたぐ場合は入る辺・出る辺を合わせる。ラベルが図形に隠れる場合は近くへよける。置く余白がない場合は図を保持して案内を表示する。
- フローチャートの「分岐セット」は、条件・はい／いいえの処理・合流点を接続・グループ化済みの状態で配置する。まとめて移動・複製でき、文字はダブルクリックで個別に編集できる。部品ごとの形や配置を変えるときはグループを解除する。
- 文字はダブルクリック、または図形・矢印を選択してEnterで編集する。Enterで改行、Command/Ctrl＋Enterで確定、Escapeで取り消す。
- 文字を持つ図形を選び「書式」から、横の揃えを左・中央・右、縦の揃えを上・中央・下へ変更できる。横・縦の余白はそれぞれ0〜160で指定し、「標準に戻す」で中央揃えと標準余白へ戻す。線のラベルには適用しない。余白を増やしたときは文字が収まる大きさへ広げる。設定は書式コピー、再編集ファイル、部品セット、SVG・PNG・印刷へ保持する。
- 選択時の「形」にある「図形の形」で、配置済みの部品を別の形に変更できる。文字・色・接続・担当領域は保持し、中心を基準に形と文字に必要な大きさへ調整する。「状態（円）」「状態（角丸）」もここで切り替える。文字を表示しない丸や棒へ変えても、文字データは残る。
- 「矢印の形」で直線・直角・曲線、「矢じり」で終点・両端・なしを変更できる。自己ループは直角・曲線に対応する。接続先とラベルは保ち、別の線種へ変えた線の経路を計算し直す。同じ線種のままの線は手動調整を保つ。
- 図形・矢印とも複数選択して一括変更でき、1回のUndoで戻せる。異なる形が選ばれている場合は「複数の形」と表示する。
- 「グループ化」で選択した部品と、その図形同士をつなぐ線をまとめる。どの部品を選んでもグループ全体を選択し、移動・複製・整列時に相対位置を保つ。部品にTabでフォーカスしてEnterを押すと、その部品の文字を編集できる。複数グループは1つにまとめ直せる。入れ子にはしない。Command/Ctrl＋Gでグループ化、Shiftを加えると解除する。
- 「固定」で図形・線の移動、文字、書式、形、削除を防ぐ。担当領域は領域の編集バーから固定できる。固定した図形にも新しい線をつなげられる。固定済みの線は接続先の移動へ追従する。コピー・複製した部品は固定を解除したコピーになり、元の部品は保持する。
- 図形の端の丸から接続先へドラッグするか、始点・終点を順にクリックしてつなぐ。「接続先を選ぶ」からキーボードでも指定できる。
- 接続線の端でつなぎ直し、中央のひし形で経路を調整する。線のラベルは独立して移動できる。
- 直角の矢印を1本選び、「形」→「折れ曲がり点を編集…」で複数の点を編集できる。線上の「＋」を押すか、「追加」から線上を選ぶ。番号付きの点をドラッグし、「点」の番号で選び直す。「位置」ではX・Y座標を入力できる。最大32点で、指定点を順に通るように水平・垂直の補助線を描く。
- 点のドラッグはグリッド設定に従い、Option（Alt）で一時解除する。作図面にフォーカスして矢印キーで1、Shiftを加えると10ずつ移動する。「追加」の後のEnterは選択した点の次の区間へ追加する。「削除」またはDeleteは選んだ点だけを消す。最後の点を消すと自動経路へ戻る。「完了」またはEscapeで通常の選択へ戻る。ドラッグ途中のEscape・操作中断では移動を取り消す。
- 編集を開いただけでは保存データを変えない。最初に点を追加・変更するときは、その時点の自動経路・従来の手動経路の角も保持する。「経路を整える」または「位置」の「すべて解除して自動へ」で指定点を解除する。追加・移動・削除・解除はそれぞれ1回のUndoで戻せる。
- 点を持つ線の本体をドラッグすると、その線の指定点全体を移動する。接続先の図形を単独で移動した場合は指定点を元の位置に残し、端点が図形へ追従する。両側の図形・グループをまとめて動かすと指定点も一緒に移動する。反転・複製・コピー・担当領域の並べ替え・処理挿入・保存・画像出力でも指定点を保持する。曲線・直線の従来の調整操作は維持し、別の線種へ変更すると指定点を解除する。
- 直角の自動経路は他の図形を避ける。戻り線や自己ループも対象とし、接続位置は動かさない。手で経路を変えた線はそのまま保持し、「経路を整える」で自動に戻す。操作は1回のUndoで戻せる。
- 上部の「操作」にある「グリッド・接続点に吸着」をオンにすると、接続位置を辺の両端・中央・等分点にそろえる。同じ辺への接続が1本なら両端と中央、2本なら1/3・2/3、3本なら1/4・3/4も候補になる。一般には接続本数＋1で等分し、中央と両端を加える。作成・つなぎ直し中は候補点が表示される。
- 「整列ガイドに吸着」は、図形をドラッグするとき、画面内にある他の図形の端・中央へそろえてガイドを表示する。拡大率にかかわらず画面上の6px以内を候補とし、固定した図形にもそろえられる。複数選択・グループは図形全体の外枠を基準に動かし、内部の相対位置と手動経路を保つ。Option（Alt）を押している間は、移動時のグリッド・整列ガイドへの吸着を一時解除する。
- 「整列」→「つながり順に自動配置」は、選択した単純な接続の鎖を上下または左右へ並べる。現在の位置と適用後をプレビューで見比べ、間隔は0〜400で指定する。先頭の位置、グループ内の相対位置、所属、書式を保つ。経路を整える設定をオンにすると、単位間の矢印を進行方向の辺中央へつなぎ直して自動経路へ戻す。オフでは保存済みの接続と手動経路を保持し、同じ単位で動く内部経路だけを追従させる。分岐・合流・循環・非連結、固定した選択部品、担当領域外へ出る配置は文書を変えずに案内する。選択外の図形と重なる可能性は警告し、勝手には動かさない。キャンセルでは文書・履歴を変えず、適用は1回のUndoで戻せる。
- グリッド・接続点と整列ガイドは個別に切り替えられ、設定をブラウザに記憶する。整列ガイドのある方向はガイドを優先し、それ以外の方向はグリッド設定に従う。ガイドはドラッグ中だけ表示し、保存ファイル・画像・印刷には含めない。移動は1回のUndoで戻せ、Escapeやドラッグの中断では元の位置へ戻る。
- アクティビティ図は上部の「編集対象」で「担当領域」と「図形・線」を切り替えて編集する。初期のひな形は左右2領域。「＋ 担当領域を追加」で右側へ空の領域を追加し、そのまま名前を入力できる。最大50領域まで対応する。
- 領域を選び、「左へ」「右へ」で隣の領域と並べ替える。所属する図形と内部の線の手動経路も一緒に動く。領域間の接続先は維持し、領域間の線の手動経路は元の位置を保つ。グループ内の未接続端点は、同じ担当の部品と一緒に動く。
- 「領域を削除」は領域だけを削除し、中の図形・矢印・グループを元の位置に残す。所属を解除し、空いた場所を詰めない。追加・削除・並べ替えはそれぞれ1回のUndoで戻せる。固定された領域・図形を動かす操作や、複数の領域をまたぐグループの形を崩す並べ替えは、文書を保持して案内する。
- 幅は数値欄か右境界のドラッグで調整する。隣と接している境界では両方の幅を変え、隙間に面した境界や右端ではその領域だけの幅を変える。所属図形のための余白を保つ。「全領域の高さ」は領域の高さをまとめて変更する。長い領域名は見出し内へ折り返し・省略して表示し、保存データと名称入力欄には全文を保つ。
- Command/Ctrl＋ZでUndo、Shiftを加えてRedo。矢印キーで選択図形を移動できる。
- 再編集用の `.diagram.json` はファイルメニュー、SVG・PNGは右側の書き出しパネルから保存する。
- 右の「書き出し」で「図全体」「選択部分」を切り替え、プレビューを見ながら画像をコピー、PNG・SVGを保存できる。選択時の「編集」にある「選択部分を画像コピー」からも、選んだ部分をコピーできる。
- 表示設定のテーマは作図画面・線・文字にも反映する。「自動」はOSの変更に追従する。文書の色は変更せず、書き出しプレビュー・SVG・PNG・印刷は元の色で出力する。独自に塗りを設定した図形は、画面でもその塗り・線・文字色を維持する。

作図中の内容は、このブラウザへ自動保存する。明示保存と自動保存を区別し、起動時と「開く」で、どちらを読み込むか選ぶ。読込失敗時は現在の図を保持する。

### 保存・読み込み

ファイルメニューの「ブラウザ内に保存」「ファイルに保存…」で保存先を選ぶ。ブラウザ内の自動保存と明示保存は各1件を別々に保持し、編集しても明示保存の内容は変わらない。ファイルへの明示保存は `.diagram.json` をダウンロードする。Command/Ctrl＋Sは直近に使った保存先へ保存し、初期値はブラウザ内。保存先は表示設定とともに記憶する。

起動時に保存した図がある場合と、Command/Ctrl＋Oまたは「開く」では、候補を選んで読み込む。候補には文書名・保存日時・自動／明示・保存先を表示する。ローカルファイルは選択後に候補を表示し、内容を開く前に確認できる。このページからファイルへ保存した内容も、ページを閉じるまでは候補として参照できる。日時のない旧データは日時不明と表示する。

候補の閲覧・読み込みだけでは、選ばなかった自動保存・明示保存を書き換えない。読み込んだ図の編集を始めた時点で自動保存を更新する。起動時の選択を閉じたり、図を開かずにページを閉じたりしても以前の保存データは保持する。変更が残る図を置き換えるときは「保存して続ける」「置き換える」「キャンセル」を選ぶ。保存して続ける操作で保存に失敗した場合は、置き換えを中止する。

「自動保存…」から、対応する環境ではローカルへの自動保存も開始できる。ファイル選択と書き込み許可を利用者が行い、明示保存用とは別の専用ファイルを使う。新しい空ファイル、または同じ文書IDの有効な自動保存ファイルだけを選べる。明示保存したファイル、他の図、不正なファイルは上書きしない。ブラウザ内の自動保存も並行して続ける。

ローカルの書き込みは順番に処理し、書き込み中の編集は完了後に最新版を保存する。権限が失われた、外部でファイルが変更された、書き込みに失敗した場合は停止し、失敗を表示する。保存先の切り替えが失敗した場合もローカル自動保存は停止する。別の図を開く・新しく作る・ページを閉じる場合も停止し、ページの再読み込み後は保存先を選び直す。ローカル自動保存が使えない環境では、ブラウザ内の自動保存と明示的なファイル保存を使う。

ブラウザ自動保存は旧キー `kaijo.diagram.recovery.v1`、明示保存は `kaijo.diagram.saved.v1` を使う。旧復元データは削除せずに検証して候補へ表示する。同じ文書の有効な旧 `saved` がある場合は「保存時の内容（旧形式）」も選べる。ファイルの文書形式は `kaijo-diagram` バージョン3とし、保存方法・日時を `saveInfo` に追加する。文書を読み込むときには保存管理の情報を作図データから分離し、バージョン1・2の旧ファイルも読み込める。

吸着候補の本数は同じ辺に付く始点・終点を合わせて数える。新しい線は追加後の本数、つなぎ直し中の端点は二重に数えず、自己ループの両端はそれぞれ数える。手動で指定した接続位置はほかの線の追加・削除で動かさず、再調整したときに吸着する。「グリッド・接続点に吸着」をオフにすれば辺上の任意の位置へ接続できる。接続位置は辺上の割合で保存し、図形の移動や大きさの変更へ追従する。

### 色のパレット・RGB指定

選択時の「色」で塗り・線色・文字色を切り替え、18色の定型色から選ぶ。構造式エディタの基本色を参考に、図の塗りに使いやすい淡色も用意する。現在の色はチェック印と枠で示し、複数の色が混在する場合はその旨を表示する。定型色にない色も、従来のカラーピッカーとR・G・B各0〜255の数値入力から指定できる。数値は「RGB値を適用」または入力欄のEnterで確定し、空欄・範囲外・整数でない値では適用しない。

複数選択・グループへ一括適用でき、塗りは図形にだけ適用する。固定した部品を含む選択は変更しない。1回の色変更を1回のUndoで戻し、同じ色の再選択や変更対象の切り替えでは履歴を増やさない。文書の色を変更するため、JSON・SVG・PNG・印刷にも反映する。表示テーマの切り替えは文書の色を変えない。

### マイ部品・部品セットの再利用

図形や矢印を選択して「編集」→「部品セットとして登録…」から、名前・任意のカテゴリ（40文字以内）とプレビューを確認して登録する。左側の「マイ部品」から一覧・プレビューを開き、配置・名前・カテゴリの変更、削除・ファイル保存ができる。「配置する」の後に作図面をクリックするとその位置へ、Enterでは画面中央へ配置する。Escapeで中止でき、配置全体を1回のUndoで戻せる。

一覧は名前とカテゴリをNFKC正規化した空白区切りのAND検索で絞り込み、カテゴリごと（未分類を含む）にも絞り込める。表示順は手動順・名前順・更新順から選び、手動順で絞り込みがないときは上／下で隣と入れ替える。検索・絞り込み・並べ替えだけでは部品セットや更新日時を変更しない。

配置前には、作図面上に半透明の部品セットと点線の範囲を表示する。ポインターに追従して、吸着と表示倍率を反映した実際の配置位置を確認できる。上部の「中央に配置」「中止」はキーボードとタッチでも使える。配置中のTabは元の図形を飛ばして配置ボタンへ進み、矢印キーやDeleteで元の選択を変更しない。中止すると元の選択へ戻り、文書・Undo・保存内容を保持する。プレビューは保存・画像・印刷に含めない。

マイ部品と印刷のダイアログは見出しと下部の操作を固定し、長い内容は内部でスクロールする。特大文字や狭い画面でも「閉じる」「印刷する…」へ移動できる。「このセットをファイルに保存」は選択した1セットのファイル書き出しを示す。

セットには選んだ図形・線、内部の接続線とグループ、文字・色・書式・接続位置・手動の経路点を保持する。選択外の図形へ接続している線を含めた場合は、外形上の接続位置を未接続の端点として残す。担当領域と問題文は含めない。配置した部品は新しいIDを持つ編集可能なコピーとなり、配置先の担当領域へ割り当てる。セットや原図の編集内容と配置済みのコピーは独立する。

部品セットの登録・名前変更・削除・ファイル取り込みは、文書のUndoや保存状態を変更せず、マイ部品のブラウザ自動保存を更新する。「ブラウザ内に保存」は別の明示保存を更新する。初めてマイ部品を使うときと「保存内容を選ぶ…」では自動／明示を日時・件数から選ぶ。候補の閲覧・キャンセル・読み込みだけでは、どちらの保存内容も書き換えない。保存に失敗した内容は画面に保持して案内し、ファイルへ保存できる。

ファイル形式は `.flowparts.json`（`kaijo-flowchart-parts` バージョン1）。選んだ1セットと一覧全体を書き出せる。ファイル読み込みは検証後に現在の一覧へ追加し、同じIDは新しく付け直し、同じ名前には番号を付ける。不正なファイルや容量超過では一覧全体を保持する。最大100セット・合計2MB、1セット内は図形と線を合わせて1000個まで。ブラウザのキーは `kaijo.flowchart.parts.auto.v1` と `kaijo.flowchart.parts.saved.v1`。既存の auto／manual／browser／local の保存内容との互換を維持する。通常の図の保存とは独立し、マイ部品を開くまで読み込まない。

### 出力寸法・余白・印刷配置

書き出しパネルの「PNGの寸法」で、従来の1・2・4倍か、幅／高さの画素数を指定する。幅・高さは余白を含み、反対側は縦横比を保って整数の画素数へ切り下げる。1辺8192px・3200万画素を超える指定は、縦横比を保って縮小し、実際の寸法と調整した旨を表示する。空欄・不正値の間は出力を止める。PNGの寸法指定はSVGの自然な寸法を変えず、SVGは拡大しても画質を保つ。

「画像の余白」は上・右・下・左を0〜1000で指定する。単位は1倍時のpxで、PNGでは図と同じ倍率で拡大する。SVGと画像コピーにも同じ余白を使い、背景の白／透明も従来どおり選べる。画像生成中の変更は開始時の画像へ混ぜない。画像設定はブラウザの表示設定へ記憶し、図の保存データ・Undo履歴は変えない。

印刷プレビューでは「用紙に合わせる」か「幅を指定」を選び、幅を1〜1000mmで指定できる。図の幅は図の周囲の余白を含むSVG全体の幅で、左右・上下の3段階の配置を指定する。タイトル・氏名欄・問題文を置いた後の領域へ収め、指定幅が用紙へ入らない場合は縮小して実際の寸法を表示する。画面のプレビューと印刷DOMを同じ寸法・配置にし、ブラウザの通常の印刷でも反映する。入力が不正なまま通常の印刷を開始した場合は直前の有効な設定で現在の図を作り直す。氏名欄の有無、A4／JIS B5・縦横・長い問題文のページ分割を維持する。

### 大きさをそろえる・書式のコピー

図形を2つ以上選び、選択時の「編集」→「大きさをそろえる…」で基準の図形と「幅」「高さ」「幅と高さ」を選ぶ。最初に選択した図形を基準の初期値とし、一覧から変更できる。各図形の中心を保って寸法をそろえ、接続先・接続位置の割合・ラベル・手動経路のデータは保持する。矢印の端点は変更した外形へ追従する。グループは解除せず、内部の図形それぞれの寸法をそろえる。

円形の状態は幅か高さに合わせて縦横を同じにする。幅と高さが異なる基準で円形の状態に「幅と高さ」を指定すると、変更せず寸法の選び直しを案内する。固定した図形は基準として使えるが、それ以外の対象に固定された図形が含まれる場合は変更しない。すでにそろっている場合も変更・履歴を増やさない。文字に合わせた自動拡大は行わない。

「書式をコピー」は1つの図形・矢印の書式を、このページ内の専用クリップボードへ保持する。複数選択やグループの場合は、ダイアログでコピー元の部品を選ぶ。別の部品を選び「書式を貼り付け」でまとめて適用できる。共通項目は文字の大きさ・太字・文字色、線色・線幅・破線。塗りの色は図形から図形への貼り付けだけに適用する。形状・寸法・文字の内容・接続・矢じり・経路・ラベル位置・担当領域・グループは維持する。文字が収まらない場合は「書式」の「文字に大きさを合わせる」で調整できる。

固定された部品もコピー元にできる。貼り付け先に固定された部品が含まれる場合は全体を変更しない。サイズ変更・書式貼り付けは、それぞれ1回のUndoで戻せる。コピー自体は履歴・保存状態を変更しない。通常の部品コピーや画像コピーとは独立し、コピー元を編集・削除した後や別のファイルを開いた後も繰り返し使える。書式クリップボードは保存データへ含めず、ページを再読み込みすると消える。

### 画像のコピー・選択部分の書き出し

書き出しパネルの初期範囲は「図全体」。新しい図・別のファイルを開くと図全体に戻す。「選択部分」のまま選択を解除した場合は案内を表示し、コピー・PNG・SVGのボタンを無効にする。選択がないことを理由に図全体へ自動で切り替えない。

選択した図形と、その図形同士をつなぐ矢印を出力する。グループは全体を含め、矢印だけを選んだ場合も出力できる。担当領域の編集で領域を選ぶと、領域・所属する図形・内部の線を含める。所属する部品が領域をまたぐグループの一部なら、そのグループ全体を含める。選択外の担当領域の見出しは含めない。

選択した線の接続位置、直角線の障害物回避、複数の曲線の間隔、自己ループ、手動経路・ラベル位置は、元の図全体を基準に計算する。選択外の図形を画像から除いても経路を変えない。選択枠、固定の印、整列ガイド、トレースの強調表示は画像へ入れない。選択部分の保存名には `_選択部分` を付ける。再編集ファイルと印刷は引き続き図全体を使う。

コピーする画像はPNG。PNG保存と同じ白／透明背景・1倍／2倍／4倍の設定を使い、プレビューにPNGの画素数を表示する。SVGは倍率に依存しない。透明背景のプレビューは市松模様で示す。画面がダークでも文書本来の色で出力する。PNGは1辺8192px・3200万画素を上限として必要に応じて解像度を下げ、表示と出力寸法を合わせる。

画像の生成を始めた時点の図・選択・名前・背景・解像度を保持し、生成中の編集で画像を変えない。生成中は画像ボタンを無効にして重複処理を防ぐ。画像コピー非対応や拒否の場合は、作成した同じPNGを保存するボタンを表示する。勝手にファイル保存は始めない。案内の「閉じる」・Escapeで元の操作ボタンへ戻る。画像コピーは文書の保存状態・Undo/Redo・エディタ内の部品コピーに影響させない。通常のCommand/Ctrl＋Cは再編集用の部品コピーのままとする。

実装ではPNG化を共通化し、画像を作るPromiseを`ClipboardItem`へ渡して、クリック中に`clipboard.write`を呼ぶ。画像の読込完了を待ってから呼び出さない。[WebKitのAsync Clipboard APIの説明](https://webkit.org/blog/10855/async-clipboard-api/)と[非同期処理後の書込に関するWebKitの記録](https://bugs.webkit.org/show_bug.cgi?id=222262)を参照。

### 授業支援機能の保留

作図機能を優先するため、右側の「授業」パネルと関連する使い方の説明は一時的に非表示にしている。既存ファイルの問題文・固定・生徒用の設定は読込・保存時に保持する。問題文付きの図では上部の案内から問題文をダイアログで閲覧でき、印刷にも利用できる。作図用のひな形、手動トレース、図の点検、印刷は引き続き利用できる。

以下の授業用ひな形の仕様は内部に保持しているが、通常の画面から問題文の作成・変更、配付用保存、生徒画面の確認を開始する入口は表示しない。授業用機能の回帰テストだけが `data-lesson-tools="on"` を設定して検証する。

#### 保持している授業用ひな形の仕様

右の「授業」で問題文を入力して保存し、編集させない図形・線・担当領域を固定する。「生徒の画面で確認」では元の文書・編集履歴を退避したコピーを操作する。「確認を終了」で確認中の変更を破棄して元に戻す。確認中にページを閉じても、自動復元には元のひな形を残す。

「配付用ひな形を保存」は、生徒向けの編集画面で開く `.diagram.json` を書き出す。生徒は「ファイルを開く」から読み込み、問題文を確認して、固定されていない部品や新しく追加した部品を編集できる。完成した図は通常の「再編集ファイルを保存」で保存する。ひな形の作成者側の文書と保存状態は配付用の書き出しで置き換えない。

配付されたファイルも「ひな形を編集」で問題文や固定を変更できる。固定は授業中の誤操作を防ぐための仕組みで、認証・権限管理・解答の秘匿を行うものではない。問題文は文字データとして保存し、HTMLとして実行しない。

### 手動トレース

右の「トレース」で開始する図形を選ぶと、作図画面上部に進み方の候補が出る。分岐の条件や状態遷移のイベントは、生徒が考えて矢印を選ぶ。現在位置と通った経路を表示し、「1つ戻る」「最初から」で選び直せる。右パネルには操作履歴を表示する。

並列開始では各枝へ現在位置を分け、並列終了では各入力辺からの到着を待つ。枝は好きな順に確認できる。同じ辺から次の回の処理が先に到着しても、その到着を保持する。アクティビティ図の終了記号では全体を終了する。通常の行き止まりはその経路だけを終了する。

両端に矢じりがある線は両方向へ進める。矢じりのない線や接続先のない線は理由を表示し、その線へ進めない。並列開始の枝が欠けている場合も進行を止める。自己ループや反復をたどれ、1回のトレースは1000手までとする。

トレース中は編集用パレットを隠し、図の編集を止める。終了ボタンまたはEscapeで編集に戻る。履歴と強調表示はトレース中だけのもので、再編集ファイル・SVG・PNG・印刷には含めない。条件の自動評価、プログラムの実行、自動採点は行わない。

### 図の点検

右の「点検」に、文字が空の部品、接続先のない矢印、孤立した図形、分岐の空欄ラベルを見直し候補として表示する。フローチャート・アクティビティ図は判断から出る複数の枝、状態遷移図は状態から出る遷移の条件・きっかけを確認する。初期・終了の丸、並列の棒、合流・統合の記号には文字を要求しない。両方向の状態遷移は1本につき1候補にまとめる。矢じりのない自由線は未接続の候補に含めない。

候補を押すと該当箇所を選び、見える位置へ移動する。グループの部品なら従来どおりグループ全体を選ぶ。編集後は一覧を更新し、候補数を正誤判定や点数として扱わない。トレース中は候補を読めるが、選択への移動は終了後に行う。点検結果は保存データへ追加しない。

### 授業用の印刷

「印刷…」で印刷プレビューを開く。用紙はA4（210 × 297 mm）・JIS B5（182 × 257 mm）、向きは縦・横。「問題文を印刷」「氏名欄を印刷」を個別に切り替えられる。氏名欄は初期状態ではオフ。オンにすると最初のページへ学年・組・番号と氏名の空欄を付ける。問題文が未設定ならその切り替えは無効にする。

選択した用紙の実寸で文字を配置し、残りの領域へ図全体を収める。長い問題文は全文をページに分け、図を最後のページに置く。プレビューと印刷は同じ配置を使い、白い用紙と文書の色で出力する。問題文はHTMLとして実行しない。

用紙・向き・問題文・氏名欄の設定はブラウザの表示設定と一緒に記憶する。図の再編集ファイルには含めず、ブラウザの通常の印刷操作にも直前の設定を反映する。設定変更だけでは印刷を開始せず、「印刷する…」からブラウザの印刷画面を開く。

## 構成

| ファイル | 責務 |
|---|---|
| `index.html` / `editor.css` | 共通の画面、テーマ、文字サイズ、印刷 |
| `core.js` | 文書データ、ファイル検証、グループ・固定、サイズ統一・書式コピー、コピー・貼り付け、履歴、ひな形、トレース状態、図の点検 |
| `render.js` | SVG、接続位置と経路、文字配置、全体・選択部分の書き出し範囲、整列ガイドの計算、画面上のグループ・固定・トレース表示 |
| `parts.js` | 部品セットの検証・カテゴリ・検索／並べ替え・キャプチャ・プレビュー文書・配置・ファイル取り込み |
| `layout.js` | 接続の鎖を対象にした自動配置案、経路の追従・再設定、警告と原子性の検証 |
| `output.js` | 画像の四辺余白・画素数と上限、印刷の寸法と配置の計算 |
| `storage.js` | ブラウザの自動／明示保存、旧データの読み込み、ファイルの保存情報と検証 |
| `local-autosave.js` | 許可された専用ファイルへの自動保存、書き込みの順序・停止・競合検査 |
| `editor.js` | ポインター・キーボード・IME、選択、保存候補の選択、画像コピー・保存・印刷 |

`core.js` と `render.js` は、ブラウザとNode.jsの両方から使える。文書形式と表示・入力処理を分け、保存形式にバージョンを持たせる。

## 拡張の境界

作図機能は整列ガイド、画像のコピー・選択範囲の書き出し、大きさをそろえる・書式のコピーに加え、選択時ポップアップ・上部1行の共通UI、色パレット、自動／明示保存とブラウザ／ローカルを選べる保存・読み込み、直角の矢印の複数の折れ曲がり点、部品セットの保存・再利用、画像の寸法・四辺余白と印刷時の寸法・配置まで実装した。操作性の仕上げとして、部品セットの配置プレビュー・中止と、スクロールしても見出し・主要操作が見えるダイアログを追加した。さらに図形・文字の重なり順の変更と重なった部品の候補選択、文字の揃えと余白、マイ部品の検索・カテゴリ・並べ替え、単純な接続の鎖を対象にした自動配置を実装した。次の候補は分岐・反復を含む自動配置への拡張であり、授業支援機能の追加は保留する。

図形は見た目だけでなく、処理・判断・状態などの種類を持つ。接続先は図形ID、ラベルは矢印との関係、担当領域の所属は領域IDで保存する。自己ループ、逆方向・同方向の複数遷移、未接続の端点を保持できる。

図の種類の変更は部品パレットの変更に対応し、既存の図を削除・変換しない。図形全体の自動配置、実行・採点、共同編集は後続の範囲とする。ひな形は操作確認用に作成した独自の例で、教科書の問題・図版を複製しない。

接続経路は自動回避と手動調整に対応する。自動回避は直角の線が対象で、図形の外接矩形から通常12pxの余白を取り、隙間が狭い場合は4px・0pxまで縮める。担当領域は障害物に含めない。未調整のラベルも図形に隠れない近くの位置へ表示する。自動計算結果は描画時だけ使い、保存データを変更しない。探索量には上限があり、図形の重なりなどで通り道を確保できない場合は従来の経路を保持する。図形全体の自動配置や、すべての線・ラベル同士の重なり解消は含めない。

保存形式は `kaijo-diagram` のバージョン3で、複数の経路点・グループ・固定・問題文を保持する。バージョン1・2のファイルも読み込める。新しく保存するファイルは、複数点を知らない旧エディタが黙って点を捨てないようバージョン3にするため、旧エディタでは開けない。拡張子は `.diagram.json` を維持する。直角の線の `waypoints` は最大32点、曲線などの従来の単一調整は `bend` で保持し、両者の併用は拒否する。文書は2MB以内、図形と線は合計1000個以内。対応外の形式・サイズは現在の図を保持して読み込みを断る。文字や式をプログラムとして実行しない。
