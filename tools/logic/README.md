# 論理回路エディタ

tools/logic/index.html は論理回路を組み立て、入力・中間点・最終出力を確認する静的ツールです。旧 lc02.html はこのツールへ転送します。

## 現行仕様（0.6 BETA・2026-10-15）

- 上部は共通ファイルメニュー、Undo/Redo、複数選択、表示・整列、文書タブ、右端の設定・ヘルプの1行です。標準文字サイズ・マウス時は高さ41px、文字拡大・タッチ時は操作範囲を拡張します。アプリアイコンから一覧へ戻れます。テーマは自動・ライト・ダークのアイコンで選びます。
- 文書タブごとに回路・入力値・Undo/Redo・倍率・保存先・演習状態を保持します。新規作成と読み込みは新しいタブで開きます。未保存の文書を閉じるときは保存・破棄・キャンセルを選び、保存失敗時は閉じません。最大20文書を開けます。狭い画面はタブの横スクロールと一覧選択を使います。
- 起動時は直前の文書を表示し、保存候補の画面を自動表示しません。joho.logic-workspace.v1 に各文書の下書きと選択文書を保存します。Undo履歴・ローカルファイルの権限は再起動をまたいで復元しません。記録の破損・別ブラウザタブの更新を検出したら上書きを停止し、元データを保持します。
- 旧 joho.logic-circuits.v1 の名前付き保存（最大30件）と .logic.json を引き続き使えます。旧下書き joho.logic-draft.v1・切替前アーカイブは移行元として読み、上書き・削除しません。「ブラウザから開く…」で自動保存と明示保存の候補を選べます。
- ⌘/Ctrl+Sは文書ごとの前回の明示保存先へ保存します。初回は保存先を選びます。⌘/Ctrl+Oはローカルファイルの選択を開きます。Chrome等の対応環境では選択したローカルファイルへの明示保存・自動保存を利用でき、書込後に読み戻して確認します。自動保存と明示保存には別のファイルを使い、自動保存で明示保存済みとは扱いません。非対応環境はブラウザ内自動保存とダウンロードを使い、ダウンロードは利用者の確認後に保存済みとします。
- 左の「＋ 中間点」で P1、P2…を追加できます。入出力端子へ接続でき、選択した配線の「中間点を挿入」では、その配線だけを1回の編集として分割します。信号は変えません。接続した中間点は枝の終端にもでき、真理値表とコピーには入力→中間点→最終出力の順に列を追加します。循環・入力端子の二重接続は従来どおり拒否します。
- 真理値表の「演習」では、現在の回路の中間点・最終出力を全入力パターンについて0/1で埋めます。回路上の信号表示を隠し、判定は正誤と未入力数・得点を表示します。正解は「解答を見る」で別に表示し、修正・再判定を許可します。初回の全欄判定の得点はやり直すまで保持し、解答確認後の得点は練習用として区別します。回路の論理的な変更で問題・入力済み解答を更新します。位置移動だけでは解答を消しません。
- 演習の回答欄はCP21と同じ `LogicWidgets.createTruthAnswerControl` を使います。未入力の「−」で0/1を選び、入力後はクリック・タップで反転します。長押し・右クリックで0／未入力／1を選択でき、キーボードの0・1・Deleteでも入力・消去できます。
- 未接続端子と出力へ到達しないゲートの警告は、該当端子の点だけを警告色にして少し拡大します。外側の円や「!」は表示せず、詳しい内容は下部の接続状況の一覧と端子の読み上げで確認できます。
- 演習・表示設定は回路のUndoや .logic.json に混ぜません。演習中の真理値表コピーは自分の入力をコピーし、解答を確認していない欄へ正解を埋めません。これは端末内で行う自学用の採点であり、本人確認や正式提出の採点ではありません。
- 回路エンジン・描画・保存形式は ../../js/logic-*.js を共用し、中間点の追加UIは独立ツールだけで有効にします。CP21の既存演習UI・採点は維持します。SVG/PNGには中間点の名前と観測位置を含め、編集用の選択・診断マーカーは含めません。
- 右パネル・ヘルプ・表示設定は回路のUndo・未保存判定と分離します。ヘルプの共通部品は ../shared/help-panel.js、共通のファイルメニューは ../shared/file-menu.js・file-menu.css を使います。他アプリの稼働コードや教材台帳の掲載設定は変更しません。

.logic.json はバージョン1の既存構造に type: "probe" を加えます。旧ファイルはそのまま読み込めます。中間点を含む新ファイルを旧版エディタで開くことはできません。課題提出用の保護形式・本番連携は今回拡張・有効化しません。

検証の入口:

    node scripts/test-logic-workspace.mjs
    node scripts/test-logic-workspace-browser.mjs
    node scripts/test-logic-core.mjs
    node scripts/test-logic-applications.mjs
    node scripts/test-logic-editor.mjs
    node scripts/test-logic-editor-browser.mjs

ブラウザ検証は JOHO_TEST_URL で指定したローカルサーバーと一時プロファイルを使います。ChromeのOPFSへの実書込・読戻しと、OSの保存先選択ダイアログの実操作は別の検証です。Playwright WebKitでOPFSが利用できない環境ではFileSystemHandleの差替えで失敗・順序・分離を検査し、実ダウンロードも確認します。Safariアプリと物理タッチ端末の確認は区別します。

## ヘルプの共通化（0.4 BETA・2026-09-15）

決定事項・実装コミット・検証の記録は[開発記録](docs/DEVELOPMENT.md)にまとめています。

`tools/shared/help-panel.js`・`help-panel.css`を使用し、本文を8項目に整理しました。右パネルと同時表示でき、ヘルプ内のキーで回路を誤操作しません。保存などの確認はモーダルのままです。既存の作品ファイル・保存キー・編集処理は変更していません。他エディタ本体への適用は各担当の作業として残しています。Chrome・Playwright WebKitの検証と、Safariアプリ・実タッチ端末での確認は区別します。

## 課題提出への対応状況（2026-09-15）

[editor-lite v1](../shared/assignment-lite.md) の共通部品と `assignment.js` を組み込みました（0.5 BETA）。旧RSA試作は変更していません。`assignment-config.js` は **本番無効**・許可origin未設定です。URLだけで課題モードへ切り替わらず、通常起動では鍵を生成しません。

課題では確定編集だけを不正検知の参考情報として残します。普通の保存と隔離した暗号保存、保護ファイルの書出し・読込、許可された持込み、fm2への途中保存・正式提出の区別に対応します。実fm2画面のbridge・教員閲覧／復旧UI・GASとの実機検証は別作業で、有効化していません。fm2担当へのpayload・RPC・起動方式の引き継ぎは上記資料に記載しています。

追加の検証は `scripts/test-assignment-lite.mjs` と `scripts/test-assignment-lite-browser.mjs`。通常保存・自動復元・画像出力の回帰テストも引き続き行います。
