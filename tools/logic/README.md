# 論理回路エディタ

`tools/logic/index.html` は旧 `lc02.html` の自由編集機能を独立化した静的ツールです。旧URLは新しい場所への案内・転送のみです。

- 上部1行の保存・読み込み・履歴・表示設定、左の部品・整列、選択時だけの操作バー、右の真理値表・テンプレート・書き出し、下のヒントと倍率表示。
- `../../js/logic-*.js` の回路エンジン・描画・保存処理を共用します。CP21の組み立て演習は従来の埋め込みUIを使います。
- 保存キー `joho.logic-circuits.v1` と `.logic.json` の形式を変更していません。同一origin・同一ブラウザの旧保存データを利用できます。
- 表示設定・右パネルの幅と開閉状態は `joho.logic.ui.v1` へ保存し、回路のUndo・未保存判定とは分離します。幅は境界のドラッグ／左右キーで変更でき、狭い画面では収まる幅に制限します。
- 自動復元用の下書きは `joho.logic-draft.v1` へ別枠で保存します。確定した部品・配線・入力値を次回に復元し、名前付き保存・`.logic.json` の内容や未保存判定を変えません。ドラッグ途中・Undo履歴は復元しません。読取失敗時や別タブの更新を検出したときは自動保存を停止し、既存の下書きを保持します。
- ツールチップは即時ホバー／Tab移動に対応。⌘/Ctrl+S・Oで保存／読み込み、?でヘルプを開きます。入力欄・ダイアログ・操作途中では回路用ショートカットを動かしません。
- ダークモードは作図領域にも適用します。画像出力は従来どおり白背景です。
- 旧lc02の未掲載状態を維持し、目次・検索への公開設定は変更しません。

検証は `scripts/test-logic-tool-browser.mjs`、`scripts/test-logic-tool-usability-browser.mjs`、`scripts/test-logic-draft.mjs` と既存の回路エンジン・保存・配線テストを使用します。
