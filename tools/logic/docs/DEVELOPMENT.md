# 論理回路エディタ 開発記録

## 担当と範囲

論理回路エディタは、作成者の依頼に基づき本Codexスレッドで整備しています。他アプリの稼働コードは担当者へ引き継ぎます。共通部品は`tools/shared/`、共通仕様の正本はローカルの`tools/docs/README.md`です。

## 2026-09-15の決定事項

- ヘルプを読んだまま編集できる非モーダル小窓にする。
- 移動・サイズ変更・最小化と、項目・位置・本文スクロール位置の記憶に対応する。
- 目的別の短い手順と折りたたみの補足へ整理し、環境・利用上の注意・バージョン・学校名・Copyrightを残す。
- 右の真理値表・テンプレート・書き出しとは同時表示できるようにする。保存等の確認はモーダルのまま維持する。
- 操作・配置・設定保存を共通部品にし、本文・編集処理は各アプリが用意する。他エディタへの組み込みは各担当の別作業とする。

呼び出し方・UI契約・保存スキーマ・統合時の注意点は[共通ヘルプの実装資料](../../shared/help-panel.md)を参照してください。
