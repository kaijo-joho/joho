# 論理回路エディタ 開発記録

## 担当と範囲

論理回路エディタは、作成者の依頼に基づき本Codexスレッドで整備しています。他アプリの稼働コードは担当者へ引き継ぎます。共通部品は`tools/shared/`、共通仕様の正本はローカルの`tools/docs/README.md`です。

## 2026-09-15の決定事項

- ヘルプを読んだまま編集できる非モーダル小窓にする。
- 移動・サイズ変更・最小化と、項目・位置・本文スクロール位置の記憶に対応する。
- 目的別の短い手順と折りたたみの補足へ整理し、環境・利用上の注意・バージョン・学校名・Copyrightを残す。
- 右の真理値表・テンプレート・書き出しとは同時表示できるようにする。保存等の確認はモーダルのまま維持する。
- 操作・配置・設定保存を共通部品にし、本文・編集処理は各アプリが用意する。他エディタへの組み込みは各担当の別作業とする。

呼び出し方・UI契約・保存スキーマ・統合時の注意点は[共通ヘルプの実装資料](../../shared/help-panel.md)を参照してください。

## editor-lite v1（0.5 BETA・2026-09-15）

- 作成者の指示で、課題用の保護保存・確定編集の履歴・途中保存・提出前の全フォーム確認を実装。履歴は不正検知の参考情報とし、詳細な操作再生や本人制作の証明を目的にしない。
- 画面・ヘルプ・エラーの名称は「提出フォーム」に統一。内部のfm2識別子は変更しない。
- AES/HMAC・IDB・固定列挙bridge・課題クライアントを `tools/shared/assignment-lite*` へ分離。通常保存・下書き・アーカイブはそのまま維持する。
- 通常モードの作品・Undoを退避し、課題中は通常保存を停止。持込みは許可された課題でだけ行い、履歴に追記する。保護ファイルの読込・全消去・Undoも旧履歴を消さない。
- 応答喪失時は同じ内容・IDで再送。別タブの暗号保存を上書きしない。保存エラーでも暗号ファイルへの退避を可能にし、平文へ無言で切り替えない。
- **本番設定は無効。** 実提出フォームの画面bridge・教員UI・実GAS/学校アカウント・実際のSafariアプリでの確認は別作業。GASや他エディタのコード、本番設定・実生徒データを変更していない。
- 引き継ぎの詳細は [editor-lite実装資料](../../shared/assignment-lite.md)。ローカル共通仕様 `tools/docs/README.md` 4.4も更新した（公開対象には追加しない）。
