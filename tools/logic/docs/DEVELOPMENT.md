# 論理回路エディタ 開発記録

## 担当と範囲

論理回路エディタは、作成者の依頼に基づき本Codexスレッドで整備しています。他アプリの稼働コードは担当者へ引き継ぎます。共通部品は`tools/shared/`、共通仕様の正本はローカルの`tools/docs/README.md`です。

## 2026-10-15：タブからの名前変更

- 共通仕様4.5へタブからの文書名変更を追加し、論理回路エディタへ適用。選択中のタブに共通ファイルメニューと同じ鉛筆アイコンを置き、タブ名のダブルクリックとF2でも既存の名前変更画面を開く。
- タブが省略される狭い画面でも選べるよう、タブ一覧に「名前を変更…」を置く。一覧の選択値は現在の文書へ戻し、変更・キャンセル後は一覧へフォーカスを戻す。
- タブ切替・名前変更で既存のタブ要素を保持し、非選択タブのダブルクリックと変更・キャンセル後のフォーカス復帰を保つ。名前だけを変更し、文書ID・回路・履歴・倍率・保存先を維持する。タブ名・一覧・未保存表示・再開用記録を同期し、明示保存済みのデータは保存操作まで保持する。

検証結果:

- Chrome / Playwright WebKitで鉛筆・非選択タブのダブルクリック・F2・一覧・タップ、変更・キャンセル・空白入力、フォーカス復帰、再読み込み後の名前、他タブの回路・履歴と明示保存の保持が成功。27表示条件と既存の中間点・採点・ファイル保存・競合保護も成功。
- 回路コア57件、応用4回路、文書・中間点・採点の単体検証、構文・検索索引・差分チェックが成功。Safariアプリ・物理タッチ端末は未確認。

## 2026-10-15：共通UI・中間点・真理値表演習（0.6 BETA）

- 共通ファイルメニューを tools/shared/file-menu.js・file-menu.css に追加。他アプリへ一括適用しない。
- 文書タブと保存先・履歴・倍率・演習状態の分離、自動再開、保存失敗・別タブ更新・破損時の保持を documents.js にまとめる。旧保存は移行元として読み取り、削除・上書きしない。
- probe は入力1・出力1の透過部品。枝先の観測点も許可し、analysis.outputs の最終出力を維持して probes と columns を追加する。保存正規化・循環拒否・描画・画像・Undo・複製に共通エンジンを使う。追加UIは独立ツールだけで有効にする。
- truth-practice.js は回路から問題を作り、0/1・未入力・得点を判定する。再判定と初回得点を区別し、解答は別操作で表示する。信号表示と演習のコピーから意図せず正解を出さず、演習を回路の編集履歴に入れない。
- ローカル自動保存は明示保存とは別ファイル。文書ごとの保存を直列化し、保存結果は開始時の文書へ固定する。書込後は読戻しを照合し、失敗を保存済みと扱わない。
- 課題用の保護形式・本番無効設定・GAS側は維持する。中間点を課題提出用の保護形式へ追加する作業は含めない。

検証結果（2026-10-15）:

- 回路コア57件、応用4回路、配置・編集・保存・旧下書き・複数選択・拡張52パターン、新しい中間点・採点・文書保存の単体検証が成功。
- Chrome / Playwright WebKitで中間点の挿入と接続、循環拒否、中間点を含むSVG出力、演習の初回採点・修正・解答表示、文書別の履歴・倍率・保存先、自動再開、旧データ保持、競合・取消・書込失敗・容量不足時の保持が成功。
- 両ブラウザの27表示条件、タップ、既存の配線・複数出力・SVG/PNGの画素・寸法、CP21の既存UI、非モーダルヘルプの回帰が成功。WebKitでtouchのclickが生成されない条件を再現し、pointerupで一度だけ追加するよう修正した。
- ChromeのOPFSは実際の書込・読戻しで確認。WebKitのこの検証環境ではOPFSが利用できないため、FileSystemHandleの差替えによる順序・失敗・分離の検査と、実ダウンロードを区別した。OSの保存先選択、Safariアプリ、物理タッチ端末は未確認。

## editor-lite v1（0.5 BETA・2026-09-15）

- 作成者の指示で、課題用の保護保存・確定編集の履歴・途中保存・提出前の全フォーム確認を実装。履歴は不正検知の参考情報とし、詳細な操作再生や本人制作の証明を目的にしない。
- 画面・ヘルプ・エラーの名称は「提出フォーム」に統一。内部のfm2識別子は変更しない。
- AES/HMAC・IDB・固定列挙bridge・課題クライアントを `tools/shared/assignment-lite*` へ分離。通常保存・下書き・アーカイブはそのまま維持する。
- 通常モードの作品・Undoを退避し、課題中は通常保存を停止。持込みは許可された課題でだけ行い、履歴に追記する。保護ファイルの読込・全消去・Undoも旧履歴を消さない。
- 応答喪失時は同じ内容・IDで再送。別タブの暗号保存を上書きしない。保存エラーでも暗号ファイルへの退避を可能にし、平文へ無言で切り替えない。
- **本番設定は無効。** 実提出フォームの画面bridge・教員UI・実GAS/学校アカウント・実際のSafariアプリでの確認は別作業。GASや他エディタのコード、本番設定・実生徒データを変更していない。
- 引き継ぎの詳細は [editor-lite実装資料](../../shared/assignment-lite.md)。ローカル共通仕様 `tools/docs/README.md` 4.4も更新した（公開対象には追加しない）。

- fm2の純粋検証部を読み取り、合成作品のMAC・作品hash・全履歴prefixとの完全一致を確認。GAS/Drive/生徒データへの接続なし。
