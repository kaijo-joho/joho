回路の接続状況

項目を選ぶと、その端子や部品を回路上で確認できます。

    真理値表をコピー

    自動コピーが許可されませんでした。下の内容を選択し、⌘C（WindowsはCtrl+C）、または端末の「コピー」でコピーしてください。スプレッドシートへ貼り付けると、行・列に分かれます。

    表示設定

    テーマ

    部品を置く・変更する

    1. 左のAND・OR・NOTを、回路内へドラッグして置きます。クリック・Enterでも追加できます。
    2. 部品をドラッグして位置を調整します。
    3. 部品を選ぶと出る操作バーで、AND・ORの交換や削除ができます。
    入力・出力の追加と削除

    「＋ 入力」でC・Dを、「＋ 出力」でF₁・F₂…を増やせます。部品・入力・出力は、選択時の削除ボタン、近くの「×」、Deleteで削除します。最後の出力は残します。

    つなぐ・付け替える

    1. 出力端子（●）から入力端子（●）へドラッグします。端子を順にクリック、またはTab・Enterで選んでも接続できます。
    2. 付け替えは、配線を選び、左端・右端を別の端子へドラッグします。接続先の古い配線は置き換えます。
    3. 曲がり位置は、配線を選ぶと出るハンドルをドラッグします。矢印キーでも動かせます。
    配線の途中にNOTを挿入する

    配線を選び、操作バーの「NOTを挿入」を押すと、途中へNOTを追加して自動でつなぎ直します。分岐がある場合は選んだ1本だけが反転します。位置は後からドラッグで調整でき、1回のUndoで元に戻せます。

    分岐・曲がり位置の補足

    付け替えは、分岐があっても選んだ1本だけを変更します。ハンドル上ではShift＋矢印で大きく移動、Deleteで自動経路に戻せます。配線は水平・垂直で、同じ信号は途中で分岐し、分岐点だけに●を付けます。循環する回路や逆向き接続はできません。

    整列・複数選択

    1. 上部の表示・整列メニューから回路全体を並べます。配線がなるべく直線になる位置を優先します。
    2. 空白からの範囲ドラッグ、またはShift＋部品クリックで複数選択します。
    3. 選択時の操作バーからまとめて複製・削除できます。「配置」で端・中央・等間隔を揃えます。
    吸着・キーボード・タッチの操作

    移動中は中心・等間隔・配線が直線になる位置に吸着します。Alt（Option）で一時解除します。キーボードの複数選択は部品でShift＋Enter／Space。タッチでは上部の複数選択（狭い画面では「ツール」内）をオンにします。

    揃えるには2個以上、等間隔には3個以上を選びます。複製は選択内の配線も引き継ぎますが、選択外への配線は複製しません。

    真理値表・表示・接続の確認

    1. 右端の真理値表を開き、行を選ぶと入力値が切り替わります。入力の箱でも切り替えられます。
    2. 上部の表示・整列メニューの「0/1」で値・信号色の表示を切り替えます。実際の値は変わりません。
    3. 端子が警告色になったら、下部の接続状況を開きます。項目を選ぶと該当箇所へ移動します。
    画面の移動・倍率・右パネル

    右下で拡大縮小・全体表示。Space＋空白ドラッグで画面を移動します。タッチでは複数選択をオフにして空白をドラッグします。

    右端のタブで真理値表・テンプレート・書き出しを開閉します。右パネルの境界はドラッグ・左右キーで幅を調整できます。Shiftで大きく、Homeで最小、Endで最大、Enterで標準幅。開閉状態と幅は次回も引き継ぎます。

    真理値表をコピーする

    見出し横のコピーアイコンで、全行・全出力を見出し付きでコピーします。スプレッドシートへ貼り付けると行・列に分かれます。上部の0/1表示設定には影響されません。

    保存・読み込み

    タブの名前は、選択中のタブの鉛筆ボタン、タブ一覧の「名前を変更…」から変更できます。タブ名のダブルクリック、またはタブにフォーカスしてF2でも同じ画面を開けます。

    1. 上部のファイルメニューから、ブラウザまたはローカルファイル（.logic.json）へ保存します。⌘Sは文書ごとの前回の保存先を使い、初回は保存先を選びます。
    2. 「新規作成」「ブラウザから開く…」「ファイルから開く…」は新しい文書タブで開きます。⌘Oはファイル選択です。
    3. タブを閉じるときは未保存の変更を確認します。ファイルのダウンロードは、完了を確認してから保存済みにしてください。
    自動保存と再開について

    文書ごとの下書きをブラウザ内へ自動保存し、次回は直前の文書から再開します。保存候補は「ブラウザから開く…」で選べます。Undoの履歴やローカルファイルの権限は再起動後に引き継ぎません。

    「ファイルへの自動保存を開始…」では、対応するChrome等で保存先を選べます。最後の明示保存を残すため、自動保存には別のファイルを指定します。ブラウザ内への自動保存は同時に続けます。自動保存は明示保存とは別で、閲覧データを消すとブラウザの下書きも消えます。

    保存データの互換性

    旧lc02の名前付き保存と .logic.json を引き続き読み込めます。旧下書き・切替前アーカイブも読み込み候補として保持します。中間点を含むファイルは、この機能に対応したエディタで開いてください。

    課題モードの保存と提出（連携準備中）

    課題モードは現在、本番では有効になっていません。有効化後は、提出フォームから開いて開始を確認すると、作品と確定した編集・Undo/Redo・持込みの履歴を通常保存と分けて暗号保存します。選択・倍率・ドラッグ途中・キー入力は記録しません。

    「提出フォームへ途中保存」「提出へ進む」で作品・履歴・課題ID・登録鍵IDを提出フォームへ送信します。途中保存は正式提出ではなく、最後は提出フォームで確認・確定します。送信先と保管方針は開始画面で確認してください。端末内だけの未送信変更は、鍵を失うと復旧できません。教員に相談すると、最後に提出フォームへ保存した作品から復旧します。

    履歴は不正検知の参考情報であり、本人制作の証明ではありません。Macの製造番号や他サイトの閲覧履歴は取得しません。通常の作品を課題へ持ち込めるかは、課題ごとの設定に従います。画像出力はできますが、課題の提出は専用の手順を使ってください。

    中間点・真理値表の演習

    1. 左の「＋ 中間点」でP1、P2…を配置して端子へ接続します。または配線を選び、「中間点を挿入」を押します。中間点は信号を変えず、観測する場所を真理値表へ追加します。
    2. 右の真理値表で「演習」を選び、中間点と出力の各欄へ0か1を入力します。回路上の信号表示は演習中は隠れます。
    3. 「判定・採点」で正誤と得点を確認します。修正して再判定できます。最初の全欄判定の得点は「やり直す」まで保持します。

    「−」から0/1を選び、入力後はクリック・タップで反転します。長押し・右クリックでは0／未入力／1を選べます。キーボードの0・1で入力、Delete・Backspaceで消去、Escapeで選択肢を閉じられます。

    正解は「解答を見る」で確認します。確認後の判定は練習用です。タブごとに演習状態を保持しますが、回路の論理が変わると解答欄を更新します。位置移動だけでは消しません。正式提出の採点ではなく、端末内で行う自学用の機能です。

    SVG・PNGの書き出し

    1. 右端の書き出しパネルを開きます。このヘルプは開いたまま操作できます。
    2. SVG・PNG、ファイル名、白／透明背景を選びます。PNGは1・2・4倍を指定できます。
    3. 「書き出す」で画像を保存、または「PNG画像をコピー」で文書へ貼り付けます。
    画像に含めるもの・再編集

    0/1は上部の表示に従います。入出力は枠なしの点、分岐だけに●を付けます。画像からは再編集できません。編集を続ける場合は.logic.jsonも保存してください。

    ショートカット・ヘルプの操作

    Windowsは⌘をCtrlに読み替え
    ⌘S / ⌘O保存 / ファイルから開く
    ⌘Z / ⌘Shift Z元に戻す / やり直し
    Delete選択した部品・配線を削除
    Escapeドラッグを取り消す・選択解除
    ?ヘルプを開閉（最小化中は展開）
    ヘルプを移動・縮小する

    見出しをドラッグ・矢印キーで移動します。右下の角、右端、下端でサイズを変更できます。Shiftで大きく変更、Enterで標準位置。「−」で最小化、「×」で閉じます。狭い画面では下部に表示され、見出しの上下ドラッグ・上下キーで高さを変更します。

    「編集へ戻る」でヘルプを開いたまま回路へ移れます。ヘルプ内では回路用ショートカットを動かしません。Escapeは開いた補足を閉じ、補足外ならヘルプを閉じます。回路操作中のEscapeは操作の取消を優先します。ボタンの説明はホバー・Tabで表示されます。

    このアプリについて

    推奨環境
    macOS ＋ Google Chrome（最新版）。Safariなどほかのブラウザでは、表示や一部の機能（画像のコピーなど）が異なる場合があります。
    ご利用にあたって

    このアプリは情報科の学習・教材作成のための教育用ツールです。0と1による論理回路の動作を扱い、実際の回路の電圧や信号の遅延などは再現しません。表示や計算の正確さを保証するものではありません。

    通常モードで作成した回路は、お使いのブラウザ内、または利用者が選んだローカルファイルに保存され、外部には送信されません。ブラウザの閲覧データを削除すると保存内容も失われるため、大切な回路はローカルファイルにも保存してください。

    このアプリの著作権は海城中学高等学校に帰属します。改変・再配布はご遠慮ください。
