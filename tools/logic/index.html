論理回路エディタの使い方

1. 部品を置く・変更する

  • 左のAND・OR・NOTを回路内へドラッグして配置します。クリック・Enterでも追加できます。「＋ 入力」でC・Dを、「＋ 出力」でF₁・F₂…を増やせます。
  • 部品をドラッグして移動します。選択時に出る操作バーでAND・ORの交換や削除ができます。近くの「×」やDeleteでも削除できます。最後の出力は残します。

2. つなぐ・付け替える

配線を選び、操作バーの「NOTを挿入」を押すと、途中へNOTを追加して自動でつなぎ直します。分岐がある場合は選んだ1本だけが反転します。挿入位置は後からドラッグで調整でき、1回のUndoで元に戻せます。

  • 出力端子（●）から入力端子（●）へドラッグします。端子を順にクリック、またはTab・Enterで選んでも接続できます。
  • 配線を選び、左端・右端を別の端子へドラッグすると付け替えられます。接続先の古い配線は置き換えます。分岐があっても選んだ1本だけを変更します。
  • 配線を選ぶと曲がり位置のハンドルが出ます。ドラッグ・矢印キーで移動し、Shiftで大きく動かせます。ハンドル上でDeleteを押すと自動経路に戻ります。
  • 配線は水平・垂直です。同じ信号は途中で分岐し、分岐点だけに●を付けます。循環する回路や逆向き接続はできません。

3. 整列・表示・やり直し

  • 左の整列ボタンで配線がなるべく直線になるよう並べます。部品移動中は中心・等間隔・配線が直線になる位置に吸着します。Alt（Option）で一時解除します。
  • 入力の箱や真理値表の行を選ぶと入力値を切り替えられます。上部の「0/1」で値・信号色の表示を切り替えます。実際の値は変わりません。
  • 右端のタブで真理値表・テンプレート・書き出しを開閉できます。右下の倍率で拡大縮小し、「全体表示」で回路全体を表示します。空白をドラッグすると画面を移動できます。
  • ⌘Z：Undo、⌘Shift Z：Redo（WindowsはCtrl）。ドラッグ中のEscapeでキャンセルします。

右パネルの左端をドラッグすると幅を変えられます。境界へTabで移動し、左右キーでも調整できます（Shiftで大きく、Homeで最小、Endで最大、Enterで標準幅）。開閉状態と幅は次回も引き継ぎます。

4. 作業途中の自動復元

確定した編集を、このブラウザの下書きへ自動保存します。次に開くと前回の部品・配線・入力値を復元します。ドラッグ途中の位置やUndoの履歴は復元しません。

名前付き保存とは別の一時的な下書きです。複数の回路を残すには、保存アイコンから保存してください。全消去や読み込み後は、その状態が次の復元対象になります。閲覧データを消すと下書きも消え、別端末とは同期されません。

5. 保存・読み込み・書き出し

  • 上部の保存アイコンで、名前を付けてブラウザ（最大30件）またはローカルファイル（.logic.json）へ保存します。作りかけの回路も保存できます。
  • 読み込みアイコンで保存済み回路・ローカルファイル・テンプレートを選びます。全消去や別回路の読み込み前は、未保存の変更の保存を確認します。ファイル保存はダウンロードを確認してから続けてください。
  • ブラウザ保存は端末間で同期されず、閲覧データを削除すると失われます。旧lc02と同じサイト・同じブラウザなら、保存済みの回路を引き続き読み込めます。
  • 右の書き出しパネルでSVG・PNGを選びます。0/1の有無は上部の表示に従います。出力は白背景、入出力は枠なしの点です。画像から回路の再編集はできないので、続きの編集には.logic.jsonを使います。
  • 真理値表の見出し横のコピーアイコンで、全行・全出力を見出し付きでコピーできます。スプレッドシートへ貼り付けると行・列に分かれます。上部の0/1表示設定には影響されません。
