# HTMLエディタ 利用ガイド

## 1. 概要

HTML・CSSを編集し、プレビューで確認してMacのファイルへ保存するためのエディタです。このガイドは、教材と一緒に開くHTML実習の画面（0.11.4）を対象としています。

### できること

- 教材を読みながら実習ファイルを編集し、保存する。
- 画像・CSS・同じフォルダのページをプレビューで確認する。
- 保存済みの実習ファイルを提出し、正式な受領を確認する。
- 保存の失敗や内容の消失に備え、ブラウザの控えを手動で取り出す。

## 2. 利用条件

| 項目 | 内容 |
| --- | --- |
| 対応環境 | MacのGoogle Chromeを基本とします。導入課題HTML11のフォルダ・保存の準備確認には、直接上書き保存できるChromeを使います。Safari等の非対応環境では読取専用・ダウンロード保存になります。 |
| 必要なアカウント | 編集・プレビューは学校アカウントがなくても使えます。実習ファイルの取得・提出には自分の学校アカウントを使います。 |
| 対象となる利用モード | 現在公開中の、HTML実習ページと組み合わせて使う実習用画面。 |
| 利用を始める前の条件 | Macの［書類］に［HTML実習］フォルダを作成します。取得・提出の可否は課題の設定にもよります。 |

### op-start | 実習を始める

- 適用条件：実習用画面を開くとき

- 関連項目：tr-start

#### 手順

1. 授業で指定されたHTML実習の教材ページを開きます。
2. 赤い本人確認の案内が出たら［学校アカウントを確認する］、黄色いフォルダの案内が出たら［フォルダを接続…］に進みます。
3. 上部の［手順］で、その教材での取得・編集・保存・提出の流れを確かめます。解説だけを開いている場合は、［実習ファイルと提出］の［エディタで開いて取得］から進みます。

#### 正常な結果

解説・編集・プレビューの領域と上部メニューが表示されます。起動時にファイルは自動で開きません。

#### 注意・データへの影響

教材を切り替えるには、解説内のナビゲーションか［設定］→［教材と課題］の［教材］を使います。1つの教材に複数の課題がある場合は、同じ場所の［学校の課題］で対象を確認できます。教材を切り替えても編集中のファイルは開いたままです。解説から別ページへ移動する際に未保存の確認が出たら、移動前に保存します。

#### 補足

編集画面を準備できない場合も、起動画面の解説や教材目次へのリンクから教材を読めます。別タブに作業内容が残っていれば、そのタブを残します。

### op-account | 学校アカウントを確認する

- 適用条件：実習ファイルを取得するとき、本人確認の警告が出ているとき。未保存の内容は先に退避し、提出処理を終えてから操作します。
- アプリ内ヘルプ：表示する
- 関連項目：tr-account

#### 手順

1. 右上の［⚠️未接続］を押してメニューを開きます。
2. ［学校アカウントを確認する］を押します。赤い警告の同名ボタンからも進めます。
3. 表示された学校アカウントの確認画面で、自分のアカウントか確認します。
4. 完了後、右上に自分の氏名が表示されるか確認します。氏名がない場合はユーザーIDを確認します。

#### 正常な結果

確認した氏名、氏名が取得できない場合はユーザーIDが表示され、未確認の赤い警告が消えます。

#### 注意・データへの影響

別の人の情報の場合は、編集中の内容をMacへ保存してから［利用するアカウントを変更］を使います。右上には、このブラウザで最後に確認した情報が表示されます。Google側でアカウントを切り替えた場合は、エディタでも確認し直します。確認の有効期間は90日です。期限切れの案内が出たらもう一度確認します。

#### 補足

学校用のChromeプロファイルで学校アカウントを使います。作り方は本人確認画面の［学校用プロファイルの作り方］で確認できます。ログイン画面が表示できない場合は、［表示・ログインで困ったとき］から同じプロファイルの別タブで学校アカウントにログインし、［本人確認画面だけを開き直す］を押します。ユーザーIDだけが表示される場合は、右上のメニューの［氏名を取得して再確認］を使えます。

### op-renew | 実習ファイルの確認情報を更新する

- 適用条件：提出時に、開いている実習ファイルの確認情報の更新を求められたとき
- アプリ内ヘルプ：表示する
- 関連項目：op-account、op-save、tr-submit

#### 手順

1. 対象の実習ファイルを開いたまま、右上の氏名・ユーザーIDのメニューから［開いている実習ファイルの確認情報を更新］を押します。
2. 実習ファイルを取得したときと同じ自分の学校アカウントで確認します。
3. 「本文を保持して確認情報を更新しました」と表示されたら、［保存］を押してMacの実習ファイルへ保存します。

#### 正常な結果

編集した本文を保持しながら、開いているファイルの確認情報が更新されます。保存後、もう一度提出を準備できます。

#### 注意・データへの影響

エディタの右上で学校アカウントを再確認しても、取得済みのファイルの確認情報は自動では更新されません。ファイルの先頭にある「本人用の配付情報（編集しない）」は、コード欄で書き換えたり削除したりせず、更新を求められたときに上記の操作を使います。

#### 補足

更新対象ではない、または自分のアカウントで確認しても進めない場合は、実習ファイルを保持して授業担当者へ相談します。

### op-folder | 保存先フォルダを接続する

- 適用条件：実習フォルダを接続または読み込むとき。対応したChromeでは直接上書き保存、非対応環境では読み取り専用です。
- アプリ内ヘルプ：表示する
- 関連項目：tr-file、tr-save

#### 手順

1. Finderで［書類］に［HTML実習］フォルダを作ります。
2. ［フォルダを接続…］または［設定］の［フォルダを接続・変更…］を押します。
3. ［HTML実習］フォルダを選びます。Chromeで利用許可が表示されたら確認します。

#### 正常な結果

対応したChromeでは、設定に保存先フォルダ名が表示されます。接続先はブラウザに記憶され、許可が続いていれば次回も自動接続します。ファイルは自動で開きません。読み取り専用の環境では必要なフォルダをその都度読み込み、上書き保存には使えません。

#### 注意・データへの影響

フォルダ選択の画面では、中のHTMLがグレー表示でも正常です。ファイルではなくフォルダを選択します。フォルダの名前だけで、書類内の絶対的な場所まで確認されたとは扱いません。接続を解除してもMacのファイルは残ります。

#### 補足

許可が切れている場合は、［設定］の［前回のフォルダへ再接続］を押します。前回のフォルダが応答しない場合は、同じメニューから［フォルダを接続・変更…］か［フォルダの接続を解除］を選べます。Chromeから継続して許可する選択肢が出た場合は、選ぶと次回の確認を減らせます。

### op-get | 実習ファイル・教材画像を取得する

- 適用条件：実習ファイルは学校アカウント確認済みで対象課題が取得可能なとき。教材画像は、その教材に画像の案内があるとき。
- アプリ内ヘルプ：表示する
- 関連項目：tr-get

#### 手順

1. 上部の［ダウンロード］を押します。対応したChromeでは先に［HTML実習］フォルダを接続します。
2. 実習ファイルは対象の［新しくダウンロード］を押します。1回で取得と保存を開始します。
3. 教材画像は、Finderで［HTML実習］の中に［images］を作り、対象画像の［imagesへ保存］を押します。解説の画像リンクからも保存画面を開けます。直接保存に対応していない場合は［画像をダウンロード］を使います。
4. 保存先とファイル名を確認します。通常のダウンロードを使う環境では、Finderで実習ファイルを［HTML実習］へ、画像をその中の［images］へ移動します。

#### 正常な結果

「保存しました」に続いて、保存先とファイル名が表示されたら、接続したフォルダへの保存を確認できます。通常のダウンロードではFinderでファイルが入った場所を確認します。

#### 注意・データへの影響

取り直したファイルで編集中の内容を上書きしないよう注意します。直接保存では同名の実習ファイルや画像を上書きしません。Chromeで接続・許可・保存に失敗した場合、自動で通常のダウンロードへ切り替わるわけではありません。取得済みの内容に［保存を再試行］が出た場合は、その案内に従います。取得だけでは提出されません。開いているファイルの内容は取得操作では変わりません。

#### 補足

途中の作業を再開するときは、［開く］で保存済みのファイルを選びます。同名のファイルを見つけた場合も、まず［開く］で内容を確認します。配付画面やログインで困った場合は［表示・ログインで困ったとき］から、学校用のChromeプロファイルと開き直し方を確認できます。取得や保存の結果が分からないときは、開いている配付画面で表示を確認します。

### op-open | 保存済みのファイルを開く

- 適用条件：作業を始める・再開するとき
- アプリ内ヘルプ：表示する
- 関連項目：tr-file、tr-recovery

#### 手順

1. ［開く］を押します。
2. OSのファイル選択で、保存済みのHTML・CSSを選びます。
3. 接続中は、そのフォルダ内のファイルを選びます。初回のフォルダ接続直後は、エディタ内の一覧から選べる場合もあります。

#### 正常な結果

選んだファイル名とコードが編集欄に表示されます。

#### 注意・データへの影響

未保存の内容がある場合は、切替前の確認を読み、［保存して開く］または［キャンセル］を選びます。編集中のファイルを今の内容のまま残したいときは、保存を確認してから切り替えます。

#### 補足

［開く］は⌘Oでも使えます。接続先を変えるには［設定］の［フォルダを接続・変更…］を使います。別の場所のファイルを読み込むだけなら、［設定］→［保存の補助操作］の［別の場所からファイルを開く…］を使えます。

### op-edit | コードを編集して表示を確認する

- 適用条件：課題でコードの編集が指定され、保存済みのHTMLまたはCSSを開いているとき
- アプリ内ヘルプ：表示する
- 関連項目：op-open、op-preview、op-hints、op-save

#### 手順

1. 解説と課題の指示を見ながら［編集］の欄でコードを書きます。改行・字下げ・閉じタグも自分で入力します。
2. ［プレビューを更新］（⌘Enter）を押して、現在のコードの表示を確認します。
3. ［保存］（⌘S）を押し、Macへの保存を確認します。

#### 正常な結果

プレビューで表示を確認でき、HTMLにtitleがあればプレビュー欄に題名も表示されます。保存するとファイル名の未保存の印が消えます。

#### 注意・データへの影響

ファイル先頭の「本人用の配付情報（編集しない）」はそのままにします。プレビューで表示を確認した後は、［保存］を押して編集内容をMacへ保存します。

#### 補足

導入課題のhtml11-01.htmlは、コードを編集せずに開いて保存します。プレビューがコードの修正を求めている場合は、まず自分で見直します。

### op-save | Macのファイルに保存する

- 適用条件：HTML・CSSの編集中
- アプリ内ヘルプ：表示する
- 関連項目：tr-save

#### 手順

1. 編集欄上部の［保存］または⌘Sを使います。
2. 保存先や上書きの確認が出た場合は、場所とファイル名を確認します。
3. ［Macのファイルに保存しました］と、表示されたファイル名を確認します。

#### 正常な結果

Macへの直接保存を確認した案内が出て、未保存の印が消えます。

#### 注意・データへの影響

未接続の場合は、直接保存に対応したChromeなら保存先フォルダを接続できます。直接保存に非対応の環境や読取専用の場合は上書きできません。画面内の保存方法の案内に従ってコピーをダウンロードし、Finderで保存先・内容・ファイル名を確認します。ダウンロード開始だけでは元ファイルへの上書きは確認できません。［保存］・⌘Sはプレビューも更新します。プレビューを更新するだけなら⌘Enterを使います。

#### 補足

Finderのファイルが別の操作で変わったと案内された場合は、［設定］→［保存の補助操作］→［編集中のファイルのコピーをダウンロード］で編集内容を確保し、Macにあるファイルの内容と見比べます。ダウンロードで名前に「(1)」などが付いた場合は、提出前に指定の名前と内容を確認します。

### op-restore | ブラウザの控えを取り出す

- 適用条件：Macのファイルだけでは作業内容を戻せないとき
- アプリ内ヘルプ：表示する
- 関連項目：tr-recovery

#### 手順

1. 現在の編集内容が残っていれば、［設定］→［保存の補助操作］→［編集中のファイルのコピーをダウンロード］などで先にコピーを確保します。
2. ［設定］から［復旧候補を開く…］を選びます。
3. ［自動保存］と［ファイル保存時］の区別、日時、ファイル名を見て候補を選びます。取り出した内容を確かめ、保存先を確認してMacへ保存します。

#### 正常な結果

選んだ控えの内容が編集欄に表示されます。候補を選ばず閉じれば現在の編集内容に戻れます。選ばなかった控えも残ります。

#### 注意・データへの影響

復旧した内容は、改めて保存するまでMacのファイルに反映されません。同じファイルの自動保存の控えは編集を止めた後に更新されます。ブラウザの変更やサイトデータの消去で、控えや接続先の記憶を失うことがあります。消去する前にMacに保存したファイルと復旧候補を確認します。

#### 補足

ブラウザの控えから取り出せるのは編集したコードです。授業の終わりにはMacへ保存し、画像も含めたフォルダ全体をバックアップします。

### op-display | 表示と列配置を調整する

- 適用条件：解説やコードが狭い・文字を読みづらいとき
- アプリ内ヘルプ：表示する
- 関連項目：op-preview

#### 手順

1. 列の境界をドラッグして幅を調整します。境界のクリックで左右のパネルを折りたためます。
2. ［表示］から解説・プレビューの開閉や列配置の初期化を行えます。
3. ［設定］の表示設定で文字サイズ・例文の折り返し・行間・テーマを変更します。［表示設定を初期値に戻す］で表示を戻せます。
4. 例文だけを読みやすくするときは、例文の上の文字の縮小・拡大、折り返し、拡大表示の操作を使います。

#### 正常な結果

編集内容を変えずに、列や文字の表示を調整できます。

#### 注意・データへの影響

狭い画面では［解説］［コード］［プレビュー］を切り替えます。列幅と開閉状態は、このブラウザに記憶されます。表示設定を戻しても、ファイルの内容や保存先は変わりません。

#### 補足

境界線にTabで移動すると、EnterまたはSpaceで開閉し、左右の矢印キーで幅を変更できます。解説を印刷するときは、［表示］→［解説を別タブで開く］からブラウザの印刷を使います。

### op-preview | プレビュー・画像・リンクを確認する

- 適用条件：HTML・CSSの表示を確かめるとき
- アプリ内ヘルプ：表示する
- 関連項目：tr-preview、tr-preview-assets

#### 手順

1. 画像・CSSを含むフォルダを接続または読み込みます。
2. プレビューの更新ボタンまたは⌘Enterを押します。
3. リンクや画像を確認します。別タブの作品プレビューも使えます。

#### 正常な結果

同じ実習フォルダにあるHTMLへのリンクはプレビュー内で移動します。プレビューの更新または保存をすると、編集中のファイルの表示に戻ります。外部サイトへのリンクは別タブで開きます。

#### 注意・データへの影響

接続したフォルダの素材は更新時に読み直します。読み取り専用で素材を変えた場合は、フォルダを選び直します。別タブの青いバーの［Finderで開く方法］から、実際のHTMLをブラウザで開く手順を確認できます。未保存の編集がある場合、Finderから開くのは最後に保存した内容です。

#### 補足

別ファイルのCSSで背景画像を指定する相対パスは、そのCSSの場所を基準にします。プレビューにはHTML/HTM/CSS各2MiB、フォルダ200ファイル・合計50MiB・深さ8までの上限があります。コードに書いたJavaScriptや外部の画像・CSS、CSSの@import・外部フォント、srcsetの切替などはプレビューできません。

### op-hints | エラー行のヒントを確認する

- 適用条件：プレビューがコード修正を求めているとき
- アプリ内ヘルプ：表示する
- 関連項目：tr-preview

#### 手順

1. まず自分でコードを見直します。
2. ［エラーを探す］を押し、確認画面を読みます。必要なら［ヒントを使う］を選びます。

| file | 残っている | - | guide | op-open |
| backup | ファイルがない、または保存内容が古い | ブラウザの控えを手動で確認します。 | guide | op-restore |
| other | 選択肢にない・文章で説明する | - | handoff | - |
| unknown | 分からない | - | handoff | - |
| unavailable | 今は確認できない | - | handoff | - |

#### ヘルプデスクへ進む条件

- 引継ぎ条件：選択肢に当てはまらない、確認できない、または操作案内で解決しない場合。
- 引継ぎ候補の項目ID・選択肢ID：tr-recoveryと、この表で選択した選択肢ID。op-項目の案内後に未解決の場合は、そのop-項目ID。
- ヘルプデスクで追加確認すること：使用ブラウザと、いま表示されている案内。必要に応じてファイル名・発生した操作・保存状況を確認します。氏名や配付情報をURLに入れません。

## 6. データの扱いと制限

| 項目 | 利用者に説明する内容 |
| --- | --- |
| データの保存先 | 実習ファイルの正本はMacの保存先フォルダです。 |
| 自動保存と明示的な保存 | ブラウザの控えとMacへの保存は別です。控えがあってもMacへ保存済みとは限りません。 |
| 作業再開・復元 | 通常は［開く］でMacのファイルを選びます。復旧候補は手動で選びます。 |
| 上書き・削除 | 保存先確認で上書きを選ぶとMacの同名ファイルを置き換えます。接続解除はフォルダ内のファイル削除ではありません。 |
| 提出・受領の確認 | ［提出を受け付けました］で正式な受領を確認します。★や確認待ちの表だけでは提出完了ではありません。 |
| 共有・公開 | 実習ファイルの提出は、作品をウェブ公開する操作ではありません。 |
| 外部へ送る情報と操作 | 学校アカウントの確認・実習ファイルの取得では学校用の画面と通信します。上部の［提出］を押すと保存確認済みのHTML本文を埋め込みフォームへ渡し、フォーム内の［提出する］で正式な提出を行います。対応する経路ではヒント利用履歴も送られます。通常のコード編集・プレビュー更新だけでは正式提出になりません。 |
| ヘルプから相談へ進むとき | 小窓から［相談へ進む］場合は、対象アプリと参照した案内の情報を相談フォームに渡します。自由記述や画像はフォームで必要なものだけ入力し、最後の［送信する］で相談を登録します。［別タブで相談する］では新しい入力欄が開きます。 |
| 利用上の制限 | 入力したJavaScriptや外部素材等にはプレビューの制限があります。ファイルをMacへ保存したこと、見た目を確認したこと、提出したことはそれぞれ確認します。 |
| 追加の確認が必要な場合 | 個別の受付条件や受領の調査は、表示された案内を確認し、授業担当者へ相談します。 |

案内を引き継げなかったと表示された場合は、相談フォームに困っていることを一言入力します。
