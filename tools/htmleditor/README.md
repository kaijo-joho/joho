# HTMLエディタ：ローカル採点への段階移行

2026-10-17。ローカルフォルダが正本であり、通常の保存をクラウド同期へ変更しない。

## 今回の稼働範囲

- フォルダへの書込み・読戻しが成功した固定HTMLを、提出モーダル上部で先に採点する。GASフォームは並行して開く。
- 採点結果は、スピナーと「保存した内容を採点しています…」を最低5秒表示してから出す。採点とGASフォームの準備は即時に始め、5秒を超えた採点へ追加の待機は入れない。モーダルを閉じると待機を解除し、途中で内容が変われば旧結果を出さない。
- 現行GASの生成済み採点器の実bytesと、14個の凍結基準・40個の雛形結合を再利用。旧版もその版の基準を使う。課題ごとに現在の基準へ付け替えない。
- Workerで解析し、HTML実行・外部リンク取得はしない。数値は内部に残すが、生徒には★／☆だけを表示する。`needs_review`には★を付けない。
- HTML11の受領項目は端末内では採点しない。未知の版、取得失敗、Worker非対応・時間切れ、手動選択・別タブは従来の提出・採点に戻る。
- 端末内の結果は未提出。既存GASの受領表示だけが現行の提出完了を確定する。受領済み履歴・原本・台帳・受付設定・鍵は変更しない。

採点器の由来は`html-normal-1.0.0-html-css-0.3.0-parse5-8.0.1-csstree-3.2.1`、source hashは`e83fb967aaefe2ec448ee30c415e832587f31598cd10a3ef7824bd0f33a8b22f`。生成物のSHA-256は`grading-assets.js`に固定し、読み込み時にも照合する。ライセンスは`grading/LICENSES.txt`。公開カタログへDrive ID・保存先ID・鍵・本人情報を含めない。

## プレビューのリンク移動（0.9.1）

同じ実習フォルダ内のHTMLへのリンクは、プレビュー内だけで読む。編集対象・未保存内容・保存先・教材・ヒント対象は変更せず、リンク先の相対画像/CSS/次のリンクはそのファイルを基準にする。「更新」や保存で編集中ファイルのプレビューへ戻る。リンク先のエラーはプレビュー内で案内し、編集元の行番号へ付けない。読取失敗は元の表示を残し、更新・フォルダ変更後の古い応答は無視する。外部のHTTP(S)リンクは従来どおり別タブへ開き、入力HTMLのスクリプト実行や親画面への遷移は許可しない。

## 保存競合・復旧用の控え（0.9.2）

通常のファイル保存も、新規HTML・画像の保存と同じWeb Lockを使う。最新内容の読取り・競合確認・書込み・close後の読戻しを一つの排他範囲とし、後続タブでは先行保存を確認して上書きを止め、編集内容と未保存表示を保持する。保存先の確認画面ではロックせず、確認後に内容の変更・同名ファイルの追加・編集中文書や接続先の変更を再確認する。Web Locks非対応時は無保護で書かず、コピーのダウンロードを案内する。同一originの対応済みタブ間の保護であり、旧版タブ・別ブラウザ・OS側の同時編集を排他できる保証ではない。

復旧用のブラウザ保存に失敗した場合は、黄色い警告を編集領域の上に残す。同じ失敗のトーストは重複させず、控えの保存に成功したときに警告を解除する。Macへの保存成功と控えの保存失敗は別に表示し、ブラウザ保存だけでMacの保存済み判定を変更しない。既存の控えを削除せず、起動時の自動復元は行わない。

## 配付と提出の責務（2026-10-18確認）

現行v3の方式を維持する。学校アカウントの本人確認情報（有効期間90日）と公開manifest・原本から、実習ファイルをブラウザ内で生成する。取得のたびにGSSの対象学年・開始日時・受付状態を照会する方式には戻さず、開始前の先行取得を許容する。開始日時はHTMLファイルの取得を厳密に禁止する境界ではない。公開済みの原本は、画面のリンクを隠すだけでは秘匿できない。

ファイル取得と提出受付は別に扱う。既存の提出GASでGoogle本人確認・対象学年・受付状態・期限・採用版等を検査し、原本を取得できたことだけで提出可能とは扱わない。Colab/GSSの配付、課題一覧の条件、旧HTMLの経路・既配付ファイル・受領履歴は変更しない。この確認は文書の整合化であり、コード・GAS/GSS設定・受付条件を変更するものではない。

## 新しい受付の接続前候補

`intake-client.js`と[`scripts/html-intake-gas`](../../scripts/html-intake-gas/README.md)は接続前の候補。`index.html`は新クライアントを読み込まない。GAS入口も既定で無効であり、設定フラグだけでは動かない。

新方式では、同じ要求IDの固定本文・採点結果を本人GSSと署名付きoutboxの両方へ読戻し確認してから受領を表示する。教員GSSへは後から転記する。本文・受領時刻・版・全再提出履歴を残し、失敗は同じIDで照会・再開する。署名は受領後の改変検出であり、本人による制作やブラウザ採点の真正性を証明するものではない。

指定2アカウントだけの準備が承認され、専用GASと2名分の試験GSSを作成した。教員所有/本人のみ編集/再共有禁止/固定保護/世代/容量、受付GASへの無効状態の登録まで実確認済み。試験GSSは既存フォルダの他教員共有を継承させず、教員のマイドライブへ置き、通常台帳とPython試用は変更しない。distのHTML用接続証明・課題/版認可・提出bridge・旧gradeと競合しない転記窓口は未接続。ここを完了・確認するまでは、現行フォームを切り替えない。生徒アカウントと40名の学校実機検証も未実施。端末内の★が速くなっても、現行GASの受付時間が短くなったと報告しない。

## 再生成と検証

`scripts/export-html-local-grading.mjs`へ、私有の読取り済み結合/凍結JSON・検証済みGAS生成器・依存ライセンスのディレクトリを明示して生成する。秘密情報を含む入力をリポジトリへ置かない。新しい版を既存キーへ上書きする場合は、旧クライアントが残ることを考慮し、別URL・別hashでの追加を基本にする。

```sh
node --test tools/htmleditor/tests/*.test.cjs scripts/html-intake-gas/tests/*.test.mjs
git diff --check
```

採点器は全40結合に対して空欄・編集例・構造エラーを旧エンジン入口と比較する。合成試験は実生徒の認証・OAuth・GSS待ち時間・同時実行上限の証明にはしない。公開時はPages成功後に変更した公開bytesを照合する。復旧は今回のコミットのrevertと再公開で行い、個別GSSや過去の提出を削除しない。
