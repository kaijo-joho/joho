# 線分による領域（2026-09-16、0.4.0）

今回の範囲は、共有点で接続した線分の閉じた輪郭から、単純多角形の領域を作る機能。関数と軸・2関数の間の領域、積分、穴のある領域、自己交差した多角形は次段階とし、今回の面積と混同しない。

## 操作

- 「点・線分・文字」の＋から「領域」を開き、境界に使う線分を選ぶ。線分の並び順や向きは問わない。同じ座標の別の点は接続と見なさず、端点の共有を使う。
- 閉じた接続成分が1つなら、その線分を自動選択する。線分を選択中なら、その線分を含む閉じた成分を優先する。枝分かれ等がある場合は必要な境界だけを手動で選ぶ。
- 作成ダイアログに面積または問題の理由を表示する。領域の新規作成・境界の変更は、有効な単純多角形になってから確定する。
- 選択時に基本色・不透明度・面積の表示切り替えを常設する。色の追加パレット、RGB・自由な色、名前・文字位置は既存の開閉メニュー／詳細ダイアログを使う。境界の線幅・線種・色は元の線分側で編集する。
- 領域内部のクリックで選択できる。線・点との重なりではそれらの選択を優先する。名前・面積は1つのラベルとして配置・ドラッグし、面積を消しても左一覧で値を確認できる。
- 頂点の移動・係数の変更に塗りつぶしと面積が追従する。操作途中に自己交差・退化・未定義となったときは領域だけを非描画にし、理由を表示する。元の参照を保持するため、値を戻すかUndoすれば復元する。

## 文書と計算

- `kaijo-graph` version 5。version 1〜4の元データを保持して移行する。旧versionの文書に新しいregion注釈が混入した場合は拒否する。保存キーは変えない。
- 注釈 `region` は共通のid/name/visible/style/labelに加え、`segmentIds`（重複のない既存線分IDを3〜100個）と `showArea` を持つ。点や計算済み座標を複製しない。
- style.color/opacityは塗りつぶしの色と不透明度。既存注釈と同じstyleのwidth/dashを保持するが、輪郭は元の線分の書式を使う。既定色は青、不透明度0.25、面積表示はオン。
- `regions.js` に接続の追跡、単純多角形の検査、面積、内部のラベル位置、包含判定、面積の表示文字列を分離。`annotations.js` が既存の点・接線交点の評価結果を渡す。
- 面積は軸の実座標値から求める非負の幾何面積。対数目盛の画面上の面積ではない。両軸に単位があるときはその積を添え、単位の換算や補完はしない。表示は8桁の有効数字へ丸め、文書の式・座標精度は維持する。
- 自己交差、辺の重なり、重複頂点、零面積、非有限座標、対数軸の非正座標は塗りつぶしと面積表示を行わない。凹多角形に対応する。非常に細い領域等、数値的に区別できない形状は理由を表示する。
- 元の線分・点・系列の削除は依存する領域まで一括削除し、Undoで一括復元する。領域だけの削除は境界を残す。複製した領域は同じ境界を参照する。

## 描画・出力・検証

- 2Dで既存系列・線分・点の背面へ塗る。文字には塗りつぶしの不透明度を適用せず、可読性を保つ。3Dでは保持するが表示しない。
- JSON・自動／明示保存、PNG・SVG出力、全体表示に対応。テンプレート「三角形の領域と面積」で係数hと面積の連動を試せる。
- `regions.test.cjs`：接続、数値既知の面積、自己交差・凹多角形・大小の尺度、参照削除、履歴、保存移行。
- `region-plot.test.cjs`：描画順、透過、ラベル、表示切り替え、警告、3D保持。
- `regions-browser.test.cjs`：Chromeの作成、点のドラッグ、係数、書式、クリック選択、Undo、JSON／ブラウザ保存、画像出力、390px幅・ダーク・特大文字・タッチ・キーボード。
- 既存の系列・接線・交点・保存を含む単体テストとChromeの回帰テストを併用する。Safari実機確認は従来の指示どおり省略する。
