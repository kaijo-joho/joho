# 軸の目盛数値の位置

再編集用ファイルの `axes.x.labelPosition` と `axes.y.labelPosition` は、目盛数値の位置をそれぞれ指定する。

- `edge` は、横軸を描画領域の下、縦軸を左に表示する既定値である。
- `axis` は、横軸を `y=0`、縦軸を `x=0` の近くに表示する。相手側の軸が対数軸である場合、または 0 が表示範囲にない場合は `edge` と同じ位置へ自動的に戻す。

新規文書は両方とも `edge` で作成する。既存の version 10 保存ファイルでこの項目がない場合も、読み込み時には `edge` として扱う。保存形式は version 10 を維持し、値を保存するときは `edge` と `axis` 以外を受け付けない。

軸上の数値は利用者の `annotations` ではなく描画専用の装飾として生成する。そのため注釈の上限 100 件を使わず、画像書き出しにも含まれる。`tickLabels=false` では表示せず、`tickMarks`、分数・π 表記、指定した目盛間隔に従う。3D 表示は従来どおり描画領域の端に表示する。

対数軸では Plotly に目盛値そのもの（例: `1`, `10`, `100`）を渡し、数値用装飾だけを `log10` 座標へ変換する。これにより目盛線、グリッド、数値が同じ位置になる。1つの十進桁内に収まる狭い範囲では、読み取り用に 3〜6 個の値を選ぶ。

横軸・縦軸をともに軸上へ置くと、原点の数値が重ならないよう横軸側の 0 を省く。原点 `O` を表示する設定では、数値の 0 は表示しない。
