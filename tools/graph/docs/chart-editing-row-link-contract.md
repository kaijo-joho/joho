# 分析グラフの編集・数表と点の連動（0.9.0）

## 操作と範囲

- 分析グラフごとに軸名、単位、範囲、目盛り間隔・表記、色、点の大きさ、線幅、線種、凡例を保存する。範囲は両端を空欄で自動。箱ひげ図の横軸はカテゴリなので数値範囲・目盛り設定を持たない。単位は表示のみで値を換算しない。分析グラフの対数軸は今回の対象外。
- 色・線・凡例は選択ポップアップで変更し、全色は開閉式、RGBは詳細ダイアログに残す。軸設定は一覧の「︙」からも開く。複製は新しいIDを持ち、元の数表・回帰を参照したまま書式を独立して編集できる。
- 回帰付き散布図は回帰式、n、Pearson r、R²、RMSEを図中に表示でき、SVG・PNG・印刷にも含める。表示だけ丸め、計算は元の精度を保つ。未定義値を0として表示しない。
- 2D数表の実測点、散布図、残差図の点を選択すると、元の行番号・全列の値・欠測をポップアップに出す。数表編集ボタンは対象行のページを開く。補間線の途中をクリックしても存在しない観測行を作らない。
- 行の選択は作図・散布図・残差図・比較配置で共用し、現在表示中のビューを維持する。欠測でその図に描けない行は強調しない。空白クリック・Escapeで解除し、ドラッグ・ズームで解除しない。
- 選択の強調は一時状態。保存・画像出力には含めない。Undo/Redo・文書読み込みで解除する。
- 点のポップアップで回帰から除外・復元できる。数表では各行と選択行の一括操作、全行の使用を切り替える。数表ダイアログは適用まで下書きで、キャンセルすると編集と除外指定を取り消す。

## 回帰に使う行

- `series.excludedRows` は元の数表の0始まりの行番号配列。利用者への表示は1始まり。data2d/data3dだけが持ち、重複・負数・範囲外を拒否、保存時は昇順へ正規化する。
- 指定は数表単位で、その数表を参照する作図面の回帰・散布図の回帰・残差図に共通する。描く列の組が異なっても同じ観測行を除外する。
- 除外しても元のセルは保持し、作図面と散布図では白抜きの点にする。残差は回帰に使用した点のみ。除外行を戻す操作は作図面・散布図・数表から行える。
- 統計量・相関行列・ヒストグラム・箱ひげ図は元の全データを使う。回帰の除外指定を暗黙に転用しない。
- 回帰結果は `n`（使用）、`skipped`（除外指定されていない欠測）、`excluded`（指定除外）を分ける。合計は元の行数。残差の先頭列は元の1始まり行番号を保持する。
- 行削除では残る行に合わせて除外番号を付け替える。追加行は使用。CSV等による全置換では除外を解除。数値を含めない自作テンプレートも除外を空にする。

## 保存形式

`kaijo-graph` version 10。version 1〜9を段階的に移行し、従来の数表は全行使用、従来の分析グラフは既定の表示設定とする。古いversionを名乗りながら今回のフィールドを含む入力は拒否する。

```js
chart.axes = {
  x: {label:'', unit:'', min:null, max:null, step:null, format:'auto'},
  y: {label:'', unit:'', min:null, max:null, step:null, format:'auto'}
};
chart.style = {pointSize:8, width:2, dash:'solid'};
chart.legend = true;
chart.labels = {equation:false, metrics:false};
series.excludedRows = []; // data2d / data3d
```

色は従来の `chart.color`。凡例・ラベルは真偽値、点サイズ2〜30、線幅0.5〜20、線種solid/dash/dot。範囲は±10億以内の有限なmin&lt;max、目盛り間隔は正。軸名160文字・単位80文字以内。文字列はDOMのtextContentまたはPlotly向けエスケープを通す。

一時的な行選択は `{seriesId, rowIndex}` としてコントローラが持つ。描画点の `customdata[0]` は元の1始まり行番号、`meta.dataRows` と `meta.seriesId` で結び付ける。強調用traceは `meta.observationHighlight` を持ち、出力から除く。

## 検証

- 分析コア: 除外・欠測の内訳、モデル制約、元行番号、旧版移行・不正入力。
- 分析グラフ: 軸・目盛り、凡例、書式、回帰式・指標、参照更新。
- Chrome: 書式の適用・不正範囲の拒否・複製・Undo、点の実クリック、数表編集の取消と確定、比較表示、除外と復元、保存・旧版移行、SVGから強調を除外、390px・ダーク・大きな文字・キーボード・タッチ。
- 既存の数式・注釈・領域・回帰・保存・印刷の回帰テストも維持する。Safari実機確認はユーザー指定により対象外。
