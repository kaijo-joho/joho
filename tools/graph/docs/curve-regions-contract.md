# 曲線による領域（2026-09-16、0.5.0）

## 範囲と操作

- 2D関数 `y=f(x)` または登録済みの接線を第1の境界とする。第2の境界は別の関数・接線・横軸 `y=0`。縦方向に2境界を結ぶ、始点から終点までの有限な区間を塗る。陰関数・媒介変数・極座標の閉曲線、穴、3D領域、広義積分は対象外。
- 左の「点・線分・文字」＋ →「領域」から「線分で囲む」「曲線と軸・曲線の間」を選ぶ。関数・接線を選択中は曲線方式を優先し、閉じた線分の組がなく関数がある場合も曲線方式を初期表示する。境界には非表示の対象も選べる。
- 区間の始点・終点は式で保持し、pi・係数を使える。始点 < 終点が必要。軸に指定した記号を画面に使い、保存値は既存の正規化方式に従う。関数の指定範囲外へは自動で区間を縮めず、理由を表示する。
- ダイアログで面積・定積分を数値プレビューする。面積は `∫|f−g| dx`、定積分は `∫(f−g) dx`。交差で上下が入れ替わっても面積を相殺しない。新規作成と境界・区間の変更は評価に成功した場合に確定する。
- 基本色・不透明度・面積／定積分の表示切り替えは選択ポップアップへ置く。名前・文字位置・追加色・RGBは既存の開閉部と詳細で扱う。左一覧では面積を常に表示し、定積分はツールチップでも確認できる。境界・区間は「︙」で編集する。
- 塗りは境界や点の背面に置き、交差による複数部分を1オブジェクトとして選択・編集する。重なった線・点の選択を優先する。名前・面積・定積分を1つのラベルとしてドラッグでき、塗りの不透明度は文字に適用しない。
- 係数・境界式の変更に追従する。変更により一時的に評価不能になっても元の参照と区間を保持し、理由を表示する。値を戻すかUndoすると回復する。

## 保存形式

- `kaijo-graph` version 6。version 1〜5を移行し、既存の線分領域を保持する。旧版に `curveRegion` が混入した文書は拒否する。保存キーは変えない。
- `curveRegion` は共通のid/name/visible/style/labelに加え、`targets`、`interval`、`showArea`、`showIntegral` を持つ。
- targetsは2要素。関数は `{type:'series',id}`、接線は `{type:'tangent',id}`、第2の横軸は `{type:'axis',axis:'x'}`。同一対象2つ・未知の参照・不正な種類は拒否する。intervalはスカラー式の文字列2つ。
- 既定は青・不透明度0.25、面積オン・定積分オフ。width/dashは共通書式として保持するが塗りには使わず、輪郭は元の関数・接線の書式を使う。
- JSON、自動／明示保存、ローカル保存、Undo/Redo、複製、全体表示、PNG/SVGへ対応する。3Dでは保持したまま非表示。境界削除は依存する領域も削除して1回でUndoでき、領域だけの削除は元の境界を残す。

## 数値処理

- `integrals.js` はDOMに依存せず `compute(f,g,[a,b])` から `polygons/area/integral/labelPoint/warning` を返す。`annotations.js` が係数・接線・定義範囲・対数軸を解決する。無効時は空polygon、数値null、理由を返す。
- 初期64区間をわずかに不等間隔にし、適応Simpson法で符号付き積分と絶対値積分を同時評価する。初期の大きさを基準にした相対誤差の目安 `1e-9` と曲線の曲がりを使って細分し、32768座標での評価・30段の分割を上限とする。誤差見積もりは数学的な厳密保証ではない。
- 符号が変わる箇所を二分法で探し、その交点を上下の共通頂点にして塗りを分割する。最大部分の内側へラベルを配置する。一致した境界の面積0は許容し、塗りなし・値0で表示する。
- 面積は実座標での非負値、定積分は境界順序に依存する値。対数表示の画面上の面積ではない。両軸に単位がある場合だけ積を添え、換算しない。表示は8桁の有効数字。浮動小数点の相殺誤差程度の定積分は0へ丸める。保存する式や係数は丸めない。
- 未定義・非有限・対数軸で非正となる境界・未収束・予算超過は面と数値を表示しない。非常に細かい振動、狭い突起、接するだけの交点等は有限の標本では完全に検出できない。区間を狭めて確認するための教材用数値近似とする。
