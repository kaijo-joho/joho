# 物性値・状態図テンプレート

2026-09-17に一次資料を確認した。理科年表にあるような物性値・相平衡を扱うが、理科年表の本文・図表は転載せず、公開された相関式を独自に計算する。実測表は`reference`、相関式の計算値は`model`として区別する。

## 水

- [IAPWS SR1-86(1992)](https://iapws.org/technical-guidance/release/Supp-sat)：飽和蒸気圧の式(1)、飽和液体密度の式(2)。温度273.16–647.096 K、臨界定数647.096 K・22.064 MPa・322 kg/m³。PDF第1ページで公開・利用を許可している。
- [IAPWS R14-08(2011)](https://iapws.org/technical-guidance/release/MeltSub)：氷 Ih の融解圧の式(1)、昇華圧の式(6)。三重点273.16 K・611.657 Pa。PDF第1ページはIAPWSへの帰属表示を条件に全部・一部の公開を許可している。実装・出典欄に International Association for the Properties of Water and Steam を記載した。

`water-properties.js`は温度Kを受け取り、圧力MPa・密度kg/m³を返す。SR1-86 Table 1の照合値（373.1243 Kの圧力0.101325 MPaと密度958.365 kg/m³など）、R14-08 Table 3の照合値（260 Kの融解圧138.268 MPa、230 Kの昇華圧8.94735×10⁻⁶ MPa）をテストに用いる。相関式の三重点での微差を線の隙間として見せないため、三重点ちょうどの圧力は0.000611657 MPaに合わせる。

水の状態図は、昇華203.15–273.16 K、蒸気圧273.16–647.096 K、融解268–273.16 Kの数表を作り、圧力50 MPaまでを表示する。高圧氷III・V・VI・VIIや準安定状態は対象外。融解曲線の拡大は270–273.16 Kを線形軸で示す。密度の図は273.16–373.15 Kの**飽和液体**であり、圧力一定の密度表ではない。

## 二酸化炭素

[Span–Wagner (1996)](https://doi.org/10.1063/1.555991)の補助相関式を使う。詳細な係数・制限・更新方針は[CO₂の出典記録](co2-properties-sources.md)を参照。三重点216.592 K・0.51795 MPa、臨界点304.1282 K・7.3773 MPa。昇華180–216.592 K、融解216.592–230 K、蒸気圧216.592–304.1282 Kを数表化し、圧力40 MPaまでを表示する。

## 図と数表の扱い

温度は`°C = K − 273.15`へ換算する。圧力は絶対圧。状態図の縦軸は対数で、等間隔は等しい圧力差を意味しない。1気圧の補助線は0.101325 MPa。昇華・融解・蒸気圧の曲線は三重点で接続し、液体と気体の境界は臨界点で止める。超臨界領域との間に架空の境界線を延長しない。

数表の点は直線で結び、外挿や自動平滑化をしない。物理的に連続な相境界を有限個の点で近似するため、ズームして読み取る値には離散化による差がある。編集・保存・書き出しは通常の数表と同じで、元の出典と条件を保持する。公式文書のPDF・図版そのものは同梱しない。
