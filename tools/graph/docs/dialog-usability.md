# 編集画面の整理（0.20.1）

項目が多い画面は、同じモーダル内で目的別に切り替える。アイコンだけで意味を推測させず、短いラベルを併記する。選択対象の書式を右パネルへ集約する既存の方針は維持する。

## 画面の分類

| 編集対象 | タブ |
| --- | --- |
| 2D数表 | 数表・描画・出典 |
| 3D数表 | 数表・出典 |
| 数式・曲面・陰関数・媒介変数・極座標 | 数式・出典 |
| 座標・グラフの設定 | 範囲 / 目盛・表示 / 軸名 |
| 散布図・ヒストグラム・箱ひげ図・残差 | データ・軸・書式 |
| 散布図行列 | データ・書式 |
| データを取り込む | 用意済み・URL・ファイル |

- 数表の「描画」は点の結び方と元の点の表示を扱う。CSV保存は「数表」に置き、編集中の値を保存する。
- 座標の「範囲」は軸の種類、通常・対数、範囲、拡大率、等縮尺を扱う。横軸・縦軸は幅がある画面で左右2列に並べる。
- 分析グラフの書式には代表色5色、任意色の選択、RGB指定、点・線・凡例などをまとめる。RGB指定は同じ画面で開閉する。
- 数式の書き方、軸の説明、補間の注意点などの詳しい説明は、関連する設定内で開閉する。

## 数表と取り込み

- 表の下の＋で行を追加し、列見出しの右の＋で通常列・計算列を追加する。行削除は表下の行操作、末尾列削除は列＋のメニューに残す。計算列は列名の横のアイコンから式を編集する。
- セルのクリックは選択だけとし、矢印キーで上下左右へ移る。Enter・F2・ダブルクリック・文字入力で編集を始める。編集中の矢印キーは文字の移動に使い、Enterで確定して次行、Tab／Shift＋Tabで隣の列へ移る。Escapeはそのセルの編集を取り消し、次のEscapeでモーダルを閉じる。日本語変換中のキーをセル移動に使わない。
- 複数セルの貼り付け、50行ごとのページをまたぐ移動、日付・カテゴリ列、回帰への使用・除外を維持する。計算結果のセルは直接書き換えず、列名の横から式を変更する。
- 幅721px以上では軸・誤差の列割り当てを1行で常時表示する。狭い画面では開閉でき、横・縦・奥行きの列名を要約する。
- 計算列の編集、前後の行参照、プレビューは表と同じ画面内に置く。計算列の「適用」は編集中の表へ反映し、モーダルの「描画」で作品へ確定する。
- データ取り込みの「用意済み」「URL」「ファイル」にアイコンを添える。詳しい設定は「読み取り設定」と「列・欠測の設定」に分ける。取得方法・欠測の扱い・出典の保存は変更しない。

## 入力とモーダルの扱い

- タブ付きのモーダルは高さを画面に収まる一定値に保ち、ヘッダー・確定ボタンを固定して内容側をスクロールする。タブを切り替えても枠の高さ・上下位置を変えない。短い単一画面のモーダルは必要な高さにする。
- データ取り込みも同じ高さ固定を使う（0.20.1）。用意済み一覧・URL欄・ファイル選択・読み込み後のプレビューで外枠を動かさず、長い一覧や設定は内容側だけをスクロールする。
- 編集用タブの切り替えでは入力欄を作り直さず、値・計算列の編集中の式を保持する。作品・自動保存・履歴には確定時だけ反映する。
- キャンセル・Escapeで破棄し、開いた操作へフォーカスを戻す。座標のプレビューも元に戻す。
- 編集用タブはクリック・タップ・左右矢印・Home・Endで操作でき、現在位置を読み上げに伝える。取り込み方法のボタンはTabで移動し、Enter・Spaceで切り替える。
- 入力形式や数値の上下限のエラーでは、最初の該当欄のタブ・折りたたみを開いてフォーカスする。複数エラーがあっても順に修正できる。式の文法や計算条件のエラーは従来どおり内容を表示する。
- 編集用のHTMLモーダルは1つ。計算列の適用などは同じモーダル内の操作として維持する。
- 右パネルの自由な色はブラウザの色選択を直接開く。専用のRGBモーダルを挟まず、ブラウザ側のRGB入力も利用できる。分析グラフの詳細編集にあるRGB値は、同じ設定画面内の下書きとして扱う。
- 右パネルの線幅・不透明度はスライダーと数値入力を併用し、線種は見本アイコンの排他的な選択とする。複数選択では共通項目に適用し、値が異なる数値欄には「混在」を表示する。書式のドラッグ中は保存せずプレビューし、確定で1回の履歴にまとめる。
- 残差・散布図・散布図行列・ヒストグラム・箱ひげ図の追加に、それぞれの図を表すアイコンを添える。アイコンだけにはせず名称を併記する。

保存形式はversion 14、既存の数値・数式・計算方法は変更しない。Chromeでタブ切り替え、入力保持、キャンセル、Undo、エラー欄の表示、暗色・文字拡大・390px幅を確認する。Safari実機確認は依頼により対象外。
