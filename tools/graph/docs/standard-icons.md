# 標準操作アイコン（0.23.1）

共通部品 `tools/shared/ui-icons.js`・`tools/shared/ui-icons.svg` の20261113版（46 ID）を使う。`index.html` で共通APIを `icons.js` より先に読み込む。`GraphIcons.create(name, document)` は共通操作を `JohoIcons.apply(svg, id)` へ渡し、SVGの `use` から公開用スプライトを参照する。開発用資料のパスは実行時に参照しない。

依存版はコミット `a7f633ff0018c49ca1a2b412ac4344cb906462c3`。この共通部品が先に `origin/main` へ入っていることを確認してからグラフ側を公開する。

今回変更するグラフのJS・CSSの読込URLは `?v=0.23.1`、共通APIは `?v=20261113` を付ける。旧キャッシュのアイコン定義と新しい呼出側の混在を避けるため、対象6資産の版をそろえる。

## 対応する操作

| 標準ID | グラフで使う操作 |
| --- | --- |
| `file` | ファイルメニュー、データ取込のファイルタブ |
| `new` | 新しいグラフ |
| `save` | 明示保存、保存して閉じる、自作テンプレートの保存 |
| `open` | ブラウザ・ローカルから読み込み、CSV・テンプレートのファイル選択 |
| `undo` / `redo` | 元に戻す・やり直し |
| `settings` | 上部の設定メニュー |
| `help` | 使い方 |
| `view` | 表示するグラフ、オブジェクトの再表示、画像確認 |
| `copy` | PNG・出典テキストをコピー |
| `duplicate` | オブジェクトを複製 |
| `delete` | オブジェクト・自作テンプレート・数表の削除 |
| `export` | 画像・CSVの書き出し、取得した原データのダウンロード |
| `theme-auto` / `theme-light` / `theme-dark` | テーマ切替 |
| `more` | 狭い画面の操作メニュー、オブジェクト・自作テンプレートの管理 |
| `close` | 文書タブ・パネル・ダイアログ・接線追加を閉じる、キャンセル |
| `zoom-in` / `zoom-out` | 拡大縮小メニュー、全体・横・縦方向の拡大縮小 |
| `fit` | グラフに表示範囲を合わせる |
| `refresh` / `stop` | ローカル自動保存の開始・停止 |

23種類を既存操作に適用する。未実装の操作は増やさない。メニュー内の「…」は共通の横三点にそろえる。

`adjustments` は係数や読取条件の調整用で、グラフ固有のスライダー型を保持する。軸、数式、接線、各種分析グラフ、線種見本、書式コピー・適用、複数選択、非表示など、標準IDと意味が異なるものはグラフ側のアイコンを使う。数式内の記号やアプリアイコンは対象外とする。

## 表示と操作の維持

- 共通SVGは24×24の座標、`currentColor`、線幅1.7、丸い線端・結合、塗りなし。上部では22pxで表示する。
- SVGは `aria-hidden="true"`、`focusable="false"`。操作名、ツールチップ、無効・選択状態とキーボードフォーカスはボタンに持たせる。
- 標準41pxの上部1行、狭幅メニュー、タッチ時44px、右側タブの既存寸法を維持する。
- 文書schema version 15、数式評価、軸・係数、Undo/Redo、保存先、ショートカットと操作ハンドラーを変更しない。

## 確認

`node tools/graph/tests/standard-icons-browser.test.cjs` は対応ID、外部SVGの描画、操作名、配色、自動テーマ、フォーカス、無効状態、複製とUndo/Redo、720px・390px・タッチ操作を確認し、一時フォルダへスクリーンショットを作る。

共通部品の公開前に検証する場合は、`GRAPH_SHARED_DIR` に共通担当の候補ディレクトリを指定できる。候補の2ファイルは読取のみで、グラフ側へ複製しない。公開後は指定なしで同一リポジトリの依存版を確認する。`GRAPH_TEST_URL` は公開ページ等の確認先、`GRAPH_ICON_SCREENSHOTS` は確認画像の保存先を指定する。

既存の上部メニュー・複数文書・軸書式・書式スライダーのブラウザテストも使う。復元が必要な場合はグラフのアイコン適用コミットだけをrevertし、他アプリが使う共通部品は削除しない。
