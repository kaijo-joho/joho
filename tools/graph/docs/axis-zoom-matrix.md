# 軸スライダーと散布図行列（0.18.0）

## 軸の拡大率

「座標・グラフの設定」の各軸に、入力した最小値・最大値を100%とするスライダーを置く。範囲は6.25〜1600%で、目盛りは対数的に動く。100%へ戻すボタン、キーボードの矢印操作、拡大率の読み上げに対応する。

- 線形軸では算術平均、対数軸では幾何平均を中心として、範囲の幅を変える。
- 数値・日付の横軸／縦軸、3Dの高さの軸に対応する。日付の境界は日単位へ外側に丸める。カテゴリ軸には表示しない。
- 入力した範囲を変更すると、その範囲を新しい100%とする。無効な範囲では操作を無効にし、許容範囲を超える操作は採用しない。
- 作図をプレビューし、「適用」で1回の履歴と保存に反映する。キャンセル、Escape、再読込では未確定の範囲を保存しない。個別軸の拡大で等縮尺を解除する。
- 分析グラフ・比較表示のとき、座標設定は作図側の軸だけを変更する。

MacBookのトラックパッドからChromeへ伝わるピンチは、ページには拡大率に基づくCtrl＋wheel相当のイベントとして届く。指を広げた縦横方向の情報は含まれないため、自動判別を実装しない。方向別ボタンと軸スライダーを使う。根拠：[ChromiumのTouchpadPinchEventQueue](https://raw.githubusercontent.com/chromium/chromium/main/components/input/touchpad_pinch_event_queue.cc)（2026-09-17確認）。

## 散布図行列

- 1つの数表から数値列を2〜4列選ぶ。元のx/y割当とは独立し、計算列も選べる。日付・カテゴリ、重複した列、範囲外の列は拒否する。
- 横方向・縦方向に列を並べ、非対角に散布図、対角にヒストグラムを表示する。対角の縦軸は度数であり、元の列の値ではない。
- 同じ変数の座標範囲を行・列で共用する。列名を軸名として使い、数値から範囲を自動決定する。
- 非対角セルの相関はPearson r。必要な2列の両方に値がある行だけを使い、使用数nを併記する。一定値の列、使用数不足の相関は「—」。表示は小数第4位までに丸め、計算精度は保持する。
- 対角の階級分けは既存ヒストグラムと共通。自動階級数はceil(sqrt(n))、最大100。左端を含み、最後の階級だけ右端も含む。
- 回帰からの除外指定によらず、全行から欠測を除いて集計する。別表の行番号結合、無断の間引きは行わない。相関は因果関係を意味しない。
- 点を選ぶと元のデータ行を選択し、欠測のない対応セルで同じ行を強調する。数表の編集で再描画する。強調は保存・画像出力に含めない。
- 色・点の大きさ・線の太さを編集でき、PNG/SVG・比較・印刷の既存出力へ対応する。小さな画面は図内でスクロールする。
- 入口は左の＋、数表の関連グラフ、統計量・相関行列の画面。統計画面は選択した数値列が2〜4列の場合に作成ボタンを有効にする。

## 保存と互換性

文書は `kaijo-graph` version 14。version 1〜13は移行できる。旧版を名乗る文書へmatrixを混在させた場合は拒否する。新しい図は `charts[]` の `kind: 'matrix'`, `seriesId`, `columns`（0始まり）として保持し、既存の書式フィールドを共用する。行列1つを分析グラフ1件と数え、分析グラフ12件・比較6件の上限を変えない。

元表・列との参照、非表示・複製・削除、Undo、数値を除いた自作テンプレートは既存の分析グラフと共通である。相関係数・階級度数を文書へ保存せず、元データから再計算する。

標準テンプレートは33件。同梱資料は7件のまま。追加3件の条件は [散布図行列テンプレートの出典](matrix-template-sources.md) にまとめる。
