# 散布図行列テンプレートの出典と条件

## 相関の向きを比べる

16行の固定模擬データで、正の相関・負の相関・ほぼ無相関を比較する。実測値ではなく、授業で相関係数と散布図行列の読み方を確認するためのモデルである。相関は因果関係を意味しない。

## 振り子の線形化

長さ `L`（m）、周期 `T`（s）、周期の二乗 `T²`（s²）を用いる。値は高校物理で用いる小角近似 `T = 2π√(L/g)`、`g = 9.8 m/s²` から計算した模擬値で、実測値ではない。`T` と `T²` は計算列として定義し、途中で丸めずに計算する。小角近似の範囲を超える振幅、空気抵抗、支点の大きさは扱わない。

## 東京の月別平年値

既存の `GraphOpenDataCatalog` の `jma-tokyo-normal-1991-2020` を正本として共用する。元表の12か月から、月・平均気温・降水量・日照時間を抽出し、散布図行列には数値3列（平均気温、降水量、日照時間）を指定する。統計期間は1991〜2020年の平年値であり、12点は月別の季節関係を表す。年ごとの変化や長期傾向を表すデータではない。

出典は気象庁「過去の気象データ検索｜東京 平年値（年・月ごとの値）」および既存カタログに記録された利用条件・確認日を引き継ぐ。テンプレートでは数値を再転載せず、既存カタログの表から必要な列だけを抽出する。
