# オープンデータ取り込み 0.10.0

2026-09-17実装。従来の検討案を、実装した範囲と今後の拡張に分けて記録する。文書version 10を維持し、数表と既存の `series.source` を使う。

## 取り込みの流れ

「数式・数表」の＋ →「CSV・オープンデータを追加」に入口をまとめる。

- **用意済み**：確認したオープンデータを同梱し、選択・プレビュー・描画で追加する。0.11.0では気象庁の東京・札幌・那覇の月別平年値（1991–2020）とNASAの太陽系8惑星を収録し、名前・分類で検索できる。ネット取得・利用者登録は不要。[出典と利用条件](open-data-sources.md) を参照。
- **URL**：公開HTTPSのCSV・TSVを直接取得する。取得できない場合は同じ画面に「公開元を開く → CSVを保存 → ダウンロードしたファイルを選ぶ」を表示する。ネットワークエラーの原因をCORSと断定しない。
- **ファイル**：ローカルCSV・TSVを選択する。ファイルはブラウザ内で処理し、アップロードしない。

いずれも横軸・縦軸・3Dなら高さの列を選択する。初期値は日付・数値列を候補とし、品質情報の列を避ける。プレビューは元の表記で先頭8行を示し、描画前に取り込む行列数・欠測・対象外の列を確認できる。1回の「描画」で数表と必要な軸設定を追加し、Undo1回で戻せる。既存の系列は保持する。詳細編集用の別モーダルを続けて開かない。

## CSVの解釈

- 取得・ファイルは1MiB以内、解析は10050レコード・100列以内。数表に保存できるのは10000行・20列・絶対値10億以内。作品全体の既存上限2MiB・総50000行も適用する。
- UTF-8・Shift_JISを自動判別し、UTF-16のBOMも認識する。文字コード、カンマ・タブ・セミコロン、見出し行・データ開始行は手動で変更できる。
- 引用符内の区切り・改行・二重引用符を扱う。レコード番号と物理的なテキスト行番号は、引用符内の改行がある場合は異なる。
- 厳密な数値、全角数字、3桁区切り、指数表記を扱う。文字列中の数字だけを抜き出したり、内部空白を削って別の数値に変えたりしない。HTML・JSON・バイナリはCSVとして取り込まず、本文を実行しない。
- 空欄、NA、N/A、null、NaN、--、---、…、×、/の連続などは欠測（null）。既知の欠測記号以外は理由を示して止め、利用者が選んだ場合だけ欠測へ変換する。欠測だけのレコードは保持し、空文字だけのレコードは除外件数を記録する。列数の不一致や末尾の説明は無言で無視しない。
- 数値列を最大20列まで初期選択し、他の数値列も選べる。統計・相関・回帰・誤差棒は既存の数表機能へ接続する。地域・品質コードなど1列の値を完全一致で絞り込める。
- 日付の横軸は `YYYY-MM-DD` / `YYYY/M/D` を読み、最初の有効な日付からの経過日数、年、月へ変換する。実在しない日付を丸めて別日にしない。月は1〜12で、年を区別しない。起点・変換方式を出典の補足に保存する。
- 品質情報は候補を区別するために列名を認識するが、コードの意味による自動除外はしない。公開元の説明に基づいて絞り込む。特に気象庁の注意付き値を自動で正常値へ変換しない。

CSVの多様な表題・単位行・末尾注記をすべて自動判定する保証はない。見出し・開始行の指定で解決しない複雑な表、横持ち年次表、Excel・JSONは、表計算アプリなどで必要な表をCSVへ整えて取り込む。

## 出典と保存

`source.title` に資料名、`source.url` に出典URL、`source.notes` に取得・取り込み日時、元データ名、文字コード・行設定、日付変換、抽出条件、欠測への変換、取り込まなかった列、任意の利用条件URL・期間・地域を記録する。同梱データは公式表の期間・地点・確認日・加工内容・利用条件も含む。

保存する正本は数値化した表と出典である。日付や文字列の元の表記、取り込まなかった列、元CSV本文は作品に保存しない。この点を画面・ヘルプに明示し、URL・同梱データには「元のCSVを保存」を用意する。元ファイルを保持する経路を設ける。出典欄は編集できるが、同梱データは収録時点で条件を記録済み。

作品を開いた際の自動再取得は行わない。取得時の数値を保持する。画像には出典を自動挿入しないため、外部掲載時には出典欄から併記するようヘルプで案内する。アプリ本体の改変・再配布に関する表示と、同梱の公開データ・ライブラリの利用条件を分ける。

## URL取得

- HTTPS・最大2000文字、利用者が入力して実行したURLに限る。userinfoやAPIキー・署名・認証トークンを含むURLを拒否し、ファイル経由へ案内する。e-StatのappIdを保存・配布しない。
- `fetch` のGET、`mode:'cors'`、`credentials:'omit'`、`referrerPolicy:'no-referrer'`。編集中の作品を送信しない。最終リダイレクトURLも検査する。
- 読み込み全体15秒、Content-Lengthとストリームの実バイト数を検査する。HTTP失敗・HTML/JSON/Excelなどの型・読み込み中の切断を区別する。
- キャンセル・別データ選択・モーダル終了で中止する。古い応答が戻ってもプレビューや作品を変更しない。読込失敗・プレビュー・キャンセルでは文書を変更しない。
- CORS不許可を `no-cors` や第三者プロキシで迂回しない。ダウンロード経由でも利用条件は変わらない。各公開元の条件に従う。

## 今後の範囲

日付を文字のまま表示する時系列軸、カテゴリ・品質・元表記を持つ列型モデル、複数条件の抽出、気象庁等の専用アダプター、e-Stat API、JSON・Excelの直接取込、元データとの更新差分は後続。保存形式を拡張する際は表の行編集・削除・並び替え・自作テンプレートの数値なし保存と整合させる。
