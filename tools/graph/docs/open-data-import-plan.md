# オープンデータ取り込みの検討（未実装）

2026-09-17時点の案。0.9.0では検討資料のみとし、外部URLの取得やAPI接続は追加しない。既存機能は数値中心のCSV・TSVを読み込めるが、WebページのURLや公開元独自のCSVをそのまま解釈するものではない。

## 次に作る入口

「数式・数表」の＋に「データを取り込む」をまとめ、ファイル選択または公開CSVのURL入力から、プレビュー→列選択→グラフ作成へ進める。

1. UTF-8・Shift_JIS、区切り文字、見出し行・データ開始行を確認する。複数見出しや単位行を数値に誤変換しない。
2. 横軸・縦軸・追加の数値列を選ぶ。欠測表記は一覧で確認し、0に変換しない。行を無言で読み飛ばさない。
3. 日付・地域名・品質フラグは数値列とは別に保持できるデータモデルを先に設計する。初期版で扱えない列もプレビューで明示する。時系列軸や地域での抽出はこの基盤上に加える。
4. 数表へ取り込み、散布図・折れ線・回帰・統計量・相関行列で使う。元URL、資料名、取得日時、単位、期間・地域、利用条件の参照先を記録する。
5. 取り込んだ値は作品に含め、後日の閲覧で再現できるようにする。公開元の更新は自動反映せず、「再取得」で差分を確認して適用する。

## 公開元ごとの対応

| データ | 取り込み方の案 | 確認が必要な点 |
| --- | --- | --- |
| 自治体などの公開CSV | ファイルまたは直接URL、列のプレビュー | 見出し、文字コード、地域・年月列、単位、公開元の利用条件 |
| 気象庁の過去データ | ダウンロードしたCSVから始め、専用の読み取りを追加 | ダウンロード時刻・複数の表題行・品質情報を区別する。注意付きの値や欠測を正常値と混ぜない |
| e-Stat | 最初はCSV、次に統計表・地域・期間を選ぶAPI用画面 | APIには利用登録とアプリケーションIDが必要。作品や公開ソースへ利用者のIDを埋め込まない |

気象庁CSVの構造・品質情報は [公式のCSV形式説明](https://www.data.jma.go.jp/risk/obsdl/top/help3)、e-StatのアプリケーションID要件は [公式API仕様](https://www.e-stat.go.jp/api/api-info/e-stat-manual) に基づく。実際の提供ファイルを使った検証と利用条件の確認は各対応の実装時に行う。

## 静的サイトでの制約

- ブラウザから別サイトのデータを読み取るには、公開元のCORS許可が必要。URLを入力できることと取得できることは別で、一般のWebページを自動スクレイピングする機能にはしない。[MDN: CORS](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS)
- 許可のない公開元は、利用者がCSVをダウンロードして読み込む方式を用意する。`no-cors`や外部の非公式プロキシを回避策にしない。
- URL取得は利用者が実行した公開HTTPSデータに限定し、認証Cookieを送らない。データサイズ・行列数・タイムアウトを制限し、データ中のHTMLや式を実行しない。
- 既存の「入力データを外部へ送信しない」説明は、ネット取得を実装する際に、公開元へURL取得要求を送る動作と区別して更新する。

実装順は、汎用CSVプレビュー、日付・カテゴリ・出典の保持、CORS対応URL取得、気象庁などの専用読み取り、e-Stat連携を推奨する。
