# グラフテンプレートの出典

標準テンプレートは26件。`templates.js` の既存16件に、`physics-templates.js` の物理モデル6件、`science-templates.js` の物性・状態図4件を加えている。数式モデルは実測値を意味しない。

- 物理：等加速度運動、斜方投射、単振動、うなり、オームの法則、RC回路の充電。[式・単位・仮定](physics-template-sources.md)。
- 物性・状態図：水・二酸化炭素の状態図、水の融解曲線の拡大、飽和液体の密度。[一次資料と表示範囲](science-template-sources.md)。
- 公開データ：東京・札幌・那覇の月別平年値、太陽系8惑星の数表。左の＋から「CSV・オープンデータを追加」で開く。[出典と利用条件](open-data-sources.md)。

水の数表は、[IAPWS SR1-86(1992): Revised Supplementary Release on Saturation Properties of Ordinary Water Substance](https://www.iapws.org/relguide/Supp-sat.html) の飽和圧力式を使った計算値である。IAPWS はこの式を飽和条件での簡便な近似式として公開している。臨界温度 `Tc=647.096 K`、臨界圧力 `pc=22.064 MPa` と公式係数から計算し、MPa を kPa に換算した。IAPWS-95 が通常の水の国際標準であることは [IAPWS-95 (2018)](https://www.iapws.org/relguide/IAPWS-95.html) に示されている。

表の温度は 0.01°C（三重点）と 10, 20, …, 100°C、圧力は kPa で小数第3位に丸めた。0.01–100°C は飽和曲線の範囲内である。表の点の間はグラフアプリの `data2d` の仕様に従い直線補間し、平滑化や適用範囲外への外挿は行わない。したがって、これらを「実測データ」と表示しない。

公式式の利用条件に従い、リリース全体やデータベースを転載せず、授業テンプレートに必要な係数と少数の計算結果だけを保持している。

## 0.6 の実験データテンプレート

「ばねの伸びと力（合成データ）」と「時間と濃度（合成データ）」は、回帰分析の操作を学ぶために作成した合成データである。実験で測定した値や外部資料から転載した値ではない。前者は直線回帰、後者は指数回帰の例として用い、元データ・誤差棒・回帰結果を区別して表示する。教材で実測値を扱う場合は、測定条件、単位、出典を別途記録する。

PCHIP補間は単調なxの連続区間にだけ適用し、欠測をまたがず、外挿しない。現在のCSV取込では列を明示的に選ぶ。3列目以降を自動で誤差にせず、取り込み画面の「横誤差の列」「縦誤差の列」で割り当てる。誤差棒は対称な幅であり、回帰の重みには使わない。

## 0.2 の数学テンプレート

円 `x²+y²=9`、楕円 `x=3cos(t), y=2sin(t)`、極座標 `r=2cos(3θ)`、放物線 `y=x²` と直線 `y=x+2` は、記載した定義式を数値計算して描画する。外部資料の数表や図版を転載しない。楕円上の点は媒介変数の位置を係数aで指定する。接線・交点は数値近似で、正確な数学的証明や代数的な解法を置き換えるものではない。

## 計算列を使うテンプレート（0.17.0）

区間平均速度、抵抗、力と伸びの単位換算、センサーの差分・移動平均を追加した。4件とも教材用の模擬データであり、観測値や第三者の資料値ではない。計算式・単位・回帰の条件は [計算列テンプレートの前提](calculation-template-sources.md) を参照。
