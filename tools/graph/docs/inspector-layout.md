# グラフエディタ書式パネルの仕様（0.12.0）

## 編集領域

- 選択時は右ペインを自動で開き、「書式」タブを選ぶ。色・線・文字のクイック操作は選択直後も使える。
- 詳細設定と関連グラフの追加はモーダルで開く。選択対象を編集する入口を、グラフ上に重なる選択ポップアップへ置かない。
- 右ペインは幅320pxを確保し、デスクトップでは作図領域を横にリフローする。幅520px以下では作図領域の下へ移して重なりを避ける。
- 左の各行の「︙」は同じ区分内の先頭・1つ上・1つ下・末尾への並べ替えと削除を行う。並べ替え・削除はUndoで戻せる。詳細編集は右ペインまたは項目のダブルクリックで開く。

## 追加と係数

- 左の「＋追加」は1つだけ置き、数式・数表・CSV/open data、点・線分・領域・接線・交点・文字・補助線、回帰・分析グラフ・係数をすべて集約する。
- 係数のスライダーと数値入力は左に常設し、変更中はプレビュー、確定時に1回の履歴と保存を行う。

## 座標・軸

- 座標編集モーダルはxとyを2列に置く。幅650px以下では1列へ積む。
- `axes.x.labelPosition` と `axes.y.labelPosition` は `axis`（軸上）または `edge`（表示領域端）を指定する。未指定は `edge` としてversion 10以前の文書を保つ。
- 軸の近くへの配置は、他方が線形軸で、その0が表示範囲内にあるときに使う。0が画面外、または他方が対数軸なら、xは下端、yは左端へ置く。表示する軸自身は対数軸でもよい。

## ズーム

- 2D作図に全体・横方向のみ・縦方向のみの拡大縮小メニューを置き、既存の全体表示も維持する。中心は現在の表示範囲の算術平均、対数軸では幾何平均とする。
- 単軸ズームを選ぶときは等縮尺を解除する。3D・分析グラフ・比較表示では方向別ズームボタンを無効にする。
- ボタンによる範囲変更はUndo・保存に反映し、軸ラベル・目盛・装飾を再描画する。ホイールやドラッグによる表示範囲の更新も従来どおり使える。
