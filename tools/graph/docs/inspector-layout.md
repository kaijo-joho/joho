# グラフエディタ書式パネルの仕様（0.13.0）

## 編集領域

- 選択時は右ペインを自動で開き、「書式」タブを選ぶ。代表色5色・RGB指定1つと、線・不透明度・文字サイズ・配置など対象に適した書式を選択直後からすべて表示する。書式を展開するボタンや、右ペインの非表示・複製・削除は置かない。
- 詳細設定と関連グラフの追加はモーダルで開く。選択対象を編集する入口を、グラフ上に重なる選択ポップアップへ置かない。
- 0.17.0では右ペインの「その他（…）」を廃止した。CSV保存は「数表・出典」モーダル内へ置き、編集途中の数表を検証・再計算して保存する。確定には従来どおり「描画」を使う。選択した系列が現在と別の次元の場合に限り、「2Dで表示／3Dで表示」を直接表示する。
- 右ペインは幅320pxを確保し、デスクトップでは作図領域を横にリフローする。幅520px以下では作図領域の下へ移して重なりを避ける。
- 左の各行の「︙」はホバー・クリック・タップで表示切替・複製・削除を開く。ホバーでは入力フォーカスを奪わず、メニューへ移動する間は閉じない。Escapeで閉じて操作元へ戻る。同じ区分内の並べ替えはドラッグ、またはOption/Alt＋↑↓・Home・Endで行う。タッチでは色丸の領域・係数名からドラッグし、本文からは一覧をスクロールできる。移動中は挿入位置を示し、Escape・pointercancel・フォーカス喪失では取り消す。区分をまたぐ移動は行わない。並べ替え・表示切替・複製・削除は1回のUndoで戻せる。詳細編集は右ペインまたは項目のダブルクリックで開く。

## 追加と係数

- 点・線分・文字、分析グラフ、係数の見出しは、その区分にオブジェクトがあるときだけ表示する。非表示のオブジェクトも一覧に残す。
- 左の「＋追加」は1つだけ置き、数式・数表・CSV/open data、点・線分・領域・接線・交点・文字・補助線、回帰・分析グラフ・係数をすべて集約する。
- 係数のスライダーと数値入力は左に初期表示し、変更中はプレビュー、確定時に1回の履歴と保存を行う。
- 係数の「非表示」は左のスライダー・数値欄のみを隠し、名前と操作メニューを残す。数式で使う係数の定義・値を保つ。複製は衝突しない名前（例：a_2）で追加する。
- 分析グラフの非表示は単独表示を案内だけにし、比較表示・比較画像から除外する。比較の所属IDを保持して再表示で復元する。注釈・分析グラフの複製は元データや端点への参照を維持し、数表は値・書式・出典を複製する。

## 座標・軸

- 座標編集モーダルはxとyを2列に置く。幅650px以下では1列へ積む。
- `axes.x.labelPosition` と `axes.y.labelPosition` は `axis`（軸上）または `edge`（表示領域端）を指定する。未指定は `edge` としてversion 10以前の文書を保つ。
- 軸の近くへの配置は、他方が線形軸で、その0が表示範囲内にあるときに使う。0が画面外、または他方が対数軸なら、xは下端、yは左端へ置く。表示する軸自身は対数軸でもよい。

## ズーム

- 2D作図に全体・横方向のみ・縦方向のみの拡大縮小メニューを置き、既存の全体表示も維持する。中心は現在の表示範囲の算術平均、対数軸では幾何平均とする。
- 単軸ズームを選ぶときは等縮尺を解除する。3D・分析グラフ・比較表示では方向別ズームボタンを無効にする。
- ボタンによる範囲変更はUndo・保存に反映し、軸ラベル・目盛・装飾を再描画する。ホイールやドラッグによる表示範囲の更新も従来どおり使える。
- 0.18.0では座標設定に各軸の拡大率スライダーを追加した。確定前のプレビューとキャンセル、数値・対数・日付、3Dの高さに対応する。トラックパッドでの方向判別の制約と具体的な挙動は [軸スライダー・散布図行列](axis-zoom-matrix.md) を参照する。

## 記録

これは共通の選択ポップアップ原則に対するグラフ固有の例外であり、2026-09-17の作成者指示に基づく。同日の追加指示により、0.13.0で一覧のドラッグ・表示切替メニュー・書式の常時表示を追加した。保存文書versionは10を維持し、係数と分析グラフの `visible` は省略時に表示する任意項目とする。
