# 上部ツールバー（0.21.0）

2026-09-18の共通仕様2.1をグラフエディタへ適用する。文書形式はversion 14のまま。保存・読み込み・自動保存・Undoのデータ処理は変更しない。

## 配置と寸法

- アプリアイコン・アプリ名 → ファイル → Undo・Redo → 複数選択 → 表示するグラフ → 作品名 → 設定 → ヘルプの順に1行で配置する。グループの間を縦線で区切る。アイコンのリンクはウェブアプリ一覧。
- 標準文字・マウス操作では上部41 CSS px（境界線を含む）、アイコンボタン32×30px。大・特大では共通倍率1.15・1.3で拡張し、タッチ操作では44px以上を確保する。メニュー内の項目はマウスでも44px以上。
- 狭い画面では履歴・複数選択・表示の実際の操作部を「その他」へ移す。同じボタンを複製せず、状態・履歴・イベントを維持する。メニューは画面内でスクロールする。
- 作品名は編集中の1文書の名前を表示する。ファイル切替タブとしては扱わない。長い名前は省略し、ツールチップで全文を確認できる。
- グラフ上の見出し行を廃止し、作図・分析・比較へその高さを戻す。左一覧・右パネル・ヘルプの位置は上部の実際の高さへ合わせる。

## メニュー

- ファイルは新規、ブラウザ保存、ファイル保存、ブラウザから開く、ファイルから開く、ローカル自動保存をまとめる。ブラウザから開く画面では自動保存と明示保存を選べる。
- 表示メニューに作図・作成済みの分析グラフ・比較の切替、比較の配置、2D/3Dを置く。作成済みの分析グラフは左一覧からも選べる。これはオブジェクトの選択と表示先の指定の2つの役割を持つため維持する。
- 設定は座標・グラフ名、テーマ（自動・ライト・ダークのアイコン）、操作文字サイズをまとめる。表示範囲を合わせる操作は下部、画像・印刷は右の書き出しパネルへ置く。
- ホバーは開くだけで、文書・保存・モードを変更しない。クリック・タップで開閉でき、キーボードはTab・Enter・Space・下矢印・Escapeに対応する。ホバーでフォーカスを奪わず、メニュー内にフォーカスがある間はマウスが外れても閉じない。
- 狭い画面の「その他」内にある表示メニューは、親の中で展開する。別の上部メニューへ切り替えると先のメニューを閉じる。
- モーダルを閉じたら、元のボタンを含むメニューが閉じている場合は、その可視の入口へフォーカスを戻す。

## 維持・保留

- 選択対象の書式は右パネルを維持する。グラフに重なる選択ポップアップへ戻さない（共通仕様のグラフ固有例外）。
- 複数ファイルタブは保留。共通仕様4.5で文書単位・保存先・タブ別履歴・閉じる確認・再起動時の復元が未決定のため、今回独自に確定しない。
- 範囲・投げ縄など新しい選択方式は追加しない。既存の一覧上の複数選択・Shiftでの範囲選択・ドラッグ並べ替え・グラフの移動と拡大を維持する。

Chromeで41pxの実寸、文字3段階、390px、タッチ、ホバーの無変更、フォーカス保持、モーダルからの復帰、作図・分析・比較、保存と履歴を検証する。Safari実機確認は従来の指定により対象外。
