# オープンデータ同梱カタログの監査記録

2026-09-17時点で、グラフエディタへ同梱する公式データは気象庁の東京の月別平年値1件とする。大量のデータを固定せず、授業で扱いやすい12行の数表に限定した。

## 収録データ

`jma-tokyo-normal-1991-2020` は、気象庁「過去の気象データ検索」の東京（東京都、観測所番号47662）から、月、平均気温、降水量、相対湿度、日照時間を選択して転記したCSVである。元ページに表示された統計期間は1991–2020、資料年数は30である。元ページの表にある1月から12月の12行と照合し、年の行や風向などの非数値列は含めていない。

## 利用条件の確認

気象庁の公式Legal Notice（英語版）は、特段の権利表示がないウェブサイトの内容について Public Data License Version 1.0 に従って利用できること、出典を示すこと、編集した内容には編集した旨を付すこと、第三者の権利が含まれないか利用者が確認することを定めている。カタログには元ページURL、利用条件URL、出典名、統計期間、地点、取得確認日、転記・加工・固定スナップショットであることを記録した。気象庁のロゴ、画像、元HTMLは同梱しない。

数値表の利用条件がデータそのものに適用されるか不明な公開元については、規約を確認できるまで同梱しない。気象庁については公式利用条件と公式表を確認できたため、授業用の少量の数値を収録した。第三者の図版や個人情報は含めていない。気象業務法など別法令による制限があり得る用途（予報業務など）へ、このカタログを拡張しない。

## 追加・更新手順

1. 公式のデータ表と利用条件を別々に開き、URLが実在する公式ドメインであることを確認する。
2. 地域、地点、統計期間、資料年数、選択列、単位、欠測値を記録し、表の原値と転記CSVの全行を照合する。年集計行や注記を月行へ混ぜない。
3. 再配布・編集・出典表示の条件と第三者権利の有無を確認する。明確に確認できない場合はデータを追加せず、保留理由をこの記録へ残す。
4. `open-data-catalog.js`には2–20列、12行程度の数値中心CSVだけを追加し、`source.notes`へ出典、条件、期間・地点、取得確認日、加工内容、最新版ではないことを書く。利用者が編集したデータと誤認しないよう、固定スナップショットであることも示す。
5. カタログの各項目について、CSVの見出しを除く全行が数値列であること、列数が2–20、データ行数が12、`x`と`y`が列範囲内であること、公式URLがHTTPSであることを確認する。`GraphOpenDataCatalog.list()`の結果を変更しても内部データが変わらないことも確認する。

固定スナップショットは、授業資料や保存したグラフを後日同じ値で再現するためのものである。公式ページの更新を自動反映せず、更新時は新しい確認日と差分を記録してから、利用者が明示的に選べる版として追加・置換する。カタログのデータは最新版や継続的な観測配信を保証しない。
