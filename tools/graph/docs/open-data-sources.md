# オープンデータ同梱カタログの監査記録

2026-09-17時点で、グラフエディタへ同梱する公式データは、気象庁の5件、NASA NSSDCAの1件、NOAA GMLの1件である。大量のデータを固定せず、授業で扱いやすい小表に限定した。

## 収録データ

`jma-tokyo-normal-1991-2020` は、気象庁「過去の気象データ検索」の東京（東京都、観測所番号47662）から、月、平均気温、降水量、相対湿度、日照時間を選択して転記したCSVである。元ページに表示された統計期間は1991–2020、資料年数は30である。元ページの表にある1月から12月の12行と照合し、年の行や風向などの非数値列は含めていない。

`jma-sapporo-normal-1991-2020` と `jma-naha-normal-1991-2020` も同じ表の形式で、各都市の1月から12月、統計期間1991–2020、資料年数30を照合した。平均気温・降水量・相対湿度・日照時間を転記し、年集計、風向、雪などの列は含めていない。札幌は観測所47412、那覇は観測所47936である。

`nasa-planets-metric` は、[NASA NSSDCA Planetary Fact Sheet – Metric](https://nssdc.gsfc.nasa.gov/planetary/factsheet/) の8惑星を数値化した表である。番号1–8は水星、金星、地球、火星、木星、土星、天王星、海王星に対応する。距離（百万km）を149.5978707で割ってAU、回帰公転周期（日）を365.25で割って年に換算し、小数第3位に丸めた。直径の半分は平均半径ではなく**赤道半径**である。[原表の項目定義](https://nssdc.gsfc.nasa.gov/planetary/factsheet/planetfact_notes.html)に従い、重力は回転を含む赤道の値、巨大ガス惑星の重力・温度は大気の1 bar水準として注記した。残る質量・密度・温度等は表の表示値を転記し、画像・ロゴ・標章は含めない。

`jma-global-temperature-anomaly-2000-2024` は、[気象庁「世界の年平均気温偏差（℃）」](https://www.data.jma.go.jp/cpdinfo/temp/list/an_wld.html) の2000年から2024年までの25行を収録する。列は年、世界全体、北半球、南半球の年平均気温偏差（℃）である。基準値は1991〜2020年の30年平均値で、世界値は陸域の地表付近の気温と海面水温を平均した値である。公式表の全25行・全3値を照合して転記し、換算、平滑化、予測値の付加はしていない。これは地点の観測気温や将来予測ではなく、気象庁が算出した基準値からの偏差である。

`jma-japan-temperature-anomaly-2000-2024` は、[気象庁「日本の年平均気温偏差（℃）」](https://www.data.jma.go.jp/cpdinfo/temp/list/an_jpn.html) の同じ期間の25行である。列は年と日本の年平均気温偏差（℃）。基準値は1991〜2020年の30年平均値であり、公式表の全行を選択・転記した。変換、再計算、将来予測の付加はしていない。世界値と日本値は同じ基準期間の偏差として比較できるが、算出対象と方法が異なる分析値であるため、単独の観測地点の気温としては扱わない。

`noaa-mauna-loa-co2-annual-2000-2024` は、[NOAA Global Monitoring Laboratory の Mauna Loa CO₂ annual mean data](https://gml.noaa.gov/webdata/ccgg/trends/co2/co2_annmean_mlo.txt) から、2000〜2024年の25行を収録する。列は年、乾燥空気中のCO₂年平均（µmol/mol = ppm）、推定不確かさ（ppm）である。原表の年平均と不確かさをそのまま転記し、変換・再計算はしていない。原表によると不確かさはNOAA/ESRLとScrippsが独立に算出した年平均の差の標準偏差である。噴火によりマウナロア観測所は2022-11-29に観測を休止し、2022年12月から2023-07-04までの観測は約21 miles北のマウナケア観測所で行われた。年平均値は品質管理・再較正で小さく改訂されることがあるため、末尾の最新年を追随せず、2024年までの固定版とした。

## 利用条件の確認

気象庁の公式Legal Notice（英語版）は、特段の権利表示がないウェブサイトの内容について Public Data License Version 1.0 に従って利用できること、出典を示すこと、編集した内容には編集した旨を付すこと、第三者の権利が含まれないか利用者が確認することを定めている。カタログには元ページURL、利用条件URL、出典名、統計期間、地点、取得確認日、転記・加工・固定スナップショットであることを記録した。気象庁のロゴ、画像、元HTMLは同梱しない。

数値表の利用条件がデータそのものに適用されるか不明な公開元については、規約を確認できるまで同梱しない。気象庁については公式利用条件と公式表を確認できたため、授業用の少量の数値を収録した。第三者の図版や個人情報は含めていない。気象業務法など別法令による制限があり得る用途（予報業務など）へ、このカタログを拡張しない。

NASAについては、NSSDCAの公式Fact Sheetで数値を確認し、NASAのMedia Usage Guidelinesで教育・情報目的の事実情報の利用、出典表示、NASA標章・第三者著作物の扱いを確認した。収録物は画像ではなく、少量の事実数値を選択・換算したものに限る。NASAの承認・保証を示す表現はしない。NASAのサイトに第三者権利表示が付いた素材を転載しない。

追加した2件の気象庁気温偏差も、同じ[気象庁ホームページ利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)を確認した。権利表記がないコンテンツは公共データ利用規約（第1.0版）に従って利用でき、出典表示と、編集・加工時にその旨を表示する必要がある。カタログは出典URL、基準期間、選択した年、固定スナップショットであることを記録し、ロゴ・図版を含めない。

NOAA GMLのCO₂表は、[データ案内](https://gml.noaa.gov/ccgg/trends/data.html)に示された公式年平均データである。同ページの指定に従い、引用は「Dr. Xin Lan, NOAA/GML (gml.noaa.gov/ccgg/trends/) and Dr. Ralph Keeling, Scripps Institution of Oceanography (scrippsco2.ucsd.edu/)」とする。[NOAA Copyright Information](https://sos.noaa.gov/copyright/) では、別記がないNOAA作成のデジタル媒体は一般に著作権の対象ではなく、教育・情報目的に使え、NOAAを出典として示し、NOAAの承認を示唆してはならないとしている。本件は2000年以後のNOAA GML表の少量の数値だけを転記し、画像・標章・第三者素材を含めない。

候補としてNIST Atomic Spectra Databaseの第1イオン化エネルギーも公式表の全値を照合したが、同データベースは NIST Standard Reference Database #78 である。[NISTのSRD利用案内](https://www.nist.gov/open/copyright-fair-use-and-licensing-statements-srd-data-software-and-technical-series-publications) はSRDの編集データについて著作権保護が確保され得ることを示しており、今回の小規模な同梱再配布に適用できる明確な許諾を確認できなかった。そのため収録しない。

## 追加・更新手順

1. 公式のデータ表と利用条件を別々に開き、URLが実在する公式ドメインであることを確認する。
2. 地域、地点、統計期間、資料年数、選択列、単位、欠測値を記録し、表の原値と転記CSVの全行を照合する。年集計行や注記を月行へ混ぜない。惑星表など単位換算を行う場合は換算式と基準値を記録する。
3. 再配布・編集・出典表示の条件と第三者権利の有無を確認する。明確に確認できない場合はデータを追加せず、保留理由をこの記録へ残す。
4. `open-data-catalog.js`には2–20列の数値中心CSVだけを追加し、`source.notes`へ出典、条件、期間・地点、取得確認日、加工内容、最新版ではないことを書く。利用者が編集したデータと誤認しないよう、固定スナップショットであることも示す。年間時系列は、年が完了しており数値と注記を照合できる範囲へ限定する。
5. カタログの各項目について、CSVの見出しを除く全行が数値列であること、列数が2–20、行数が収録対象（月別なら12、惑星なら8、今回の年間時系列なら25）と一致すること、`x`と`y`が列範囲内であること、公式URLがHTTPSであることを確認する。転記した時系列は全行を期待配列と突合し、換算値は原値・換算係数から再計算して照合する。`GraphOpenDataCatalog.list()`の結果を変更しても内部データが変わらないことも確認する。

固定スナップショットは、授業資料や保存したグラフを後日同じ値で再現するためのものである。公式ページの更新を自動反映せず、更新時は新しい確認日と差分を記録してから、利用者が明示的に選べる版として追加・置換する。カタログのデータは最新版や継続的な観測配信を保証しない。
