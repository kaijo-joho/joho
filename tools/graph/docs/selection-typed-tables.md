# 複数選択・日付とカテゴリ（0.14.0）

2026-09-17の作成者指示による追加。右側へ書式を集約し、一覧の︙に表示切替・複製・削除を置く配置は維持する。

## 複数選択と書式

- ⌘/Ctrlクリックで追加・解除、同じ区分のShiftクリックとShift＋↑↓で範囲選択する。タッチは一覧上部の複数選択モードを使い、件数ボタンで書式を開く。
- 通常クリックは単独選択。空白クリック・Escapeで解除。係数の値操作と数表の行選択は単独操作を維持する。選択状態は作品に保存しない。
- 複数選択時は共通する書式だけを表示する。値が異なる数値・線種は「混在」、チェックは中間状態、色は選択なしで表示し、変更した項目だけを一括適用する。
- 1対象の書式をアプリ内へコピーし、選択した対象へ対応する項目だけ適用する。色・線・不透明度・点の表示・文字サイズ等が対象で、名前・式・位置・出典・参照IDはコピーしない。コピーはページを開いている間だけ保持する。
- 書式のコピー／適用は右側のアイコンまたは⌘/Ctrl＋Shift＋C/V。入力欄の操作は妨げない。適用・一括編集・複数削除は各1回の履歴にまとめる。

## 数表の列型と保存

- 文書version 11。version 1〜10は数値列・数値軸として移行する。旧版を名乗るファイルへ新しい型設定を混在させない。
- `dataTable.columnTypes` は `columns` と同じ長さの `number` / `date` / `category` の配列。省略は全列数値。元の表は列型に応じた数値・文字列・欠測nullを保存する。
- 日付は年月日または年月を検査する。不正日付を別の日へ丸めず、うるう年も検査する。元の表記を保持し、描画座標はUTCの1970-01-01からの日数とする。年月だけなら月初として描く。
- カテゴリは文字列を保持する。軸ごとに安定した項目順を保存し、同じ名前は系列をまたいで同じ座標になる。新項目だけを末尾へ追加する。一覧の並べ替えでは軸の項目順を変えない。
- `axes.x/y.type` が軸型、`categories` がカテゴリ順。内部の最小・最大座標は数値を保ち、ズーム・履歴・出力に共用する。日付の範囲は画面では日付で入力し、カテゴリの順序は1行1項目で編集する。
- 型付きの表からの描画座標は元表を正本として再計算する。純数値の旧来表と投影座標の不整合検査は維持する。
- 保存・CSV・自作テンプレート・行の追加削除・貼り付けは型情報と対応する値を保持する。数値なしのテンプレートは型と列設定を保ち、行は除く。

## 描画と分析

- 日付・カテゴリ軸は2D。列と軸の種類が異なる系列は理由を示して非描画とし、作品から削除しない。数式系列は数値軸で描く。
- 日付は実際の日数間隔、カテゴリは等間隔。元表の表示順は変えず、直線結線は入力順に従う。カテゴリに滑らかな補間を行わない。
- 日付横軸・数値縦軸の回帰を扱う。数式中の横座標と誤差幅は日数である。カテゴリを数値の順位として回帰しない。
- 統計量・相関行列・ヒストグラム・箱ひげ図の集計列は数値に限定する。日付・カテゴリの元値は数表や点の読み取りで確認できる。
- 軸のラベル・元値のホバー・比較配置・画像にも型を反映する。型付き軸では等縮尺や数学的な原点表示を使用しない。

## 数表の見やすさと次段階

表は列名・列型と行番号を固定し、横・縦スクロール、数値の右寄せ、交互の行背景、編集中セルの強調を使う。計算列は未実装。次は表操作を確認したうえで「指定列を1000で割る」「2列の比を新しい列へ出す」等、列全体の式による再計算を検討する。セルごとの表計算や授業管理へは広げない。
