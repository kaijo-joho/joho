# 計算列（0.15.0）

2026-09-17の作成者との合意による仕様。同じ行の計算と列全体の集計を組み合わせ、元データを残したまま計算結果を新しい列へ追加する。

## 式と列参照

| 表記 | 意味 | 例 |
|---|---|---|
| `[@列名]` | 同じ行の数値 | `[@気温] + 273.15` |
| `[列名]` | その列の全行。集計関数の引数に使う | `AVERAGE([気温])` |
| 両者の組み合わせ | 各行に共通の集計値を使う | `[@人数] / SUM([人数]) * 100` |

- `SUM`、`AVERAGE`、`MIN`、`MAX`、`COUNT`、`STDEV.P`、`STDEV.S` を用意する。関数名は大文字・小文字を区別しない。列名は一致させる。
- 集計関数の引数は列全体の参照を1つとする。`[列名] * 2` は使わず、`[@列名] * 2` を計算列に設定する。
- 四則演算、累乗、括弧、`pi`、`e` と既存の数学関数（`sqrt`、`abs`、`ln`、`log`、三角関数など）を使える。`ln` は自然対数、`log` は常用対数。計算列の三角関数はラジアンで評価し、グラフの角度設定から独立する。
- 通常の列名はそのまま参照する。`]`、`@`、引用符、バックスラッシュを含む名前は、メニューが `[@"列名"]` / `["列名"]` の引用形式を挿入する。引用部分はJSON文字列のエスケープを使う。
- 計算列は別の計算列も参照できる。列の位置ではなく依存関係の順で計算する。存在しない列、参照先の同名列の重複、自分自身への参照、循環参照は確定できない。
- 列名の変更では、依存する式の列参照も更新する。参照されている列を削除する場合は、先に依存する式を変更・削除する。

## 集計範囲と欠測

- 対象は数値列。集計は表の全行を使い、グラフの表示範囲、表のページ、回帰の除外行に左右されない。
- 空欄は欠測 `null`。集計は欠測を除き、同じ行の欠測を使う計算は欠測とする。欠測だけでは計算エラーにしない。
- `COUNT` は数値の個数。数値がない場合の `COUNT` と `SUM` は0。それ以外の集計には数値が必要で、`STDEV.S` は2個以上必要とする。
- `STDEV.P` は偏差の2乗の和を n で割った平方根、`STDEV.S` は n−1 で割った平方根。
- ゼロ除算、定義域外、非有限値、最終結果の絶対値10億超過は、そのセルを `null` としてエラー理由を表示する。式そのものが有効であれば、行エラーがある表も確定できる。
- 計算エラーを参照した計算列にはエラーを伝える。集計対象の計算列にエラーがある場合も集計エラーとし、欠測として黙って除かない。
- グラフ・回帰・通常の統計では、数値にならないセルを除外し、計算エラーが含まれる旨を表示する。表で行・列と理由を確認できる。
- 合計などの中間値には最終セルの10億制限を適用しない。たとえば合計100億を使った割合が100以内なら計算できる。内部の非有限値は使用しない。
- 表示だけを丸め、入力値・内部の計算値・保存値を表示桁数に合わせて丸めない。JavaScriptの浮動小数点演算を使い、厳密な数式処理は行わない。

## 操作

- 数表の「計算列を追加」から列名と式を指定する。同じ行／列全体の参照と日本語の関数メニューを挿入できる。
- 先頭5行のプレビューを見て「適用」する。式の構文や参照が不正な場合は、元の表と入力途中の式を保つ。
- 計算結果のセルは直接書き換えず、列見出しの「式を編集」から変更する。入力列を変更すると計算セルを更新する。
- 計算列の適用後に数表を確定すると、作品・グラフ・回帰・統計へ反映する。未適用の計算設定を残したまま確定できない。数表全体の取消では作品を変更しない。
- 数表の確定は1回のUndoで戻せる。列名変更、行の追加・削除、貼り付けでも式と列の対応を保つ。

## 保存と実装

保存形式は `kaijo-graph` version 12。version 1〜11は移行して読み込む。旧版を名乗る文書への `formulas` 混在は受け付けない。

```js
dataTable: {
  columns: ['時刻', '気温', '偏差'],
  rows: [[0, 20, -2], [1, 24, 2]],
  mapping: {x: 0, y: 2, z: null, errorX: null, errorY: null},
  formulas: [null, null, '[@気温] - AVERAGE([気温])']
}
```

- `formulas` は `columns` と同じ長さ。入力列は `null`、計算列は1000文字以内の非空文字列。計算列は `number` 型。計算列がなければ項目自体を省略する。
- 正本は入力列の値と式。読込・検証時に計算列と描画用 `series.rows` を再計算し、保存された計算結果だけを信用しない。計算エラー一覧は保存せず、その都度求める。
- JSONは式も保持する。CSVは計算済みの値を出力し、式は保持しない。欠測と計算エラーはCSVでは空欄になる。
- 値なしの自作テンプレートにも列名・型・式・列割当を残す。新しい測定値を入れると再計算する。
- `calculations.js` は列参照の解析、依存順の検査、制限付きの式評価を行う。式をJavaScriptとして実行しない。集計値は表の1回の評価内で共用し、行ごとに全列を再走査しない。
- 既存の20列・10000行制限に加え、式の複雑さと行数による計算量制限を設ける。上限時は式を簡単にするか行数を減らす。

日付・カテゴリの計算、別の行との演算、移動平均、係数スライダーとの連動、セル番地・セルごとの式は初版の対象外。
