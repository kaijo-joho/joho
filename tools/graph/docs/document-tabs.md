# 複数文書と右側タブ（0.22.0）

2026-09-18に確定した共通仕様4.5と、右側タブの共通仕様2.3を適用する。グラフの再編集ファイルはversion 14を維持する。

## 文書の切り替え

- 1タブを1文書とする。新規作成、JSONの読み込み、保存候補からの再開、テンプレートは新しいタブで開く。検証に失敗したファイルでは新規タブを作らない。
- 文書、Undo/Redo、作図・分析・比較の表示先、表示範囲、3Dの視点、選択状態、明示保存先、ローカル自動保存先をタブごとに保持する。タブ切替そのものは編集履歴へ追加しない。
- 文書名と選択状態を示す。最後の明示保存から編集された文書には●と「未保存」の説明を付ける。自動保存ではこの印を消さない。
- ズーム・移動・全体表示・3D回転だけでは未保存にしない。座標設定で確定した範囲や等縮尺は編集として扱い、Undo/Redoと未保存判定へ反映する。テーマと操作文字サイズはアプリ共通の設定。
- 幅不足時はタブの部分だけを横スクロールする。一覧メニューからも切り替えられる。選択タブを表示範囲へ入れ、設定・ヘルプを右端へ残す。左右矢印・Home・Endにも対応する。

## 保存・終了

- ファイルメニューの「保存」と⌘/Ctrl+Sは、現在の文書で最後に成功した明示保存先を使う。初回はブラウザ内／ローカルファイルを選ぶ。
- ファイルメニューで別の保存先へ保存した場合、成功後にその文書の保存先だけを切り替える。ローカルのファイルハンドルは今回の起動中だけ保持する。権限がないときは保存先の再指定を案内する。
- 保存開始時に対象タブ・内容・未保存判定の基準を固定する。保存中のタブ切替を許可し、あとから行った編集を保存済みにはしない。
- 未保存タブを閉じるときは「保存して閉じる」「保存せずに閉じる」「キャンセル」を選ぶ。保存に失敗した場合や選択を取り消した場合は閉じない。保存中は閉じる操作を無効にする。
- ローカル書込APIを使えない場合はダウンロードを開始するが、完了を確認できないため未保存の印を残す。「保存して閉じる」でも自動で閉じない。ブラウザ内への明示保存も選べる。
- タブを閉じても明示保存は削除しない。自動保存の候補も保持する。「保存せずに閉じる」は明示保存を更新しない操作として扱う。最後のタブを閉じると空の文書を開く。
- ローカル自動保存は文書ごとに独立する。他の開いている文書の保存先や、明示保存先と自動保存先を同じファイルにしない。既存の外部変更検知・自動保存停止も維持する。

## ブラウザ内の互換性

- `kaijo-graph:documents:<文書ID>:auto` と `:saved` に、それぞれ本文・日時・保存種別を記録する。手動で確定した軸範囲を管理情報に保持し、表示操作だけの変更を再開時にも区別する。
- 旧 `kaijo-graph:auto` / `kaijo-graph:saved` は読み込み候補へ出し、上書き・削除しない。1候補の破損でほかの候補を隠さず、読み込めなかった候補のエラーを表示する。
- 保存候補を開くと新しいタブIDを割り当てる。同じ保存内容を複数開いても、それぞれの自動保存・次の明示保存が混ざらない。本文のオブジェクトIDや参照関係は変更しない。
- 起動時には自動／明示保存の候補を選ぶ。全タブの一括再開、再起動をまたぐUndo/Redoやローカルファイルハンドルの復元は対象外。

## 右側パネル

- 右端の開閉タブは標準26px・大28px・特大30px、タッチ44pxを基準とする。書式・テンプレート・書き出しの固定アイコンを上に置き、下に縦書きの名称を表示する。
- 開いているタブを強調し、開閉状態をアプリ設定としてブラウザ内へ記憶する。パネル本体は既存の320px／300pxを維持し、狭い画面では下部へ表示する。今回、パネル幅のドラッグ調整は追加しない。
- グラフ固有の右側書式パネルは維持する。選択ポップアップへ戻さない。

## 検証

- 単体: 文書別の自動／明示保存、旧キー、破損・容量不足、編集と表示範囲の区別、保存開始時の基準、Undo/Redoの分離。
- Chrome自動操作: タブの追加・切替・終了、キャンセル・保存失敗、保存中の切替と追加編集、保存先の記憶、保存候補からの再開、右側タブ、狭幅・テーマ・文字サイズ・タッチ。
- ファイル選択・書き込みの取消と失敗は模擬File System Access APIで検証する。OSの保存ダイアログやSafari実機は、この検証に含めない。
