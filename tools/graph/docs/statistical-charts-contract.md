# 分析グラフ・自作テンプレート・比較配置（0.8.0）

0.18.0で追加した散布図行列とversion 14への移行は [軸スライダー・散布図行列](axis-zoom-matrix.md) を参照する。書式の右パネル化・一覧操作は [書式パネルの仕様](inspector-layout.md) が優先する。

## 操作

- 回帰曲線の選択ポップアップにある残差アイコンで残差グラフを作る。回帰の設定時に「残差グラフも表示する」を選ぶこともできる。横軸は元の横軸または予測値、縦軸は元の値 − 予測値。元の行番号をホバーで確認できる。
- 統計量・相関行列の対角以外のセルから、列見出しを横軸、行見出しを縦軸にした散布図を作る。欠測はペアで除外し、同じ数表を参照し続ける。散布図の設定で直線・比例・2次・指数・べき乗回帰を選べる。回帰式・R²・Pearson r・RMSEは下部に表示する。定数列などの未定義値を0とは表示しない。
- 統計画面で分布を描く列を選ぶとヒストグラムを作れる。箱ひげ図は集計対象の複数列を並べる。左の「分析グラフ」の＋からも各図を追加できる。
- 分析グラフは左一覧または作図面上部の選択欄で切り替える。選択ポップアップで編集・色・比較への追加・削除、一覧の「︙」で詳細を開く。計算済みデータを複製せず、元の数表・回帰の変更に追従する。
- 「比較の配置」で作図と分析グラフを1〜6枚選び、順序と1〜3列を設定する。狭い画面では縦1列に並べ、画像には設定した列数を使う。カードの見出しから単独表示へ戻れる。
- 書き出し・印刷は表示中の作図／分析グラフ／比較を対象とする。比較には各図の名前を付け、白／透明背景、PNG倍率、SVGに対応する。3Dを含む比較の画像はPNGを使う。各図を読める大きさにするため、出力が小さい場合は「比較に合わせて画像サイズを調整」を使う。長いカード名は画像内だけ省略表示する。

## 数値の定義

- 計算は元の精度で行い、表示を丸める。回帰は既存 `GraphAnalysis` を使用する。
- 四分位数は昇順に並べ、個数が奇数のとき全体の中央値を除いた上下半分の中央値とする。偶数のときは同じ個数ずつに分ける。1個のときQ1・中央値・Q3はその値、0個のときは未定義。箱ひげ図のひげは最小値・最大値で、外れ値を自動除外しない。
- 箱ひげ図は計算済みのQ1・中央値・Q3・最小・最大を描画ライブラリへ渡し、ライブラリの既定の四分位数方式に依存しない。参考：[Plotly box trace reference](https://plotly.com/javascript/reference/box/) の `q1` / `median` / `q3` / `lowerfence` / `upperfence`。
- ヒストグラムは最小〜最大を等間隔に分ける。自動階級数は `ceil(sqrt(n))` を1〜100に制限する。手動でも1〜100。左端を含み、右端は最後の階級だけ含む。定数列は1階級とする。浮動小数で境界が同一になるほど狭いときは重複境界をまとめる。
- 欠測は各図に必要な列で除外する。空の数表や分析できない回帰は元の設定を維持し、グラフと理由を表示する。別の数表を行番号だけで結合しない。

## 保存形式

文書は `kaijo-graph` version 9。version 1〜8を移行し、古い版に新しいフィールドを混在させたデータは拒否する。

`charts` は最大12件。全件に `id`, `kind`, `name`, `color` を持つ。

| kind | 保存する参照・設定 |
|---|---|
| `residual` | `regressionId`, `horizontal: 'x' / 'predicted'` |
| `scatter` | `seriesId`, `xColumn`, `yColumn`, `model`（回帰なしはnull） |
| `histogram` | `seriesId`, `column`, `bins`（自動はnull） |
| `box` | `seriesId`, `columns` |

列は元の数表の0始まりの列番号で参照し、現在の作図用x/yの割当とは独立する。列名や数値の変更には追従する。使用中の列がなくなる編集は確定前に拒否し、分析グラフ側の列設定を変更または削除してから数表を編集する。表全体のCSV差し替えも列の順番を基準とする。

`comparison: {columns: 1|2|3, items: ['main' またはchartId]}` を保持する。空・重複・不存在参照を拒否する。元の系列や回帰を削除すると依存する分析グラフと比較項目も削除し、Undoで復元する。分析グラフだけを削除しても元の数表・回帰は保持する。

計算結果、単独表示の切替、比較上でのズーム・3Dカメラは文書に保存しない。図の定義と比較配置を保存して再計算する。文書2MBなどの既存の上限は維持する。

## 自作テンプレート

- 右のテンプレートパネルから登録する。名前・説明と文書を保存し、「数表の数値も含める」を外すと行と誤差棒だけ空にして列名・割当・式・係数・軸・書式・出典・参照関係・比較配置を保持する。
- ブラウザのキーは `kaijo-graph:templates`。最大20件・合計8MiB、文書は各2MiB。通常の自動保存・明示保存とは独立する。実際に利用できる容量はブラウザの保存領域に依存し、失敗時に既存のライブラリを削除しない。
- 持ち出し形式は `kaijo-graph-template` version 1、拡張子 `.graph-template.json`。`name`, `description`, `document` を持つ。ファイルから取り込む場合は新しいIDで追加し、既存の同名テンプレートを上書きしない。
- 「︙」から名前・説明の変更、ファイル保存、削除ができる。ひな形を開く操作は文書のUndo対象。ライブラリへの登録・名前変更・削除は文書の履歴を変えない。
- 標準の16テンプレート、元の出典、既存の通常保存は維持する。

## 構成と検証

`charts.js` が定義の検証・依存削除・各分析グラフの計算、`workspace.js` が単独・比較描画と画像の合成、`template-library.js` がひな形の検証・保存を担当する。`core.js` は参照と形式を検証し、`editor.js` が既存の履歴・保存・操作へ統合する。

数値・境界・不正入力・旧版移行・連鎖削除・Undoを単体テストする。Chrome自動操作で数表編集への追従、相関セル、回帰、分布図、比較の配置・ズーム・画像・印刷プレビュー、自作テンプレートの保存・再利用・ファイル往復、390px・テーマ・キー・タップを確認する。SVGはラスタ化した画像の色も確認する。Safari実機確認は作成者の指定で省略する。

3Dの新しいグラフ種類、重み付き回帰・信頼区間・仮説検定、授業管理は今回の対象外であり、従来の保留を維持する。
