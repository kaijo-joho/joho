# 交点と操作性の調整（2026-09-16、0.3.1）

作成者の指示により、追加メニューの交点を一つにまとめる。登録した2D関数と接線を同じ対象一覧から選び、接線の式も表示する。係数の値は左パネルにスライダーと数値欄を常設する。これはグラフエディタ固有の決定で、係数の範囲・名前や描画対象の書式は引き続きポップアップ／ダイアログで編集する。

## 文書

- version 4。v1〜v3の数値・式・参照ID・保存キーを保持して移行する。
- 接線に `showEquation:boolean` を追加。新規はtrue、旧文書はfalseを補う。左一覧の接線式は常に表示し、図中の式だけをこの設定で切り替える。
- 関数同士の `intersection.seriesIds` と接線同士の `tangentIntersection.tangentIds` は維持し、UIではいずれも「交点」と表示する。
- 関数＋接線の交点には `intersection.targets:[{type:'series'|'tangent',id},...]` を使う。`seriesIds`との両立は認めない。対象は異なる2つ。参照は順不同で検証し、接線を消すとこの交点も削除する。`interval`は探索範囲。新フィールドを含む旧版を黙って読み捨てない。
- 接線同士を選んだ場合は既存の解析的な直線交点を使い、区間を求めない。関数が含まれる場合は区間を表示する。区間と関数の定義域を守り、接線は無限直線として扱う。

## 数値API（GraphAnnotations）

- `tangentEquation(annotation,doc)` → `{text:string,warning:string}`。軸symbolを使う。有限な傾きと接点から現在の式を作り、数値微分なので近似を示す。未定義なら空のtextと理由。微小な非ゼロ値を安易に0へ丸めない。
- evaluate(intersection)は従来seriesIdsと新targetsの両方を扱う。tangentLineを共有し、表示された線分や表示範囲から交点を求めない。

## 操作

- 点・線分・接線・交点・文字の追加は左側の直接ボタンから1クリックで設定へ。補助線も同じパレットに置く。詳細選択のためだけのモーダルを廃止する。
- 編集・色・表示・複製・削除などは線画アイコン＋説明（ツールチップ、aria-label）。対象選択時のポップアップに配置する。よく使う曲線上の点・接線、線分の継続も直接出す。
- 一覧のダブルクリックと、対象選択後のEnterで設定へ。入力欄・IME・ヘルプには割り込まない。
- 係数変更中は描画と接線式だけプレビューし、確定時に一度だけ履歴・保存へ反映する。スライダーのDOMとフォーカスを再描画で失わない。Escape/pointercancelで元へ戻す。
- 既存の保存、Undo、ドラッグ、2D/3D、狭幅・テーマ・キーボードを維持。Safari実機は作成者の指示どおり省略。

領域・面積などの③の機能は今回の対象に含めない。

## 表示と直接編集の追加調整（2026-09-16、0.3.2）

- 接線式の表示は基本8桁の有効数字に丸め、不要な末尾0を除く。微小な非ゼロ値は科学表記で保持する。切片の差し引きで生じる機械精度付近のノイズは両項の大きさを基準に扱い、絶対閾値で小スケールの値を消さない。計算値・式・交点探索・保存形式version 4は変えない。
- 選択ポップアップに基本6色を常設する。「色・線」は非モーダルの追加欄を開閉し、残りの12色・線幅・線種を直接変更する。RGB・自由な色・不透明度等は「色・線の詳細…」に従来のダイアログを残す。
- 「文字・配置」は名前／文字の表示・接線の方程式表示・文字サイズを直接変更する。上下左右のずれは「文字・配置の詳細…」で編集する。入力した数式や座標の設定画面は維持する。
- 直接編集は確定した操作ごとに履歴へ1回反映し、Undo・保存・図の表示へ連動する。不正な数値は文書を変えず入力表示を戻す。別の対象へ切り替えたら開いていた欄を閉じ、古い入力を新しい対象へ適用しない。
- 基本色のキーボード操作、詳細ダイアログからのフォーカス復帰、Escapeによる追加欄の閉鎖、390px幅・タッチ・ダーク・特大文字を確認する。

## 接線のクイック追加（2026-09-16、0.3.3）

- 選択した関数の接線アイコンと、左パレットの接線ボタンから非モーダルの座標入力欄を開く。マウスのホバーでも開き、ホバーだけではフォーカスを移さない。クリック・タップ・キーボードで開いたときは座標欄へ移す。欄へマウスを移しても閉じない。
- 接点の座標の入力中は、接線と方程式を描画にだけ反映する。元の文書、Undo、ブラウザ／ローカル保存に下書きを含めない。Enterまたは「接線を追加」で一度だけ登録・保存し、追加した接線を選択する。名前などの詳細は既存の「位置・設定」で編集する。
- 軸の数式用記号を座標欄に使い、分数・定数・係数の式も保持する。複数の関数があれば対象を選べる。空欄、不正な式、定義域外、微分できない接点では追加できず、理由を欄内に表示する。
- Escape、閉じる、外側クリック、フォーカスの移動、別の対象・モード・設定を選ぶと下書きを取り消す。Escapeと閉じるでは元の入口へフォーカスを戻す。登録するまで履歴を増やさず、登録後はUndo一回で戻せる。
- 狭い画面では左パレットを閉じ、入力欄を画面内に配置する。テーマ・文字サイズ・画面回転・ソフトウェアキーボードの表示領域を考慮する。画像書き出しは下書きを除いた描画の完了を待つ。
- 保存形式はversion 4のまま。既存の接線、交点、係数、詳細モーダルの仕様を維持する。Safari実機確認は省略する。
