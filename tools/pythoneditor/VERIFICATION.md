# 実装と検証の区分

2026-10-14。手元Macの自動操作ChromeとPlaywright WebKitで検証した。Jamf管理の生徒Mac、Safariアプリ、家庭回線、貸出機の実機を操作した結果ではない。

## 確認したこと

| 項目 | 検証・結果 |
|---|---|
| 全授業 | Chromeで22冊・125問題/確認と公開授業5ページ・80例文、計205ケース。203正常終了、2件は教材で意図したZeroDivisionError/KeyError。予期しない失敗0。 |
| 実入力 | 複数の事前入力、日本語の逐次入力、入力終了/EOF、ValueError等の種類と行番号。Chrome/WebKitで確認。 |
| 停止 | 実際の無限ループからWorker終了、コード保持、Worker再作成後の再実行。共有メモリなしの環境でも停止機構を使用。 |
| 出力・グラフ | printのsep/end、Unicode、末尾の式、NumPy、matplotlib、日本語PNG、図保存、Colabのdownload接続。日本語の欠損グリフ警告なし。 |
| 過大出力 | 10万文字上限で終了し、画面が応答する。複数図上限・一時ファイル初期化も確認対象。 |
| 問題切替・再読込み | 問題と版ごとのコード・入力・直前位置の保持。別版の下書きは上書きしないことをCore試験で確認。 |
| 保存・取込み | 明示保存、自動保存の分離、ファイル出力・取込み、取込み前の控え、取消、競合/破損を保持するCore試験。 |
| 通信断 | 読込済みの実行環境では、オフラインにしてもコード保持・ローカル実行が継続する。初回取得のオフライン利用は保証していない。 |
| 拒否時の挙動 | 合成403で問題を表示せず、別の取得経路へ要求しない。実学校認証・認証切れの再認証は未検証。 |
| 共通部品の障害 | 共通ヘルプ・CodeMirrorの取得を失敗させてもtextareaによる編集・実行を継続する。 |
| 表示 | 1440/720/390px、3テーマ×3文字サイズ。横はみ出しなし。非モーダルの共通ヘルプを開いたまま編集。 |
| 40並列 | 127.0.0.1のマスター読取へ40要求を同時送信して全件取得。GASや40台の学生端末・授業回線の負荷試験ではない。 |
| 正式提出の分離 | 実行終了・進捗・下書き保存を正式得点・提出済みにしない。正式採点とクラウド保存は未接続と表示。 |

全教材の一覧は[CURRICULUM.md](CURRICULUM.md)。集計のみを`verification-summary.json`へ保存する。私有コード・模範出力・詳細の検証fixtureと読取GSSスナップショットはリポジトリ外に置く。

matplotlib 3.10系の一部内部描画でfloat座標の非推奨警告が出る場合がある。グラフの正常終了と分けて「標準エラー・ライブラリの警告」に表示する。日本語フォントは文字化けせず表示を確認した。

## 次の段階で必要な検証

学校MacのChrome/Safari、JamfのWorker/Wasm/CDN制限、IME、40台の一斉起動・GAS読取、初回の通信断、認証期限切れ・再認証、GSS下書きの負荷・競合、貸出機→自端末の復元を確認する。

正式提出は未実装。再送・応答消失の照会、受付時刻と締切、締切後の不算入、1問ごとの最高点、旧版採点、結果・履歴の永続化までの提出成立は、本番候補APIの実装後に検証する。今回のCore試験やローカル40要求をこれらの証明に使わない。

## 検証の再現と復元

実行手順は[README.md](README.md)を参照。通常の操作試験、教材ケース、WebKitを分けて実行する。ブラウザの画面を撮影し、通常幅と390pxの表示を目視確認する。終了時にテスト用ブラウザとテスト用サーバーを閉じる。

レビュー用の127.0.0.1サーバーだけは試作確認のため起動している。公開サイト・GAS・GSSへの書込、学校設定・権限・OAuth変更は行っていない。生徒向けリンクや今年度の原本を変更せず、新規ファイルだけを戻せる状態にする。
