# 用紙エディタ 0.3.1 公開プレビュー

教員用の用紙作成・編集ツールです。テキスト、自由記述、単一・複数選択、桁別数値のOMR欄を配置できます。

ブラウザ保存と編集用JSONファイルの保存・再読込を利用できます。現在の公開版はGAS/GSSに未接続です。用紙の本文はサーバーへ保存しません。ブラウザに保存した内容は、使用したブラウザ内に残ります。

参加申込テンプレートは架空の例です。実際の開催日・会場・費用・未公開の試験や解答・生徒データは含めていません。印刷は確認用であり、正式な読取用PDFの検査・登録とは別です。

GAS接続設定は既定で無効です。実接続は、独立した接続先・必要な認証・権限・originの確認後に行います。既存WSやスキャン取込には接続していません。
