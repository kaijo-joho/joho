# OMR用紙エディタ 0.10.1

説明文・設問・選択OMR・数値欄・1行記入枠・自由記述欄を配置する教員向けツールです。編集内容はこのブラウザへ自動保存します。

1. 用紙を編集し、部品の設定を適用します。
2. 上部の「QRを発行」から、用紙管理にログインします。
3. 現在の内容を「下書きを保存」で保存します。
4. 「OMR用紙登録」で内容を確認します。PDF検査後、識別QR発行と読み取り設定登録を確定します。
5. 上部の「登録済みPDF」または「印刷」からPDF原本を開き、PDF画面で印刷します。原本と読み取り設定をダウンロードして保管してください。

QR未発行で印刷を押すと警告します。「QR発行へ進む」「QRなしで確認印刷」「キャンセル」から選びます。QRなしの用紙は読み取り用として配付しないでください。

下書き保存とOMR用紙登録は別の操作です。登録済み本文を編集すると未登録へ戻ります。変更時は新しい年度内版で登録し、旧PDFを上書きしません。未ログイン時は登録状態未確認として扱います。

登録PDF原本は登録時のブラウザに保管します。ブラウザデータを消す前に原本をダウンロードしてください。原本を失った完成版を同じQRで再生成しません。「登録履歴・中断からの再開」で登録済み設定や残っている原本を取得できます。

QRは数字14桁、通常QR Version 1（21×21）・誤り訂正H、四辺4セル余白を含む26mm角です。校章や個人情報は含みません。補正用■は13個。A4・JIS B5・JIS B4の縦横を設計対象とし、実機印刷・スキャンの合格を意味しません。

現在は本人限定の用紙管理に対応します。手書き文字の自動読取とDocs編集済み・外部PDFの検査登録は未対応です。ブラウザのPDF表示・印刷設定は利用環境でも確認してください。
