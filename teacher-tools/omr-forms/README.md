# OMR用紙エディタ 0.8.3 公開プレビュー

[教員用ツール一覧](../)から利用できます。説明文・1行記入枠・複数行の自由記述・選択OMR・桁別数値を配置する試作です。

- ページ一覧の各「削除」でページ内の内容ごと削除できます。確認画面で取消でき、最後の1ページは残します。同じ編集画面の「元に戻す／やり直す」に対応します。削除後はページ番号・表裏・QR識別情報を更新します。
- 部品編集・用紙設定・ページ一覧・部品一覧・書き出しは右端の縦タブから開きます。すべて閉じてもタブは右端に残ります。パネル幅を調整できます。
- 部品の左端、用紙タイトル・氏名ラベルの左端は標準で16mmに揃えます。ドラッグで移動し、四辺・四隅からサイズ変更できます。辺・中央・間隔・大きさへの吸着はAltキーで一時解除できます。
- 設問名・必須・本文・部品設定・位置寸法を最上部の「設定を適用」でまとめて反映します。削除は編集パネル最下部です。収まらない変更は紙面へ適用せず、入力控えを保持します。
- テキストと各設問本文では、改行、文字サイズ・色・太字・斜体・下線を指定できます。「段落の書式」の本文／見出し1〜3はカーソルのある段落または選択した段落へ適用します。選択範囲がない文字書式は全文へ適用します。
- 半角英数字も同一書式の文字列として描画し、文字ごとの位置指定による重なりを解消しました。折返し幅はフォントによる概算のため、印刷前の確認は必要です。
- 「1行記入欄」は1つの手書き枠です。「自由記述欄」は複数の罫線を指定する欄です。1行枠の高さは部品の高さに合わせて変わります。手書き文字の自動読取は未対応です。
- 選択OMRは「複数選択可」で○／□、「横並び」「縦並び」で配置を切り替えます。塗りつぶし注釈は設問名と同じ行に表示します。長い設問名は紙面上で末尾を省略するため、必要な説明は設問本文へ入れてください。○／□は濃く塗りつぶし、✓・×は使わないでください。
- QRは校章を重ねない通常のQRです。QR下のランダム識別文字は表示しません。識別情報はQR本体に保持します。
- 学年は氏名の上に中1〜高3を表示し、固定学年の事前マークも設定できます。組・番号と得点の数字見出しは各列の上にまとめます。
- 変更はブラウザへ自動保存し、再読込で直前の用紙・ページ・倍率を開きます。未適用の部品入力にも控えを残します。「ブラウザに保存」は別の明示保存です。ファイルメニューの「ブラウザから開く」で候補を選べます。保存領域の消去や別端末への移動にはファイル保存を使ってください。
- 設定で教科・分類の候補と新規用紙の初期値を変更できます。設定はこのブラウザだけに保存します。
- 片面・両面は用紙設定で選び、印刷ダイアログでも同じ方式を指定します。両面では奇数ページが表、偶数ページが裏です。

**本人限定のGSS保存に対応します。** 「保存先へ接続」で認証付きの接続画面を開き、その画面を残して元のエディタへ戻ります。「GSSに保存」で用紙定義を保存し、ファイルメニューの一覧から別タブへ再読込できます。一般公開の保存先ではなく、現在は指定の学校教員アカウントだけで利用できます。テンプレートは架空の編集例です。

GSS連携では、初回保存時の6桁用紙番号、一覧・再読込、更新履歴、通信中断時の同じ要求による再確認を用意しています。同じ用紙ファイルの再登録は止め、「登録済みの用紙に接続」で現在の下書きを保持したまま接続できます。「複製」は別の用紙として扱います。保存済みと配付版未登録は区別して表示します。0.8.1ではGoogleが返す学校ドメイン形式の接続URLにも対応しました。

13個の補正マークを保った配置版 `editor-compact/4` です。配置版を更新した用紙はQRの用紙版・定義ハッシュでも区別します。既存の読取・PDF生成側とは未接続で、印刷は確認用です。配付版の登録・PDF位置検査・実機試験は今後行います。

接続・保存関連52件とDOM模擬操作15件を検査しました。Chromeで本人限定GASへ接続し、架空用紙の保存・再読込・更新と、元の下書きの保持を確認しました。Google側に保存された2版の本文ハッシュ、同じ用紙番号、数式を文字列で保持する動作も照合済みです。正式14桁QR・配付版予約はまだ組み込んでいません。実機の印刷と読取は未検証です。
