# OMR用紙エディタ 0.11.1

説明文・設問・選択OMR・数値欄・1行記入枠・自由記述欄を配置する教員向けツールです。編集内容はこのブラウザへ自動保存します。

1. 用紙を編集し、部品の設定を適用します。
2. 「保存」→「下書き保存（ブラウザ内）」で編集途中の控えを残せます。PC用のバックアップは編集可能なJSONです。
3. 用紙管理へログインし、「保存」→「版を確定して保存（クラウド）」または上部の「QR発行（版確定）」を押します。確認後、保存・QR発行・PDF検査・読み取り設定登録をまとめて行います。
4. 「PDF出力」→「確定版PDFを出力」でPDFファイルをPCへ保存できます。PDF画面で印刷してください。クラウドへPDFファイルは送りません。

「新規作成」から新規・複製、「開く」からブラウザ下書き・PCバックアップ・クラウドの確定済み版を開きます。名前の変更は各用紙タブの「︙」から行います。

QR未発行で印刷を押すと警告します。「QR発行へ進む」「QRなしで確認印刷」「キャンセル」から選びます。QRなしの用紙は読み取り用として配付しないでください。

登録後に文章・選択肢・位置・用紙設定などを変更すると、編集中の用紙は未登録へ戻ります。次のクラウド保存で新しい年度内版とQRになります。以前の確定版は保持します。変更のない再操作では版やQRを増やしません。未ログイン時は登録状態未確認として扱います。

確定時のPDFはこのブラウザに保管します。ブラウザデータを消す前にPCへ保存してください。別のブラウザなどでPDFがない場合は、確定済みの定義から同じ版・QRのPDFを再生成して配置を検査します。再生成PDFのバイト列は原本と異なる場合があり、クラウドの最初のPDFハッシュは上書きしません。PCへ保存したPDFファイルの管理は利用者が行います。「登録履歴・中断からの再開」も利用できます。

QRは数字14桁、通常QR Version 1（21×21）・誤り訂正H、四辺4セル余白を含む26mm角です。校章や個人情報は含みません。補正用■は13個。A4・JIS B5・JIS B4の縦横を設計対象とし、実機印刷・スキャンの合格を意味しません。

現在は本人限定の用紙管理に対応します。手書き文字の自動読取とDocs編集済み・外部PDFの検査登録は未対応です。ブラウザのPDF表示・印刷設定は利用環境でも確認してください。
