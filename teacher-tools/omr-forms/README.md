# 用紙エディタ 0.4.0 公開プレビュー

[教員用ツール一覧](../)から利用できます。テキスト・自由記述・選択OMR・桁別数値の用紙を編集する試作です。

- 用紙設定・ページ一覧・部品一覧・書き出しは右端の縦タブから開きます。右パネルは幅を調整できます。
- 学年は氏名の上に中1〜高3を表示し、固定学年の事前マークも設定できます。組・番号と得点の数字見出しは各列の上にまとめます。
- 部品はドラッグで移動し、四辺・四隅からサイズ変更できます。選択部品の編集枠で外枠の印刷有無、選択肢の表示名と内部コード、文字書式を設定できます。
- 変更はブラウザへ自動保存し、再読込で直前の用紙・ページ・倍率を開きます。「ブラウザに保存」は別の明示保存です。ファイルメニューの「ブラウザから開く」で両方の候補を選べます。
- 選択肢などの未適用入力もブラウザに控えを保存します。「適用」で紙面へ反映します。ブラウザの保存領域を消した場合や別の端末・ブラウザには引き継がれません。
- 設定の「入力候補・新規用紙の初期値」で教科・分類の候補と用途等の初期値を変更できます。設定はこのブラウザだけに保存します。
- 片面・両面は用紙設定で選び、印刷ダイアログ側でも同じ方式を指定してください。両面では奇数ページが表、偶数ページが裏です。

**GAS・GSSは未接続です。** 公開版から学校の保存先へ送信しません。テンプレートは架空の編集例です。

13個の補正マークを保っていますが、ヘッダー位置を変更した新配置版 `editor-compact/1` です。QRの用紙版と定義ハッシュで区別します。既存の読取・PDF生成側との接続は行っておらず、印刷は確認用です。正式な配付版の登録、PDF位置検査、実機印刷・スキャンの検証は今後行います。

ローカルのモデル・保存試験、DOM模擬操作、6種類の紙面画像の検査を実施しました。実ブラウザ・実GAS/GSS・実機での印刷と読取は未検証です。
