# OMR用紙エディタ 0.15.1

説明文・設問・選択OMR・数値欄・1行記入枠・自由記述欄を配置する教員向けツールです。変更は用紙ごとにブラウザへ自動保存します。

「連続マーク欄」で、通常のマーク試験のように複数の設問をまとめて配置できます。初期値は10択×20問・2列です。右パネルでは選択肢の概要と「選択肢を編集…」、設問数、開始番号、段組を表示します。「選択肢を編集…」を押すと右パネル内で専用画面へ切り替わり、紙面を見ながら編集できます。

「プリセットから作る」を開いて、数字の0/1始まり、英大文字、小文字、数字＋英字、個数、追加記号を指定し、「一覧を作成・置き換え」を押します。数字＋英字の16個は0〜9とA〜F（またはa〜f）です。記号の+・−・±は生成数に追加され、合計を表示します。作った一覧はそのまま表示名・内部コードを編集でき、モードの切替はありません。各行の左の⋮⋮をドラッグすると、表示名と内部コードを一緒に並べ替えます。⋮⋮にフォーカスして↑↓/Home/Endキーで移動できます。内部コードは振り直しません。追加・削除にも対応します。 各選択肢は「⋮⋮・表示名・内部コード・削除」を1行で並べます。行ごとの見出しと↑↓ボタンは表示しません。

「適用して戻る」で選択肢を下書きと紙面へ反映し、通常設定での再適用は不要です。「キャンセル」は編集中の一覧を取り消し、元の選択肢と紙面を保ちます。見出し・位置など、通常設定の未適用入力も保持します。収まらない設定や不正なコードは、紙面を変えず専用画面に残します。別の部品・用紙へ切り替えた場合は入力をブラウザに控え、同じ部品の専用画面で復元できます。選択肢の適用だけではクラウドへの版確定・QR発行を行いません。

選択肢は記号を含めて2〜40個、1部品1〜100問、1ページ合計200問、段組は設問数以下の1〜4列です。各列を上から下、左の列から右の列へ続けます。各設問は独立した単一選択です。部品の必須設定は全設問に適用します。設問番号と内部IDは別で、開始番号や段組を変更してもIDを保持します。設問数を減らして適用した後の再追加では末尾のIDを新しく作ります。

楕円は枠線込みで縦4.2×横3.0mm、縦横比1.4です。選択肢・設問の間は、外側同士を1.5mm以上離します。選択肢の見出しは楕円の上にまとめ、中は空白にします。部品枠を縮小しても楕円は縮小せず、収まらない設定は適用しません。別ページに続ける場合は次の開始番号で別部品を作ります。連続マーク欄自体の自動採点・得点合計は行わず、得点指定は従来の数値部品を使います。

連続マーク欄は作成・保存・印刷に対応し、楕円の読み取りは未対応です。読取定義は楕円対応が必要な別形式で登録するため、従来の読取処理が欄を無視して処理することはできません。実機印刷・スキャンによる読取精度は未検証です。

1. 部品を選び、右の編集パネルから設定します。上下左右の余白をmmで変更できます。1行記入欄は記入枠自体の幅・高さも指定でき、空欄なら部品の内側に合わせます。「設定を適用」で紙面へ反映します。
2. 「保存」→「下書きを保存（ブラウザ内）」は自動保存とは別の控えです。「バックアップを保存（PC）」は再編集できるJSONファイルです。
3. 「QR発行（版確定）」から手順画面を開くと、画面内のiframeでGoogleログイン状態を確認します。この確認だけでは保存・発番しません。「QRを発行して登録」を押すと、ログイン状態の再確認、現在の内容の保存、QR発行、PDF検査、読み取り設定登録をまとめて行います。未ログインの場合は学校アカウントで別画面にログインし、同じボタンから再試行します。Googleの仕様上、新しいログイン操作はiframe内で行えません。
4. 登録完了後は同じ画面で「印刷用PDFを開く」「PDFをPCに保存」を選べます。PDFはDriveへ送りません。PDF画面で用紙サイズ・100%・片面/両面を確認して印刷します。

「数値入力（手書き）」は、正方形のマスを横につなげた手書き用の部品です。初期値は3マス・1辺8mmで、右パネルから1〜20マス・1辺6〜20mmに変更できます。見出し・設問テキスト・余白・部品の外枠も設定できます。部品全体の幅・高さを変えてもマスは伸縮せず、正方形を保ちます。収まらない設定は拒否して入力の控えを保持します。紙面には「数字を1マス1字」と表示します。

現在の数値入力（手書き）は記入用の枠です。手書き文字の自動読取・数値への変換・採点は行いません。マス数・寸法・文字種「数字」は用紙定義としてクラウドへ保存します。枠の形や色だけから種類を推測しません。

数値部品は「数値入力（マーク）」「数値入力（手書き）」の2種類です。どちらも右パネルの「得点として使用する」で得点欄にできます。得点指定は全ページを通じて最大1個で、指定しない用紙も作れます。別の部品へ付け替える際は、現在の得点欄を表示して確認します。年組番の識別欄は対象外です。

得点指定時は「満点」を入力します。桁数に収まる1以上の整数を指定し、数値範囲は0から満点へ揃います。100点を扱う場合は3桁以上にしてください。紙面にも満点を表示します。手書きでは得点以外にも任意で数値範囲を保存できますが、自動認識は未対応です。未記入を0点に変換しません。

得点欄やそのページを削除すると指定を解除し、「元に戻す」で復元できます。用紙全体の複製やバックアップでは、指定を保った独立した用紙として扱います。新しい小テストテンプレートは得点欄を1つ指定済みです。保存済みの用紙に、見出しや用途から勝手に得点指定を追加しません。

数値入力（手書き）の外周は実線、マス間の区切りは点線です。以後生成する紙面へ反映し、保管済みの確定版PDF原本は差し替えません。

「開く」→「下書きを開く（ブラウザ内）」では、用紙ごとの自動保存・明示保存・競合復旧用の控えを選べます。開いている用紙は選択し、明示保存や古い内容はコピーとして開けます。別の用紙の編集を自動で置き換えません。タブ内の「︙」から名前の変更とタブを閉じる操作ができます。閉じても保存データは残ります。

不要な用紙のブラウザ内データは、タブを閉じてから保存一覧の「保存データを削除」で整理します。対象の自動保存・明示保存・未適用入力・復旧用の控えを確認して削除します。別の用紙、PCファイル、クラウドの確定版とPDF原本は対象外です。未確認のクラウド保存結果や別画面の更新がある場合は削除を止めます。削除前の画面からデータが戻らないよう、内容を含まない削除記録を残します。

読み取り設定はQR発行時にクラウドへ自動登録されます。通常の印刷に設定ファイルの書き出しは不要です。右端「書出」の「管理者向け：設定JSONを書き出す」に、登録済みQR・OMR座標・選択肢コードを渡すための読取設定JSONと、編集中のレイアウトだけを保存する開発用JSONを置いています。再編集用バックアップには保存メニューを使ってください。

登録後に文章・選択肢・余白・位置・寸法・用紙設定を変更するとQR未発行の下書きになり、次のクラウド保存で新しい年度内版を確定します。以前の版は保持します。変更なしの再出力では版・QRを増やしません。登録中の通信失敗は同じ要求から再開します。

確定時のPDFはブラウザ内に保管します。別のブラウザなどで原本がない場合は、確定済み定義から同じ版・QRのPDFを再生成して検査し、原本とは別に保管します。クラウドの最初のPDFハッシュは上書きしません。PCへ保存したファイルの管理は利用者が行います。

QRは数字14桁、通常QR Version 1（21×21）・誤り訂正H、四辺4セル余白を含む26mm角です。校章・個人情報は含みません。補正用■は13個です。A4・JIS B5・JIS B4の縦横を設計対象とし、実機印刷・スキャンの合格を意味しません。

番号のマーク欄とQRの間に、小さく薄い「（十の位）」「（一の位）」を表示します。組の0・9と番号の十の位の5〜9は、記入案内として○を薄く表示します。01〜09に使う十の位の0と、一の位の0〜9は通常表示です。マーク位置・読み取り設定・受付範囲は変えません。既に保管した確定版のPDF原本は差し替えません。

部品の移動・縮小・設定適用は本文領域と最小寸法へ制限し、版の確定前にも300dpiの描画像素から文字・記入枠の収まりを検査します。内容を切り取って隠したり、自動で短縮したりしません。

現在は本人限定の用紙管理に対応します。手書き文字の自動読取とDocs編集済み・外部PDFの検査登録は未対応です。QRなし確認印刷は編集確認用です。配付用には登録済みPDFを使用します。実ブラウザの表示・印刷と実スキャンは利用環境での確認が必要です。
