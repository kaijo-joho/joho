発展CSSの試し方

このページでは、自由製作に取り入れやすいCSSを、値を変えながら試すことができます。作りたい表現に近い実例を選び、操作したときの変化と表示されるCSSを見比べてみましょう。

  1. スライダーや選択欄で値を変える
  2. プレビューで変化を確かめる
  3. 表示されたCSSから、必要な指定を自分の作品へ取り入れる
  4. さらに工夫したいときは、各実例の「検索語」を使って調べる

ページの幅と余白

max-widthで本文が広がりすぎないようにし、左右のmarginをautoにすると、内容を中央に配置できます。paddingは内容と端の間に余白を作ります。

値を変えてみる
600px
24px

SPOT GUIDE

海辺の展望台

最大幅を小さくすると文章の折り返しが増えます。余白を変えると、内容と枠の距離が変わります。

.page {
  box-sizing: border-box;
  max-width: 600px;
  margin: 0 auto;
  padding: 24px;
}

検索語：CSS max-width margin auto ページ 中央

写真の見せ方

aspect-ratioで写真を表示する枠の比率を決め、object-fitで枠に合わせた表示方法を選べます。object-positionを変えると、切り取る位置を調整できます。

値を変えてみる
560px
50% 
.hero-image {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
  object-position: 50% center;
}

検索語：CSS object-fit aspect-ratio 画像 トリミング

Flexboxによる横並び

display: flexを使うと、複数の要素を横や縦に並べられます。gapで要素間の距離を決め、flex-wrapを使うと、入りきらない要素を次の行へ送れます。

値を変えてみる
600px
16px
180px
01景色眺めを紹介
02歴史背景を紹介
03アクセス行き方を紹介
.spot-list {
  display: flex;
  flex-direction: row;
  gap: 16px;
  flex-wrap: wrap;
}

.spot-card {
  flex: 1 1 180px;
}

背景色・余白・角の丸み・影を組み合わせると、情報のまとまりをカードのように見せられます。それぞれの値を変え、印象の違いを比べてみましょう。

値を変えてみる

HIGHLIGHT

夕暮れの景色

色や余白、角の丸み、影の組み合わせによって、同じ内容でも印象が変わります。

画面幅に応じたレイアウト

@mediaを使うと、画面幅に応じてCSSを切り替えられます。表示領域の幅と切り替え位置を動かし、2列から1列へ変わる境目を確かめてみましょう。

値を変えてみる
640px
520px

現在は2列表示です。

VIEW POINT

街を見渡す丘

広い画面では写真と文章を横に並べ、狭い画面では縦に並べます。

.spot-layout {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 20px;
}

@media (max-width: 520px) {
  .spot-layout {
    grid-template-columns: 1fr;
  }
}

検索語：CSS media query レスポンシブ Grid 1列

リンクの反応

:hoverはマウスポインタを重ねたとき、:focus-visibleはキーボード操作などでフォーカスが見えるときのスタイルです。動く距離と変化にかける時間を調整できます。

値を変えてみる
3px
200ms
詳しい見どころを見る → 
.detail-link {
  transition: transform 200ms ease,
              background-color 200ms ease;
}

.detail-link:hover,
.detail-link:focus-visible {
  transform: translateY(-3px);
  background-color: #17456f;
}

検索語：CSS hover focus-visible transition リンク

ul・olのデザイン

list-style-typeで箇条書きの記号や番号を選べます。::markerを使うと、記号や番号だけに色や太さを指定できます。

値を変えてみる
32px

ul：順序のない一覧

  • 季節の景色
  • 展望スポット
  • 地元の名物

ol：順序のある一覧

  1. 駅を出発する
  2. 参道を歩く
  3. 展望台に到着する
.feature-list,
.route-list {
  padding-left: 32px;
}

.feature-list {
  list-style-type: square;
}

.route-list {
  list-style-type: decimal-leading-zero;
}

.feature-list li::marker,
.route-list li::marker {
  color: #c14f2b;
  font-weight: bold;
}

検索語：CSS list-style-type marker ul ol

details・summaryのデザイン

summaryはクリックできる見出しです。details[open]を使うと、開いているときだけ見た目を変えられます。「最初から開く」を切り替えて、HTMLのopen属性の働きも確かめましょう。

値を変えてみる
12px
おすすめの時間帯

夕暮れ前に到着すると、昼の景色と夕景の両方を楽しめます。

.spot-details {
  border: 2px solid #225386;
  border-radius: 12px;
  overflow: hidden;
}

.spot-details summary {
  padding: 12px 16px;
  background-color: #225386;
  color: white;
  cursor: pointer;
}

.spot-details[open] summary {
  border-bottom: 1px solid #225386;
}
