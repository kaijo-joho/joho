(1) ハードウェアとソフトウェア

物理的な装置がハードウェア、それを動かすプログラムがソフトウェアです。

応用ソフトウェア

文書を書く、Webページを見るなど、特定の目的のために使います。アプリケーション（アプリ）とも呼びます。

例：Safari、Google Chrome、Word、Illustrator。

基本ソフトウェア（OS）

コンピュータ全体を管理し、アプリがハードウェアを利用するための共通の仕組みを提供します。

例えば、アプリがファイルを保存するとき、OSの機能を利用してSSDへ書き込みます。

ハードウェア

CPUやメモリなど、コンピュータを構成する物理的な装置です。

同じコンピュータでも、動かすソフトウェアによって、文書作成や音楽再生など異なることができます。

スマートフォンも、ハードウェア・OS・アプリの組み合わせで動いています。

(2) OSの役割

OSは、CPU・メモリ・周辺機器などの資源（リソース）を管理し、複数のアプリや利用者を支えます。

タスク管理

処理の実行順序やCPUを使う時間を割り当てます。音楽を聴きながら文書を書くなど、複数の処理を進められるようにします。

文書音楽文書音楽

図は1つのコアで時間を分ける例です。複数のコアで同時に処理する場合もあります。

メモリ管理

各アプリに主記憶装置の領域を割り当て、利用状況を管理します。

OS文書アプリブラウザ空き

模式図です。実際の領域の配置や容量の比率を示したものではありません。

入出力管理

キーボードの入力を受け取ったり、プリンタへ印刷データを送ったりして、周辺機器とのやり取りを管理します。

アプリ ↔ OS・ドライバ ↔ 周辺機器

ファイル管理

ファイルの作成・保存・読み込み・削除や、フォルダによる整理を管理します。

保存したいデータ → ファイル → 保存場所

ユーザー管理

ログインする利用者を区別し、ファイルや機能を使える範囲（権限）を管理します。

利用者の確認 → 許可された機能・ファイルを利用

これらは関連し合っています。CPU・メモリ・機器などの割り当てをまとめて「資源管理」と捉えられます。

(3) ファイルとフォルダ

データはファイルとして保存し、フォルダで整理します。フォルダの中にフォルダを置くと、階層構造になります。

例：授業 → 情報 → レポート → 原稿.docx。授業 → 英語 → レポート → 原稿.docxとは、名前が同じでも保存場所が異なります。

これは教材内だけの模型です。実際のファイルを開いたり、書き換えたりはしません。情報と英語の「原稿.docx」を探してみましょう。

(4) 拡張子とファイルの種類

レポートファイル名の本体.docx拡張子は docx

拡張子は、ファイルの形式を表す目印です。末尾のドットの後に付きます。

文書・表・発表資料

txt / pdf
文字中心のデータ / レイアウトを保って配る文書
docx / xlsx / pptx
Word文書 / Excelブック / PowerPoint資料
csv
項目をカンマなどで区切ったテキストデータ

画像

jpg / png / gif
写真やイラストなどの画像で使う形式
bmp
ビットマップ画像の形式の1つ
ai
Illustratorで編集する図形やイラストのデータ

音・動画

mp3 / wav / aif
音声データで使う形式
mid
音の高さや長さなど、演奏の情報を記録する形式
mp4 / mov / avi
動画などを格納する形式

Webページ・圧縮ファイル

html
Webページの構造や内容を記述したファイル
zip
複数のファイルなどをまとめて圧縮できる形式

拡張子は形式の目印であり、中身が安全であることを保証するものではありません。

名前の末尾を書き換えるだけでは形式は変換されません。変換には対応するアプリでの書き出しなどが必要です。

(5) 語句まとめ・ポイントまとめ

語句を選ぶと説明が開きます。身近な例を1つずつ挙げてみましょう。

ハードウェア・ソフトウェア

ハードウェアは物理的な装置。ソフトウェアは、それを動かすプログラム。

基本ソフトウェア（OS）

コンピュータ全体を管理し、アプリの実行やハードウェアの利用を支える。

応用ソフトウェア（アプリ）

文書作成、Web閲覧など、特定の目的のために使うソフトウェア。

タスク・メモリ・入出力の管理

処理へのCPUの割り当て、主記憶装置の領域の割り当て、周辺機器とのやり取りを管理する。

ファイル・ユーザーの管理

ファイルの保存や整理、利用者や権限を管理する。

ファイル・フォルダ・階層構造

ファイルはデータを保存する単位。フォルダでまとめ、入れ子にして階層的に整理する。

拡張子

ファイル名の末尾で形式を示す目印。書き換えるだけでは中身の形式は変わらない。

3つのポイント

  1. ハードウェア・OS・アプリを区別する。
  2. OSの働きを、普段の操作と結び付ける。
  3. ファイルは名前・保存場所・形式を意識して扱う。

デバイスドライバとユーザーインタフェース

デバイスドライバ

プリンタなどの周辺機器を動かすためのプログラムです。OSなどと、その機器に合った方法でやり取りする部分を支えます。OSに標準で含まれるものもあります。

ユーザーインタフェース（UI）

人がコンピュータへ指示し、結果を受け取るための接点です。アイコン・メニュー・ウインドウなどを使うGUIや、文字でコマンドを入力する操作方法があります。UIはOSにもアプリにもあります。

Macで拡張子を表示する

  1. Finderを開きます。
  2. メニューバーの「Finder」→「設定」を選びます。
  3. 「詳細」で「すべてのファイル名拡張子を表示」を選びます。

拡張子を表示・非表示にする設定は、ファイルの形式を変えません。
