# 座学ワークシート Webアプリ

## 役割

生徒には空欄のプリントを授業中に配付する。なくした場合はWebアプリで再印刷し、教員が指定した時期以降にクリックで解答・解説を確認する。

HTML本文・SVGはGASプロジェクト「座学ワークシート」（ローカル短縮名`ws`）で直接保守する。初期版ではGSSを教材本文の正本にはしない。A4縦2ページ・10.5pt、B5縮小配付の書式は既存HTMLワークシート仕様を継承する。

## サイトとの紐付け

「配付ファイル一覧」の`ページ一覧.worksheetApp`にはURLでなく`dr31`のようなIDを入力する。複数の場合は空白なしの半角カンマ区切り。対応する`ワークシート一覧`は次の列を持つ。

| 列 | 例・用途 |
| --- | --- |
| worksheetId | `dr31`。先頭列・重複不可 |
| title | `3-1. 音のデジタル表現 ワークシート` |
| release | サイトへのリンク表示。初期登録はFALSE |
| url | GASのデプロイURLに`?id=dr31`を付ける |
| description | リンクの説明 |

GAS `fl` の`run_previewPagesJsGeneration()`で差分を確認後、`exportData_to_pages_js()`で生成する。`js/pages.js`は手で編集しない。座学表紙、LessonDock、講座の教材一覧が`worksheetApp`を使用する。印刷済みPDFの配付リンクは従来の`practiceFile`として別に管理できる。

## 解答公開の設定

「課題設定」に以下の対応を設定する。日時は日本時間で、数式の文字列ではなくシート上の日付・時刻値を使う。

| 項目 | 内容 |
| --- | --- |
| year / grade | 対象年度（4月始まり）・対象学年 |
| item | `ws` |
| targetId | `dr31`などのworksheetId |
| subTargetId | 空欄 |
| status | 採点しないワークシートでは`practice`。`active`も閲覧可 |
| standardDueAt | この日時を過ぎたら解答・解説を公開（同時刻は未公開） |
| startAt | 設定する場合はstandardDueAt以下。問題自体の印刷開始は制限しない |
| finalDueAt | 既存の提出期限用。ワークシートの解答終了日時にはしない |

年度・学年・item・targetIdが一致する行は1行だけにする。同じ学年に学期違いの重複行があっても解答は開かない。未設定・不正日時・GSS読取障害では解答は非公開、問題は印刷できる。教員は既存Commonの教員判定で常時確認できる。閲覧日時を変えるだけならGAS再デプロイやpages.js再生成は不要。

`課題設定.item`の選択肢に`ws`を追加し、title/description/urlの既存参照式も`ワークシート一覧`に対応させている。既存の授業予定からの自動追加・採点は今回拡張していない。初期版では教員が対象行を手動設定する。

## 教材別の正本と確認事項

- **dr31**: 2026-09-09にユーザーが確認し校了。GAS版の本文・解答を正本とし、別教材の追加に伴って変更しない。62解答・4解説。
- **dr32**: 原稿「音のデジタル表現.pdf」の10〜13ページ（対応するPPTMの49〜52枚目）に沿って作成。表面はチャンネルの3図と例題2問、裏面はデータ量の演習3問。24解答・7解説。図は独自SVGで、スライド内の第三者画像を転載しない。
- dr32の例題1は1 KB＝1000 B。裏面の演習は1 KB＝1024 B、1 MB＝1024 KBと明記する。周波数のkHzは1000 Hzとして扱う。整数指定は最後に小数第1位を四捨五入し、途中で丸めない。
- dr32の解法は、解説ダイアログ内の「次へ」で式の項を順に増やし、最後に約分・計算・丸めを確認する。紙面には式の記入欄を確保し、数値・式の解答欄には括弧付き番号を付けない。
- 小見出しは節見出しと本文の中間（節0 mm、小見出し2 mm、本文4 mm）。faviconはGASの`HtmlOutput.setFaviconUrl()`でCommonの共通アイコンを適用する。
- 静的な試作`dr31_ws.html`は、GAS版の校了後、ユーザーの指示により削除する。教材ページ`dr31.html`・`dr32.html`は削除しない。旧静的版はGit履歴から復元可能であり、過去の解答の秘匿は保証しない。
- 新しいワークシートの登録時も`release=false`を維持し、`課題設定`の年度・学年・解答公開日時は教員の指定なしに設定しない。校了とサイトへのリンク公開は別の判断とする。

## セキュリティと運用上の限界

- 学校ドメイン内限定・デプロイ教員として実行。初回にメールアドレス確認とスプレッドシート読取の認証が必要。
- 初期HTMLは常に問題のみ。解答操作はサーバーで再認証・GSS再照合してから、許可された解答データを返す。利用者の学年・教員フラグ・判定日時をブラウザから受け取らない。
- 個人情報や課題設定の内部メモはブラウザへ返さない。解答データや認証情報をGitHub Pages側へ配置しない。
- すでに公開・保存・印刷された解答を後から回収することはできない。静的版の旧Git履歴もアクセス制御の対象外。
- サーバーPDF生成、回答保存、採点、本文のGSS編集、解答の自動回収は対象外。

GASでHTMLをサーバー評価する仕組みは[GoogleのHTMLテンプレート仕様](https://developers.google.com/apps-script/guides/html/templates)に従う。
