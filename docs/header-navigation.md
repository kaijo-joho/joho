# ヘッダーの共通ナビゲーション

2026年9月9日、実習・座学の操作位置を統一し、本文と重なる右下のLessonDockと左端の目次ハンドルをヘッダーへ移した。教材本文、ページの公開設定、配付物の設定は変更しない。

## 配置と役割

通常表示の順序は、教材名、教材（書類アイコン）、検索、文字サイズ、テーマ、座学の全画面アイコンとする。教材・検索と表示設定の間に間隔と区切りを置き、アイコンの操作領域は44pxに揃える。

- 教材名は「デジタル表現 ▾」のように表示し、同じシリーズの関連ページ一覧を直下へ開く。ページ自体へは直接遷移しない。
- 教材は、現在のページに紐付くワークシート、実習ファイル、演習問題、確認テスト、ダウンロード、次回を名前付きでまとめる。対応する項目がない区分は生成せず、すべて空なら書類アイコンも生成しない。
- 検索アイコンは、クリック・タップ・Enter・Spaceで「検索・よくある質問」dialogを直接開く。マウスホバーではパネルを開かず、ツールチップだけを表示する。dialogを閉じたらヘッダーの検索アイコンへフォーカスを戻す。
- dialogは「よくある質問」を既定表示とし、「教材サイト内検索」とタブで切り替える。FAQ検索は既存の`faq.html`へ検索語と対応する講座を渡し、ページに関連する質問の開閉とFAQ一覧へのリンクも同じdialog内で利用できる。講座を特定できない座学・トップページなどでは、講座を限定しないFAQ検索を表示する。サイト内検索UIが利用できない場合はFAQ専用の小メニューへフォールバックする。処理の責務は[教材サイト内検索](site-search.md)を参照する。
- 文字サイズとテーマの3択、選択状態、保存先は既存仕様を保つ。
- 1050px以下では学校名と操作列を2段にする。操作列の教材名は利用可能な幅へ縮め、省略時も読み上げ名に全文を残す。各パネルは左右8pxの内側へ補正し、長い一覧はパネル内で縦スクロールする。390pxでも本文の上に常設ボタンを重ねない。

## 教材名の関連ページ一覧

`js/nav.js`は`pages.js`の現在ページと同じ`mainTitle`を持つ`release: true`のページを参照する。公開されているシリーズ目次（`py00`、`html00`、`dr00`等）があれば先頭へ「シリーズの目次へ」を置く。

その他のページは`show: false`を除外し、データの定義順と`category`の区分を保つ。現在のページがあるカテゴリは初期展開し、リンクを太字・左罫線・`aria-current="page"`で強調する。カテゴリはネイティブの`details/summary`で開閉する。タイトルはテキストとして生成し、HTMLを埋め込まない。

トップページでは関連ページ一覧を生成しない。直接URLで開いた未掲載ページも他ページへのリンク公開を変更せず、公開済みの関連ページだけを示す。公開済み関連ページがなければその旨を表示する。設定の正本は[ページ一覧のデータフロー](page-list-data-flow.md)を参照する。

## 共通の開閉

`js/script.js`の`window.siteHeaderMenus.bind`を、関連ページ一覧・教材メニュー・文字サイズ・テーマ・全画面開始メニューで共有する。個別のJavaScriptへホバーや閉じる処理を複製しない。検索アイコンはメニューではなくdialogを直接開くため、この共通バインドの対象外とする。

- マウスのホバーは180ms後に開く。クリック・タップ・Enter・Spaceでも開閉でき、ホバー直後の最初のクリックは開いた状態を保つ。
- パネルへポインターを移しても閉じない。離れて300ms後に閉じるが、内部にキーボードフォーカスがある間は閉じない。
- 上下矢印で開いて先頭・末尾の項目へフォーカスする。リンク一覧はTab・Shift+Tabで移動し、表示設定は既存の矢印キーによる選択も保つ。
- Escapeで閉じて入口へフォーカスを戻す。外側のクリック、フォーカスが外へ移った場合、他のパネルを開いた場合も閉じる。
- 開くときに`joho:overlay-open`を送出し、検索dialogや補足dialogとも排他的にする。検索dialog側から開く場合も同じイベントを送出する。
- `aria-expanded`と`aria-controls`を同期する。閉じた内容は`hidden`によりTabと読み上げの対象から外す。再初期化では旧イベントを解除し、同じ入口を重複生成しない。

## 座学の全画面表示

ヘッダーの全画面アイコンは開始メニューを開くだけとする。「スライドを全画面表示」のクリック・タップ・Enter・Spaceを受けてFullscreen APIを呼ぶ。ホバーだけで全画面へ切り替えない。

全画面中はヘッダー全体を隠し、上部に常設するのは前後移動、スライド選択、全画面終了だけとする。教材・検索・関連ページ一覧・表示設定の入口は通常表示へ戻って使う。終了アイコンは1クリックで戻り、ブラウザ標準のEscによる終了も維持する。

現在スライド・URLハッシュ・教材の操作状態を保持する。終了時はアイコンを元のヘッダーへ戻してフォーカスする。要求拒否では通常表示を維持し、エラーと再試行できる入口を残す。詳細は[座学共通スライド基盤](lesson-slide-deck.md)を参照する。

## 実装ファイルと検証

- `js/script.js`・`css/header.css`: 共通メニューの操作・見た目、表示設定。
- `js/nav.js`・`css/nav.css`: 教材名から開く関連ページ一覧。
- `js/lesson_dock.js`・`css/lesson_dock.css`: 既存のデータ解決・FAQ処理を使う教材メニューと、検索dialogへ渡すFAQ内容。
- `js/lesson-slide-deck.js`・`css/lesson-slide-deck.css`: 全画面開始メニューと終了時の復帰。

通常の構文検証、`test-lesson-slide-pages.mjs`、`test-logic-applications.mjs`、`test-sound-pages.mjs`に加え、リンクを扱う変更では`test-page-links.mjs`と`test-worksheet-links.mjs`を実行する。

ブラウザ回帰検証は、Chrome・WebKitを起動できるPlaywrightとローカルHTTPサーバーを用意して実行する。Playwrightを外部の依存環境へ置く場合は、その`node_modules`を`NODE_PATH`で指定できる。

```sh
python3 -m http.server 8884 --bind 127.0.0.1
# 別のターミナルで実行。別ポートの場合はJOHO_TEST_URLを変更する。
JOHO_TEST_URL=http://127.0.0.1:8884/ node scripts/test-header-navigation.mjs
```

この検証では、実習・座学のメニュー、各座学ページの実際の全画面API、デスクトップ・半画面・390px、テーマと文字サイズの組合せ、キーボード・タッチ、フォーカス保持・復帰、公開リンク除外、要求拒否を確認する。Safariアプリ自体での確認と、PlaywrightのWebKitによる確認は区別して報告する。
