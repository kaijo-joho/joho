# 座学ワークシートの共通書式

## 目的

`dr`・`lc`などの座学ページと併用する印刷ワークシートは、ウェブ教材をそのまま紙へ写すのではなく、操作前の予想、操作結果の記録、語句の手書き、要点整理を補う教材として作成する。

書式の正本は[`templates/worksheets/lesson-worksheet-b5.docx`](../templates/worksheets/lesson-worksheet-b5.docx)とする。このファイルは、教員が調整した「3-1. 音のデジタル表現」の構成と書式を保持した参照テンプレートであり、そのまま別単元へ配付せず、コピーして内容を置き換える。

## 基本仕様

- 用紙はJIS B5縦、両面印刷の2ページで完結させる。
- 余白は上下約6.5 mm、左右10 mmを基準とする。
- 本文は游明朝9 pt、見出し・タイトル・表見出しなどの強調は游ゴシック9 pt太字とする。
- 文字色は黒を基本とする。見出しの下へ装飾線を置かない。
- 表の罫線は薄いグレー、見出しセルは淡い青灰色、本文セルは白を基本とする。
- タイトルは`章-節. 単元名`とし、同じ行の右側へ学年、組、番号、氏名の欄を置く。
- 本文見出しは`1  見出し`のように番号を付ける。
- 語句は語群から選ばせず、すべて手書きの穴埋めにする。
- 記入欄は9 ptの印刷文字が収まるだけでなく、生徒が鉛筆で書ける幅と高さを確保する。
- グレースケール印刷でも図、見出し、記入欄を区別できるようにする。

## 標準的な構成

表面は次の順を基本とする。

1. タイトルと生徒情報
2. ウェブ教材と併用する目的を示す短い導入
3. 単元の基本概念を確認する穴埋め
4. 工程や関係を整理する図・表
5. ウェブ教材の図を読み取る記録欄
6. 操作前の予想と操作後の気づきを書く欄

裏面は次の順を基本とする。

1. 単元固有の主要な原理・法則
2. 語句まとめ
3. ポイントまとめ
4. 必要な場合のみ問題演習

単元の内容に合わない欄は無理に残さない。余白を埋めるために説明文や問題を増やすこともしない。

## 部品の使い分け

### 工程図

状態と工程を横方向に並べる。最初の状態は明記し、生徒が学ぶ工程名は穴埋めにする。矢印は独立した細いセルへ置く。

### 条件欄

操作や計算で対応関係を確認する値を一列に並べる。値を単独で暗記させず、周波数と周期、ビット数と段階数など、対応する項目を隣接させる。

### 図と記録表

図は横長で本文幅内に収め、必要な軸、目盛り、補助線を示す。図の直後に対応する記録表を置き、同じ位置・時刻・対象を同じ列で読めるようにする。

### 予想と観察の表

「操作」「操作前の予想」「操作後に分かったこと」の3列を基本とする。選択肢で予想させた場合も、結果欄は文章や数値を手書きできる広さにする。

### 語句まとめ

「番号」「語句の記入欄」「説明」の3列とする。説明を読んで語句をすべて手書きさせ、語群は掲載しない。行数は単元の語句数に合わせて増減する。

### ポイントまとめ

2列の表を基本に、公式、条件、処理の順序などを短い穴埋めで整理する。本文の言い換えだけになる項目は置かない。

## 作成手順

1. 参照テンプレートを別名でコピーする。
2. タイトル、生徒情報、導入文、見出しを単元へ合わせて変更する。
3. 必要な表や図の構造を残し、不要な部品を削除する。
4. 語句とポイントをウェブ教材の表記へ揃える。
5. B5縦の表裏2ページに収まるよう調整する。本文を削る前に、段落前後、図の高さ、表の行高を小さく調整する。
6. Word上で印刷レイアウトを100%表示し、表の分割、文字欠け、重なり、3ページ化がないことを確認する。
7. B5両面印刷の短辺とじを想定し、表裏の向きと余白を印刷プレビューで確認する。

## 検証上の注意

游明朝・游ゴシックがない環境では代替書体の字幅によって改ページ位置が変わる。参照テンプレートはMicrosoft Wordの保存情報では2ページだが、代替書体を使うLibreOfficeでは表面末尾の1行が独立したページへ送られることがある。最終的なページ数と印刷配置は、游書体を利用できるWord上で確認する。
