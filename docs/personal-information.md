# 情報社会（IS）：個人情報とプライバシー

2026-10-02にAstraが構成を設計し、本人承認の範囲で制作した2ページ。知的財産権3ページとは別に検証し、検証後はrelease:false・show:falseで確認用公開する。オンライン確認後の本人了承前にrelease:trueへ変更したり、他教材からリンクしたりしない。

## 教材構成

- `is31.html`「3-1. 個人情報とプライバシー」：本文6枚。個人情報の定義、属性の組合せ、個人識別符号と要配慮個人情報、プライバシー等、共有前の確認、8語のまとめ。
- `is32.html`「3-2. 個人情報の保護と活用」：本文7枚。保護と活用、取得・利用・管理・提供、第三者提供、本人の請求、仮名加工情報と匿名加工情報、目的に必要な情報、12語のまとめ。

調査済みPPTM「情報_授業スライド_01情報社会」の説明23・24枚目と、Google自主学習資料の11〜15枚目に対応する。PPTMの2025年固定版は未確認。問題集の設問・事例・解答、発表者ノート、原資料の図版は転載・翻案せず、体験会データと模式図を独自制作した。

## 操作と説明上の条件

is31は、架空の体験会に参加する12人を、3会場×2時間帯×2テーマの完全な組合せとして固定する。会場「東館」、時間帯「午前」、テーマ「工作」のチェックボックスをAND条件で適用する。条件なし12人、東館4人、東館＋午前2人、全部1人。東館を外して午前＋工作にすると3人となる。全12カードの順番と位置を維持し、一致／条件外の文字と実線／破線を併用する。

表示する数は教材内の集合に一致する件数であり、法的な個人情報該当判定や現実の個人を特定できる確率ではない。実在人物の入力・アップロード・照合機能を設けない。人物01等の札を法定の個人識別符号と呼ばない。

is32の主操作は仮名加工情報／匿名加工情報の比較のみ。定義を両方とも常時表示し、各状態で「もとの個人情報／加工基準／加工後の情報」と「利用／本人との照合／第三者提供」の位置を揃える。操作でデータを加工・匿名化完了にする機能ではなく、二つの法制度の基準と取扱規律を比較する。法的限定と例外を折り畳みの中へ隠さない。

本人の請求は対象・要件・例外を伴う。請求すれば必ず削除される、同意がなければ常に違法、氏名を消せば匿名加工情報になる、といった断定を避ける。統計情報と法律上の匿名加工情報も区別する。

## 実装

座学共通スライド基盤と`information-society.css`／`information-society.js`を共用する。知的財産権3ページと既存共通ファイルは変更しない。追加CSSは`css/personal-information.css`で`.is-personal`に限定し、固定データの条件操作は`js/personal-information.js`に置く。データ送信・保存・成績判定はない。

native checkbox／button、Enter・Space、フォーカス保持、状態保持、リセットに対応する。JavaScript無効時には全データ・全比較状態を読め、機能しない比較操作は表示しない。印刷でも比較の両状態を読める。各専用CSS／JSにはSHA-384 SRIを付ける。

## 検証

```sh
node --check js/personal-information.js
node scripts/test-personal-information-pages.mjs
PLAYWRIGHT_MODULE=/path/to/playwright JOHO_TEST_URL=http://127.0.0.1:8865/ node scripts/test-personal-information-browser.mjs
```

静的検査は本文枚数、見出し、ID、SRI、全8条件の件数、noJS初期表示、ローカル参照、送信・保存API不使用を確認する。ブラウザ検査はChromeとWebKit、1440／720／390px、3テーマ、3文字サイズで13枚を確認し、条件操作・比較状態・リセット・語句開閉・noJS・印刷を確認する。独立した内容レビューと目視確認を別途行う。

## 登録と確認用公開

知的財産権3ページの公開後に、正式GSS「ページ一覧」へ2ページを登録する。mainTitleは情報社会、categoryは個人情報とプライバシー、contentTypeはlecture。release・showはfalse、backはindex、nextと配付物・クイズは参照なし。既存のGASプレビュー／生成を使い、`pages.js`は編集しない。一覧・検索・関連教材・前後移動に新ページへの導線がないことと、直接URLの本文・SRIを確認する。

release:trueへの切替と教材間のリンク追加は、本人のオンライン確認と了承後に行う。
