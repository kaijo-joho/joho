## 論理回路（lc）シリーズ

- `lc02.html`は共通スライド基盤を維持しつつ、通常URLで回路エディタを初期表示する。導入説明は前のスライドから確認でき、見出しハッシュで開いた場合は指定先を優先する。
- エディタのツールバーは上段を編集操作、下段を部品追加とし、DOM・Tab順もこの順にする。狭い画面では各段内で折り返す。自由編集の整列アイコンは`js/logic-layout.js`で回路全体を入力・ゲートの段・出力の順に配置する。左右の段間隔をそろえ、縦方向は列の順序と最小間隔を保ちながら、直線になる配線数、配線の縦差、基準位置への近さの順で候補を選ぶ。ゲートから出力へ、最後に入力を調整し、未接続入力との間隔も維持する。端子の高さはエディタから`inputOffset`で渡し、ゲート形状を配置処理へ重複定義しない。配置だけを変更し、接続・種類・名前・入力値・真理値表を維持する。未完成回路と複数出力も扱い、キャンバスに収まらないときは変更せず案内する。整列はUndoで戻せ、繰り返しても位置・履歴を増やさない。
- 真理値表は初期表示し、エディタと表の境界の「▶」で折りたたみ、「◀」で再表示する。閉じたときは境界ボタンを残して回路を広げ、再表示時は現在の入力値の行を強調する。390px幅では回路・境界・表の順に縦へ並べる。開閉は回路の値・保存状態・Undo履歴に含めず、`hidden`と`aria-expanded`でキーボード・タッチでも操作できるようにする。ドラッグ中は開閉で座標系を変えない。
- 自由編集では部品の追加・移動中に、接続済み配線が直線になる端子の高さ、同じ行・列の隣接2部品と中心が等間隔になる位置、他の部品の中心の順で吸着を優先する。等間隔は2部品の間と外側への延長を扱い、入力・ゲート・出力を区別しない。逆方向の配線や途中の部品を貫通する直線は吸着候補にしない。取得は画面上7px以内、保持は14px以内とし、破線と「直線」「等間隔」のラベルで示す。部品に重なる位置には吸着せず、Alt（Option）を押しながらドラッグすると一時的に解除する。Escape・pointercancel・pointer capture喪失では元の位置に戻し、クリック時の微小な揺れでは動かさない。補助線と吸着状態は保存データ・SVG・PNGへ含めない。`enableAlignment`で自由編集だけに有効化し、`lc03`では自動整列・吸着を有効にせず、採点は変更しない。
- 自由編集の入力はA・Bから開始し、C・Dはツールバーで順に追加する。追加時に既存部品を動かさず、回路例に必要な入力は読み込み時に補う。自由編集では入力も×・選択を削除・Deleteで削除でき、接続配線と値を含めてUndo/Redoで復元する。削除した入力は追加し直せる。`lc03`の組み立て問題で指定された入力は削除できない。
- 自由編集は出力Fから始め、ツールバーの「＋ 出力」で増やす。複数のときは追加順にF₁・F₂…と命名し、真理値表は出力ごとの列を持つ。出力を削除したら連番を詰め、1つになったらFに戻す。最後の1出力は削除不可とし、追加・削除・接続・名前はUndo/Redoで復元する。全消去・テンプレートの読み込みでは出力をFに戻し、保存した回路を読み込む場合はその出力構成を復元する。複数出力の解析は`allowMultipleOutputs`による明示的な有効化とし、`lc03`の判定は従来の単一出力制約を維持する。回路の完成判定と真理値表には全出力の入力・到達ゲートを使い、未接続の出力があれば画像出力不可とする。編集データの保存は未完成でも可能とする。
- パレットのAND・OR・NOTはクリック・Enterで追加でき、回路内へドラッグすればドロップ位置に配置する。ドラッグ中はプレビューだけを表示し、回路外へのドロップ・Escape・pointercancelでは回路や履歴を変えない。パレットの安定したボタンでpointer captureし、ドロップ直後のclickによる二重追加を防ぐ。
- 配線を選ぶと接続元・接続先の端子を強調し、左端を別の出力端子へ、右端を別の入力端子へドラッグして付け替えられる。分岐元が共通でも選んだ1本だけ変更する。接続済み入力端子への新規接続・付け替えは、その端子の古い配線を置き換える。循環・逆向き・存在しない端子を検証した後に一括変更し、失敗時は両配線を保持する。1端子1配線、Enterでの接続、キャンセル、1回のUndoで置き換え前へ戻る操作を維持する。
- 選択したAND・ORゲートはツールバーから相互に交換でき、位置・接続・部品IDを保持する。入力数が異なるNOTへの交換は行わない。自由編集では交換と選択削除もアイコンにし、ホバーの説明・読み上げ名と44pxの操作領域を保つ。
- 配線は水平・垂直とし、重なりや他の部品の通過を避ける。別信号どうしの交差を避けるためだけに余分な折れ曲がりを増やさず、●は同一信号の分岐点にだけ付ける。
- 自由編集では、選択した配線の内部線分に44 CSS pxの操作領域を持つハンドルを表示する。縦線分は左右、横線分は上下へドラッグ・矢印キーで移動でき、Shiftで移動量を増やす。ハンドル上のDeleteは配線を削除せず自動経路へ戻す。部品貫通や別信号の配線との重なりは拒否し、両端の接続と別の分岐の設定は維持する。変更は内部折れ点`wire.bends`へ保存し、Undo/Redo・ブラウザ保存・JSON保存・画像出力で保持する。Escape・pointercancel・capture喪失は途中変更を破棄する。部品移動後も両端の高さへ追従し、部品に重なる間は自動経路へ退避する。端子の付け替えと自動整列では手動経路をリセットし、Undoで復元できる。ハンドルは保存図に含めず、`enableWireEditing`でlc02だけに有効化する。
- 操作説明はツールバーの「？」をクリック・タップ・Enterで開くモーダルにまとめる。導入スライドの説明と同じ`data-lesson-supplement-dialog`を共用し、非表示スライドに隠れないようbody直下へ移す。開閉・フォーカス・排他制御は座学共通基盤を使用し、ページ別に複製しない。内容は部品・配線・表示/整列・保存の4分類とする。保存・読み込み・画像出力も共通のダイアログ用スタイルを使い、Escape・背景・閉じるボタンで閉じて呼出元へフォーカスを戻す。他のメニューやスライド移動時は閉じ、ダイアログ内のキー操作を回路編集へ渡さない。
- エディタの高さは共通基盤が確保する残りの高さへ追従させ、独自の固定高さ計算で縮めない。390px幅ではボタンを折り返し、回路内をスクロールして操作し、真理値表は下へ配置する。
- 自由編集の保存・読み込みはツールバーのアイコンから行う。`js/logic-storage.js`が`localStorage`の`joho.logic-circuits.v1`へ名前付きで最大30件を保存し、`js/logic-workbench-files.js`が保存・読み込み・画像出力のUIを担当する。保存対象は部品と位置、配線、入力一覧・値で、編集中の選択やDOMは含めない。未完成回路・複数出力も復元可能とする。読み込みには保存した回路と従来の4テンプレートをまとめ、独立した回路例パネルは置かない。更新は保存画面の「上書き保存」、追加は「別の回路として保存」で明示し、同名の別データは自動上書きしない。保存データの削除には対象名を示して確認する。保存先は同じブラウザ内であり、端末間同期を行わず、閲覧データ削除で消えることを画面へ明記する。
- 全消去・別回路の読み込み前は、未保存の変更があれば「保存して続ける／保存せず続ける／キャンセル」を選ばせる。入力値の変更も対象とし、保存済みデータが別タブで削除・更新された場合や読めない場合も未保存として扱う。保存失敗時は置換を実行しない。読み込み・全消去前の状態は真理値表から設定した入力値も含めUndoで戻せるようにする。保存データは版・件数・サイズ・ID・部品・端子・座標・入力値・循環を検証し、不正データや容量不足で既存の保存内容を消去しない。
- 保存ダイアログには「ファイルに保存」も置き、`format: joho.logic-circuit`・`version: 1`・名前・snapshotを持つ`.logic.json`をダウンロードする。読み込みダイアログはローカルファイル、ブラウザ保存、テンプレートをまとめる。JSONは1 MiB以内に制限し、形式・版・回路・折れ点を検証してから置き換える。読み取り中のキャンセルや別メニューへの移動、不正ファイルでは回路を変更しない。ブラウザ保存領域が使用不可でもファイル保存・読み込みは利用できる。ダウンロード開始だけでは保存完了と断定しないため、全消去等の直前にファイル保存を選んだ場合は「保存を確認して続ける」を明示的に押してから進む。
- 自由編集のツールバーの「0/1」で、エディタと画像出力の値・信号色をまとめて切り替える。初期状態は表示、非表示でも実際の入力値と真理値表は維持し、表示設定自体をUndo・保存snapshot・未保存判定に含めない。SVG・PNGの出力ダイアログには形式だけを置き、0/1のチェックボックスは置かない。完成回路の現在の配置・手動経路を共通ルーターから取得し、共有ゲートを出力ごとに複製せず、選択枠など編集UIは含めない。未使用の入力は保存図から省く。保存図の入力・出力は枠なしの点と名前で示し、ゲート端子の点は描かず、配線の分岐点●とNOTの否定を表す○は残す。SVGは実際の改行と単一のXML名前空間を持たせ、描画用CSSの既定値をSVG属性へ展開して外部CSS・CSS変数に依存させない。両形式とも白背景で、PNGは通常2倍解像度・長辺4096pxまでとする。PNG変換に失敗した場合は一時URLと処理中状態を解除し、ダイアログでエラーを伝えて再試行できるようにする。

### スライド形式の共通仕様

- 対象ページの`body`に`data-lesson-slide-deck`、各スライドに`data-lesson-slide`と`data-lesson-slide-title`を設定する。DR固有のグラフや問題UIは`css/digital-representation.css`と`js/sound-*.js`へ残す。
- 前後ボタンと現在位置を含むスライド選択メニューは、共通基盤が学校名ヘッダーの直下へ生成する。配置と操作の詳細は`docs/lesson-slide-deck.md`を参照する。最後のスライドから次教材へ進む場合は、原則として`js/pages.js`の`next`を使い、HTMLへURLを重複記述しない。
- 見出しIDを含むURLのハッシュから、該当スライドを直接開ける状態を保つ。
- 全画面・最大化時におおむね1画面へ収めつつ、MacBook Airの画面を左右半分にした幅や390px幅でも操作できるようにする。内容が収まらない場合は、ページ全体ではなく表示中のスライド内をスクロールさせ、横長SVGには必要に応じて横スクロールを用意する。

### 計算と問題生成の規則

- `SoundCore`はDOMに依存させず、標本化、量子化、符号化、データ量、標本化定理の判定などの正解計算を担う。Controllerには入力状態だけを持たせ、派生値を重複保存しない。
