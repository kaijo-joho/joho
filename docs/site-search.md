# 教材サイト内検索

教材サイト内検索は、GitHub Pagesだけで動作するブラウザ内検索です。検索語や検索履歴を保存せず、検索時に外部検索サービスへ送信しません。

## 検索とFAQの入口

ヘッダーの検索アイコンは、クリック・タップ・Enter・Spaceで「検索・よくある質問」dialogを直接開きます。ホバーではツールチップだけを表示し、dialogを自動では開きません。検索欄はタブの上に1つ置き、「FAQ」と「教材」を件数付きタブで切り替えます。FAQは教材メニューには重複表示しません。開閉とフォーカスの仕様は[ヘッダーの共通ナビゲーション](header-navigation.md)を参照してください。

2026年9月13日から、検索・回答表示・AI案内を`js/faq_shared.js`へ共通化しました。`main.js`の初期データ読込段階で読み込み、`faq_page.js`も同じ部品を利用します。FAQデータの正本・生成物`js/faq.js`は変更しません。

- 未入力では、LessonDockが解決した現在ページの関連FAQを既定表示します。入力すると全公開FAQと公開教材の両方を検索し、講座フィルターは両方へ適用します。検索結果でタブを自動切替しません。
- FAQ・教材ともNFKC正規化、英字大小文字の吸収、空白区切りのAND検索を行います。FAQは従来の講座・優先度・並び順を維持し、教材は関連度順です。FAQ一覧の単元・カテゴリ・キーワード絞り込みも維持します。
- FAQは質問を選ぶと同じdialog内で短い回答・分類・本文を開きます。20件ずつ追加表示でき、タブを切り替えても検索語と講座を保持します。同一ページでdialogを閉じて再度開いても検索語・講座は保持し、FAQタブへ戻ります。入力を消すと関連FAQ表示へ戻ります（選択中の講座フィルターは維持）。
- 「すべてのFAQを見る」または「この条件でFAQ一覧を開く」から従来の`faq.html`へ別タブで移動できます。一覧リンクには検索語`q`と対応する講座`course`を渡します。通常の共通検索では別タブを開きません。
- 未入力でFAQタブを初めて開いただけでは教材索引を取得しません。最初の検索入力、または教材タブ選択時に取得し、同一ページ中で再利用します。
- サイト内検索UIが利用できない場合は、ヘッダーからFAQ専用小メニューへフォールバックし、既存のFAQ検索・一覧リンクを利用できます。FAQ共通部品自体の読込に失敗した場合も一覧リンクは残します。

## AI相談室への導線

- 検索語があり、FAQデータと教材索引の読込に成功し、両方の検索結果が0件の場合に「AIに質問しますか？」を表示します。片方に結果がある場合は自動表示しません。
- 結果の有無にかかわらず「解決しなかった」を選ぶと同じ確認を表示できます。「いいえ、検索を続ける」は確認を閉じ、共通検索欄へフォーカスを戻します。
- IME変換中は検索せず、未読込・読込中・通信失敗を0件とみなしません。教材索引の読込失敗時もFAQ検索は利用でき、教材側には再試行ボタンを表示します。検索語変更後に古い非同期結果で表示を上書きしません。
- 「はい」で既存のfaqbotへ移動します。講座・元教材ページID・戻り先だけを渡し、検索語・質問文・URLのクエリやハッシュは渡しません（FAQ一覧の戻り先の講座だけは保持）。質問はGAS画面で再入力します。
- 学校アカウント認証、GASのデプロイ設定、API呼出条件・キーは変更しません。静的サイト内の検索でAI APIを呼び出すことはありません。
- 従来のFAQ一覧単体では、FAQ結果0件でAI案内を表示する既存仕様を保ちます。共通検索dialogの「両方0件」判定とは分けます。

## 索引の更新

`js/pages.js`、公開教材HTML、または`data/slides/*.json`を変更した場合は、検索索引を再生成します。

```sh
node scripts/generate-search-index.mjs
node scripts/generate-search-index.mjs --check
node scripts/test-site-search.mjs
```

`--check`は、コミット済みの`data/search-index.json`が現在の教材内容から生成される索引と一致しない場合に失敗します。

## 検索対象

- `js/pages.js`で`release: true`になっている登録済みページ
- 通常HTMLの見出し、本文、コード
- スライド型教材が参照する`data/slides/*.json`の節名、タイトル、ノート、画像の代替テキスト

FAQ、中継ページ、テストページ、未公開ページ、配付用サンプル・解答HTML、`archive/`、`teacher-tools/`は教材索引へ含めません。FAQは別データを同じ入力で検索します。

検索索引の読込時にも、現在の`pages.js`で`release === true`と確認できるページだけを残します。講座フィルターも、この確認後に索引へ残ったページの講座だけを表示します。索引更新前のデータが残っていても未掲載ページへのリンクや、そのページしかない講座の分類は表示しません。これは索引再生成の手順を省略するための仕組みではありません。

座学のDR・LC・NWも、公開時に検索対象へ含められる構成です。シリーズで絞り込むため、索引生成時に`mainTitle`の「デジタル表現」を`dr`、「論理回路教材」を`lc`、「ネットワークのしくみ」を`nw`へ対応付けます。ただし、`release: true`の教材がないシリーズは索引にも講座フィルターにも表示しません。FAQで未対応の`lc`・`nw`が今後公開されて選択可能になった場合も、FAQへのリンクには検索語だけを渡します。

シリーズの絞り込みボタンは幅に応じて折り返し、390px幅でも高さ44px以上の操作領域を確保します。

## 実行時の読み込み

FAQ共通部品・教材検索コア・dialog UIは共通スクリプトとして読み込みます。検索索引`data/search-index.json`は、最初の検索入力または教材タブ選択時に取得し、同じページを表示している間は再利用します。
